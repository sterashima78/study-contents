# ADR 0048: 中学1年「平面図形」を8つの技能と作図・移動の図示で構成する

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0043で中学数学の縦断実装を開始し、ADR 0046までに中学1年の「数と式」と「比例・反比例」を1ページ1技能で整備した。

現行の中学校学習指導要領（平成29年告示）数学第1学年「B 図形」の平面図形では、角の二等分線、線分の垂直二等分線、垂線などの基本的な作図、平行移動、対称移動、回転移動を扱う。さらに、図形の性質に着目して作図の方法を考察・表現すること、図形の移動に着目して二つの図形の関係を考察・表現すること、基本的な作図や図形の移動を具体的な場面で活用することが求められる。

内容の取扱いでは、円の接線は接点を通る半径に垂直であることも扱う。これらは文章だけで手順を説明するより、作図途中の円弧、交点、移動前後の対応点を図で確認した方が理解しやすい。

一方、既存の中学1年演習レジストリは「数と式」「関数」の問題生成を既に多数含んでいる。平面図形の問題生成まで同一ファイルへ追加すると責務が広がるため、図形領域の演習生成は別ファイルへ分離する。

## Decision

### 1. 「平面図形」を8つの小教材に分割する

中学1年数学の `geometry` 領域に `plane-geometry` 単元を追加し、次の順序で学習する。

1. 作図と対称性
2. 角の二等分線を作図する
3. 線分の垂直二等分線を作図する
4. 垂線を作図する
5. 平行移動
6. 対称移動
7. 回転移動
8. 作図を円の接線に活用する

作図は手順だけを暗記させず、二つの円の交点や線対称性を根拠として方法を説明する構成にする。

### 2. 作図と図形の移動を既存Diagram基盤で図示する

ADR 0034およびADR 0038の共有作図基盤を利用し、各教材で理解に必要な図を表示する。

基本作図では、元の点・直線、コンパスで描く円または円弧、得られる交点、最終的な二等分線・垂線を同じ図で区別して示す。

図形の移動では、移動前後の図形と対応点を同一図に置き、平行移動では方向と距離、対称移動では対称軸、回転移動では回転の中心・角度・向きを読み取れるようにする。

図を装飾目的では追加せず、作図方法の根拠、対応点、移動を決める条件を理解するために使用する。

### 3. 円の接線を作図の活用として扱う

最後の小教材では、円の接線が接点を通る半径に垂直である性質を扱う。

接点における半径を確認し、その半径への垂線として接線を捉えることで、「垂線の作図」を具体的な場面へつなげる。

円周角、接弦定理など第3学年以降の内容は先取りしない。

### 4. 図形領域の演習生成を別レジストリへ分離する

`src/content/middle-school/math/grade1/geometry-exercise-registry.ts` を追加し、平面図形8技能の問題生成を管理する。

`MiddleMathExerciseSet.astro` は `areaKey` が `geometry` の場合だけ図形用レジストリを利用し、それ以外は既存の `exercise-registry.ts` を継続利用する。

UI、採点、単元末診断、復習リンクは既存実装を共有し、問題生成データだけを領域単位で分離する。

### 5. 確認演習は8技能に対応させる

各小教材では3問、単元末では8問を生成する。

自由作図そのものの自動採点はこの段階では導入しない。確認演習では、作図の根拠となる等距離・垂直・角度、移動を決める条件、対応点、円の接線と半径の関係を問い、教材内の図と手順を理解できているかを確認する。

将来、作図操作を直接採点する場合はDiagramEditorと制約検証の利用方法を別ADRで決定する。

### 6. 新しい外部依存関係は追加しない

既存のAstro、TypeScript、ブラウザ標準API、共有Diagram基盤を利用する。

公開リポジトリであることを前提とし、教材、図解データ、演習データ、ADRに秘密情報、個人情報、外部サービスの認証情報を含めない。

## Consequences

第1学年の平面図形を、基本作図の意味から図形の移動、具体的な作図活用まで段階的に学習できる。

作図の根拠を図で確認できるため、コンパス操作の順番だけを暗記する構成を避けられる。また、平行移動・対称移動・回転移動を移動前後の対応として視覚的に比較できる。

演習生成を図形領域で分離するため、既存の数と式・関数の問題生成ファイルをさらに肥大化させずに中学1年数学を拡張できる。

一方、実際に定規とコンパスを操作する作図技能の自動評価はまだ行わない。教材図と知識確認で基礎を整備し、インタラクティブ作図評価は必要性を検証してから追加する。
