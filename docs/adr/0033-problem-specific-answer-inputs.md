# ADR 0033: 問題ごとに回答入力方式を設計する

- Status: Accepted
- Date: 2026-08-30

## Context

例題直後の GuidedPractice は、従来すべての回答を通常のテキスト入力として扱っていた。一方で、学習上必要な操作は問題ごとに異なる。式を組み立てる問題では数式入力が必要であり、候補から1つを判断する問題ではラジオボタンまたはセレクト、複数候補を選ぶ問題ではチェックボックス、語句や文章を書く問題では通常のテキスト入力が適する。

確認問題・単元末演習にも同じ問題があり、回答内容が選択判断なのに文字列を手入力させる問題や、数学の式を通常キーボードで入力させる問題が混在していた。入力UIを科目単位で固定すると、問題が測定したい能力と回答操作がずれる。

## Decision

問題の学習目的を先に決め、その目的に合わせて各問題・各ステップの回答方式を設計する。

回答方式は次を基本とする。

- `math`: 数式を構成・変形・計算して回答する。MathLive の MathfieldElement を使う。
- `text`: 単語、短文、説明、物質名、固有名詞などを自由入力する。ネイティブのテキスト入力を使う。
- `radio`: 少数の選択肢を比較して1つ選ぶ。選択肢を常時表示する。
- `select`: 選択肢が多い、または表示密度を下げたい1択問題に使う。ネイティブ select を使う。
- `checkbox`: 複数の正解候補を選択する問題に使う。

新規・改修コンテンツでは `PracticeStep` の `input` と、選択式の場合は `options` を明示する。明示された回答方式を最優先とし、入力方式を単に科目名や選択肢数だけで決めない。

既存コンテンツについては、一度に大量の教材データを書き換えて回答内容を変質させないため、`answer-input-design.ts` に移行用の設計層を置く。既存の問題文・プレースホルダーにすでに明示されている「真か偽」「A / B」「どちら」「〜から入力してください」などの選択指示と、確認済みの分類領域を読み取り、同じ設問を適切な radio/select に置き換える。式を構成する数学問題は MathLive、選択指示のない語句・説明・単位付き物理量は text を基本とする。

この移行用設計層は問題内容を推測して新しい正解を生成するものではない。既存の正解候補に選択肢が含まれることを確認できた場合だけ選択式へ変換し、正解候補と整合しない場合は従来の自由入力へ戻す。

同じ回答設計を、例題直後の GuidedPractice、理解確認問題、単元末演習に適用する。これにより同じ内容の問題が場所によって異なる不自然な入力方法になることを避ける。

数学の式回答では MathLive を利用し、LaTeX 表現差を吸収する正規化を行う。スマートフォンでは MathLive の仮想数式キーボードを利用でき、PCでは物理キーボード入力を維持する。

## Consequences

- 問題が測る能力と入力操作を一致させやすくなる。
- 数式入力が必要な問題だけで数式キーボードが開くため、モバイルの占有面積を抑えられる。
- 判断問題では不要な文字入力を減らし、学習内容そのものに集中できる。
- 選択問題は選択肢の性質に応じて radio/select/checkbox を使い分けられる。
- GuidedPractice と各 ExerciseSet の採点処理は複数の入力要素を扱う必要がある。
- 既存教材の移行期間は、明示設定と設計層の両方を保守する必要がある。

## Implementation notes

- `GuidedPractice.astro` は回答方式に応じて適切なコントロールを描画する。
- `answer-input-design.ts` は既存設問の回答方式を監査・移行する共通設計層とする。
- `MathLesson.astro`、`PhysicsLesson.astro`、`EnglishLesson.astro` は GuidedPractice に渡す前に回答設計を適用する。
- `ExerciseSet.astro`、`PhysicsExerciseSet.astro`、`SocialExerciseSet.astro` は生成された確認・演習問題にも同じ回答設計を適用する。
- 数式回答は MathLive の値を採点時に正規化する。
- 選択肢の正解値は表示ラベルから分離できるようにする。
- 数学の展開・方程式・式変形など、式を自分で構成すること自体が学習目標の問題は `math` を選ぶ。
- 真偽、分類、公式選択、文法上の役割など、候補から判断することが学習目標の問題では `radio` または `select` を選ぶ。
- 反例、式、文章説明など、回答を自分で生成することが学習目標の問題を選択式へ変えない。
