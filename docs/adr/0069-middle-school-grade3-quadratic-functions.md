# ADR 0069: 中学3年「関数 y=ax²」を9教材で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0058, ADR 0063, ADR 0068

## Context

第3学年C(1)では、関数y=ax²の理解、具体的事象に2乗比例があること、さらに既習の式では捉えにくい関数関係があることを理解し、表・式・グラフを相互に関連付けて考察・表現することが求められる。

## Decision

### 1. 9教材へ分割する

意味、式の決定、xとyの倍率、グラフ、比例定数a、変化の割合、表・式・グラフの相互関連、具体的活用、式で表しにくい関数関係を独立技能とする。

### 2. 一次関数との違いを変化の割合から明示する

単に放物線の形を暗記させず、変化の割合が一定でないこととグラフが直線でないことを関連付ける。

### 3. aの符号と絶対値をグラフへ結び付ける

`a>0`/`a<0`による開く向きと、`|a|`による開き具合を同じ座標平面のDiagramで比較する。

### 4. 具体的活用ではモデルの前提を扱う

教材用の架空データを2乗比例とみなし、予測する。実測とモデルの食い違いや適用範囲を確認し、確定的な現実値と誤解させない。

### 5. 関数概念を式の種類に限定しない

段階料金など、簡単な式で表しにくくても入力を一つ決めると出力が一つ決まる関係を関数として扱う。

### 6. 既存基盤を維持する

既存Cartesian Diagram APIを利用し、新規グラフライブラリは追加しない。専用演習レジストリで各教材3問、単元末8問を生成する。依存関係、外部API、Study AI設定は変更しない。

## Consequences

- 中1比例・反比例、中2一次関数との縦の接続が明確になる。
- 表・式・グラフと変化の割合を相互に関連付ける教材構成になる。
- 関数概念を高校での学習へつなげやすくなる。
