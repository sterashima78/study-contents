# ADR 0037: 説明図のズームはレスポンシブ最小幅も同倍率で変更する

- Status: Accepted
- Date: 2026-08-30
- Related: ADR 0034, ADR 0036

## Context

`DiagramView.astro` は説明図に 75% から 250% の表示倍率変更を提供している。

従来は倍率変更時に `.stage` の `width` だけを変更し、`DiagramScene.responsive.minWidth` から設定した `min-width` は固定していた。そのため、画面幅より `minWidth` が大きいモバイル環境では、100% から 75% に変更しても固定された `min-width` が下限となり、図の実寸が変化しない場合があった。

`minWidth` は100%表示時に読みやすさを保つための基準であり、利用者が明示的に縮小を選んだ後まで同じ実寸を強制するとズーム操作の意味と矛盾する。

## Decision

### 1. `width` と有効 `min-width` を同じ倍率で変更する

100%表示時の `responsive.minWidth` を基準最小幅として保持する。

倍率を `z` としたとき、表示ステージは次の2値を同時に更新する。

- `width = z × 100%`
- `min-width = z × 基準minWidth`

これにより、たとえば基準 `minWidth=480px` の図を75%にした場合、有効最小幅は360pxになる。

### 2. CSSの乗算構文には依存しない

基準最小幅は `data-base-min-width` としてDOMに保持し、クライアント側JavaScriptで倍率を掛けたピクセル値を設定する。

CSS Valuesの新しい乗算構文の対応状況に依存せず、モバイルSafariを含む既存ブラウザで同じ意味になる実装を優先する。

### 3. 図データの座標値は変更しない

ズームは `DiagramScene` や各要素の座標を書き換えず、描画コンテナの寸法だけを変更する。

教材側の数学座標・SVG座標と表示倍率を分離し、ズーム操作によって教材データが変化しない状態を維持する。

### 4. 操作範囲は75%から250%のままとする

25%刻みで変更し、75%と250%ではそれぞれ縮小・拡大ボタンを無効化する。100%ボタンで基準表示へ戻す。

75%では教材作成時の基準最小幅より小さく表示されることを許容する。文字が小さく感じる場合は100%以上へ戻せるため、縮小は利用者が画面全体を見渡すための明示的な選択として扱う。

### 5. 横スクロールとの役割を分ける

100%表示では従来どおり `responsive.minWidth` を優先し、狭い画面では横スクロールで読みやすさを維持する。

縮小を選んだ場合だけ有効最小幅も縮め、図全体を画面内へ収めやすくする。横スクロールと縮小のどちらか一方を強制せず、利用者が目的に応じて選べるようにする。

## Consequences

モバイルでも75%への変更が実際の縮小として反映され、倍率表示と見た目が一致する。

一方、75%ではラベルや線も小さくなるため、教材作成者は100%時の `minWidth` を読みやすさの基準として設定し、縮小時にも識別できる十分な文字サイズ・ラベル配置を用意する必要がある。
