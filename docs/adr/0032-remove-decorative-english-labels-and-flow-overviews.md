# ADR 0032: 装飾的な英字ラベルと重複する学習フロー案内を表示しない

- Status: Accepted
- Date: 2026-08-30
- Related: ADR 0022, ADR 0029, ADR 0030

## Context

ADR 0029以降、見出しの上に `CONTENTS`、`LESSONS`、`GOAL`、`EXAMPLE`、`PRACTICE` などの英字ラベルを小さく置き、日本語見出しと組み合わせる表現を採用していた。また、科目ページや単元ページでは、教材一覧へ入る前に学習順序を示す `LearningFlow` を表示していた。

実機表示を確認すると、これらは教材の意味を増やすよりも、編集デザインとしての装飾や製品的な見せ方として目立つ。特に日本語の見出しだけで内容が十分に伝わる箇所では英字ラベルが重複情報になり、画面のノイズを増やす。

同様に「小さく区切って順番に学ぶ」などの学習フロー案内は、実際の小単元一覧や教材本文の構造と内容が重複し、学習を始めるまでに説明セクションを一つ追加していた。このサイトは完成品の教育サービスとして演出することより、生成AIを使った実験的な学習コンテンツを直接確認できることを優先する。

## Decision

### 1. 装飾目的の英字ラベルを表示しない

日本語見出しの意味を英語で繰り返す小見出し、キッカー、ラベルは画面に表示しない。

対象には次を含む。

- `ContentHero.astro` の kicker
- `SectionHeading.astro` の label
- `ActionPanel.astro` の label
- `ContentIndex.astro` の kicker
- 例題・練習・国語教材などで直接表示していた `EXAMPLE`、`PRACTICE` 等のラベル
- トップページの `EXPERIMENTAL` ラベル

既存呼び出し側との互換性を保つ必要がある共有コンポーネントでは、当面 props 自体は受け取れる状態を維持してよい。ただし画面には描画しない。

### 2. 教材そのものとして必要な英語は残す

英語科目の英文、英単語、文法上必要な英語表現、数式・記号、固有名詞など、学習内容そのものに属する英語は削除しない。

削除対象は日本語UIに併記された装飾的・分類的な英語に限定する。

### 3. 汎用的な学習フロー案内を削除する

科目ページ、単元ページ、応用・発展ページなどで、実際の教材一覧や本文より前に置いていた `LearningFlow` を削除する。

「考え方 → 例題 → 練習 → まとめ」のような順序は、各教材の本文構造として必要な場合は維持する。ただしページ冒頭で同じ順序を別セクションとして説明しない。

利用箇所がなくなるため `LearningFlow.astro` 自体も削除する。

### 4. 実験性の説明は日本語本文で明示する

生成AIを利用した制作実験であること、通常の編集・監修済み教材と同等の正確性を保証しないこと、公式資料との確認が必要なことは引き続きトップページで明示する。

実験性を示すために英語ラベルやブランド的なコピーを追加する必要はない。制作上の位置づけは日本語の具体的な説明文で伝える。

### 5. 新しい依存関係を追加しない

今回の変更は既存Astroテンプレートとscoped CSSの整理だけで実装し、ライブラリ、外部フォント、画像、クライアント依存を追加しない。

## Consequences

ページ上部の情報量が減り、日本語の見出しと教材本文が直接視線に入る。特にモバイルでは、装飾的なラベルや学習フロー案内による縦方向の占有が減り、一覧や本文へ早く到達できる。

一方で、学習順序をページ冒頭で一覧する補助表示はなくなる。必要な順序は教材本文の見出しやページナビゲーション、小単元一覧の並び順で表現する。
