# ADR 0095: 承認済みパブリックドメイン文章を国語教材へ参照導入する

- Status: Accepted
- Date: 2026-09-03
- Related: ADR 0026, ADR 0073, ADR 0078

## Context

ADR 0073 では、外部文学作品を権利台帳で管理し、`reviewStatus` が `approved` の項目だけを教材実装から参照可能とした。また、最初の実作品導入時に、承認済み台帳IDを参照する型、作品名・著作者・出典の表示、`approved` 以外をビルド対象にしない検証、原文と教材独自部分の区別を追加すると定めている。

ADR 0078 では、国語の初期候補を寺田寅彦「茶わんの湯」、夏目漱石「現代日本の開化」、鴨長明「方丈記」とし、現代文では説明・観察文章と論説文章を優先する方針を採用した。権利台帳ではこの3作品がすでに `approved` になっている。

これまでの国語教材は独自文章だけを持ち、外部作品の権利台帳IDや出典を表示するモデルを持っていなかった。そのまま本文だけを追加すると、台帳状態が後から変更された場合に教材が残り続けたり、本文と教材独自の設問・解説の区別が不明確になったりする。

## Decision

### 1. 国語教材は承認済み権利台帳IDから出典情報を解決する

`src/content/text-sources/public-domain.ts` に、権利台帳IDから教材表示用の出典情報を解決する関数を置く。

教材データでは作品名や著作者を重複入力せず、権利台帳IDを指定して解決する。IDが存在しない場合、または `reviewStatus` が `approved` でない場合はモジュール評価時に例外を発生させる。

これにより、承認前または承認取り消し後の本文を静的ビルド対象へ残さない。

### 2. 実作品教材では本文の出典と権利台帳IDを画面表示する

実作品を使う教材には次を表示する。

- 著作者名
- 作品名
- 本文取得元
- 取得元URL
- 権利台帳ID
- 本文は作品からの抜粋であり、設問・解説は教材側の独自作成であること

既存の独自文章教材には出典欄を表示しない。

### 3. 初期実装は現代文2教材とする

最初に次の2教材を追加する。

1. 寺田寅彦「茶わんの湯」
   - 権利台帳ID: `terada-chawan-no-yu`
   - 学習目標: 観察事実と説明の区別、指示語、具体例、段落の役割、要約
   - 使用区間: 冒頭で茶わんの湯を観察対象として提示し、白い湯げを雲や霧と同じ仕組みとして説明する連続区間

2. 夏目漱石「現代日本の開化」
   - 権利台帳ID: `natsume-gendai-nihon-no-kaika`
   - 学習目標: 定義、分類、対比、抽象と具体、要約
   - 使用区間: 「開化は人間活力の発現の経路である」という定義から、積極的活動と消極的活動を示す連続区間

各本文はADR 0078の現代文350〜900字の目安に収め、離れた文を継ぎ合わせない。

### 4. 外部本文と教材独自部分をデータ上でも表示上でも区別する

作品本文は `example.passage` に連続した抜粋として保持する。設問、正答、解説、読み方、まとめは教材独自部分として作成し、外部の解説や市販教材を転用しない。

実作品教材では本文ラベルを「本文」とし、既存の独自文章教材では従来どおり「例文」と表示する。

青空文庫の作品本文以外の書誌注記、底本説明、入力・校正情報、サイト説明は本文へ転載しない。ルビ表示のために電子版で付加された読みも本文へ取り込まず、本文の文字列だけを利用する。

### 5. 既存国語カタログを保ったまま実作品単元を独立モジュール化する

既存教材は内容変更を避けるため `catalog-base.ts` にそのまま保持し、新しい実作品単元を `public-domain-reading.ts` に分離する。公開用 `catalog.ts` で現代文エリアへ新単元を追加し、既存の検索関数は拡張後のカタログを参照する。

これにより、既存教材30KB程度の単一ファイルをさらに肥大化させず、今後の実作品追加を独立してレビューできるようにする。

## Consequences

権利台帳と教材表示が直接結び付き、`approved` 以外の作品を誤って公開するリスクを下げられる。出典と教材独自部分の区別も利用者から確認できる。

一方、実作品教材は権利台帳へ依存するため、台帳IDの削除やレビュー状態の変更によりビルドが失敗する。これは意図した安全側の挙動であり、権利状態を変更するPRでは関連教材も同時に確認する。

初期段階では現代文2教材だけを導入し、「方丈記」は古文教材の現代語訳・語注設計を別途確認してから追加する。
