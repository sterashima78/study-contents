# ADR 0032: 装飾的な英字ラベルを使わず日本語の見出しだけで構成する

- Status: Accepted
- Date: 2026-08-30
- Related: ADR 0022, ADR 0029, ADR 0030, ADR 0031

## Context

ADR 0029以降、サイト全体を「静かな編集ノート」に寄せるため、見出しの上に `CONTENTS`、`GOAL`、`RULE`、`EXAMPLE`、`PRACTICE`、`SUMMARY` などの英字ラベルを小さく併記していた。また、科目トップや単元ページには「各小単元の学習の流れ」「小さく区切って順番に学ぶ」といった学習方法の説明ブロックを置いていた。

実機表示では、これらは教材の理解に必要な情報というより装飾や説明の重複として見え、低ノイズなノートという方針に対して視覚要素を増やしていた。日本語の見出しだけで内容は十分に識別でき、科目・領域・単元・小単元という階層もパンくずと一覧から把握できる。

一方、英語科目の本文・例文・問題文など、学習対象そのものとしての英語は削除対象ではない。また、生成AIを使った実験であることや、オリジナル英文に関する権利上の説明は制作上の重要情報なので残す必要がある。

## Decision

### 1. 装飾目的の英字併記を表示しない

共通UIでは、主見出しの上に置く補助的な `kicker` / `label` を画面へ表示しない。

対象には次を含む。

- `ContentHero.astro` の kicker
- `SectionHeading.astro` の label
- `ContentIndex.astro` の item kicker
- `ActionPanel.astro` の label
- `WorkedExample.astro` の label
- 練習、国語例題・確認問題、英文カード、実験注記に直接記述していた英字ラベル

呼び出し側との互換性を保つため、既存の `kicker` / `label` プロパティは当面受け付けてもよいが、視覚要素としては描画しない。

### 2. 学習方法を説明するだけの独立セクションを置かない

科目トップや単元一覧で、教材構造と同じ内容を繰り返す学習フロー表示は削除する。

特に次のような説明は独立した大きなセクションにしない。

- 「各小単元の学習の流れ」
- 「小さく区切って順番に学ぶ」
- 英語単元ページの学習手順説明

利用者は科目・領域・単元・小単元の一覧から直接教材へ進める構成を優先する。

### 3. 必要な制作情報は残す

生成AIを使った実験であること、精度上の注意、オリジナル英文の扱いなど、制作方法・権利・利用上の注意に関する情報は削除しない。ただし装飾的な英字ラベルは付けず、日本語の見出しと本文だけで示す。

### 4. 英語学習コンテンツ自体は対象外とする

英語科目の英文、例文、語句、設問など、学習対象として必要な英語表現はそのまま表示する。「英語を日本語へ置き換える」判断ではなく、「日本語UIに装飾目的で英語を重ねない」判断とする。

### 5. 新しい依存関係を追加しない

変更は既存Astroコンポーネントとscoped CSSの整理だけで実施し、外部フォント、画像、UIライブラリ、状態管理ライブラリは追加しない。

## Consequences

見出しの情報量が減り、日本語の主見出しと教材本文に視線を集中しやすくなる。トップ・科目・単元・教材ページの見た目も一貫して簡素になる。

学習方法を説明する導入ブロックが減るため、初見利用者への説明量は少なくなる。一方で、実際の教材一覧や教材本文へ早く到達でき、サイトを製品紹介ではなく実験的な教材そのものとして見せる方針と整合する。
