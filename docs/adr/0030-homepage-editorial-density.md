# ADR 0030: トップページは実験性を明示しつつ編集紙面の密度を整える

- Status: Accepted
- Date: 2026-08-30
- Related: ADR 0007, ADR 0022, ADR 0023, ADR 0024, ADR 0029

## Context

ADR 0029でサイト全体を「静かな編集ノート」へ寄せた後、実機のモバイル表示を確認すると、トップページでは大きなヒーロー見出しと長い説明が初期表示の大半を占めていた。その結果、科目一覧へ到達するまでの情報量が多く、デザイン検討で意図した低ノイズな学習ノートよりも、説明を読むランディングページに近い印象になっていた。

また、各科目の説明文で「1ページ1技能」など同じ表現が繰り返され、カード内の情報量に対して内容の差が読み取りにくい。トップページは製品としての魅力を訴求する場所ではなく、生成AIを使った学習コンテンツ制作の実験であることを示したうえで、公開中の教材へ進む入口として機能させる必要がある。

ADR 0024では、生成AIを使ったバイブコーディングの実験であること、生成AI由来の誤りを含む可能性、公式資料等との確認が必要であることをトップページで明示すると決定した。この前提は維持する。本ADRはADR 0024を置き換えず、実験性の明示を保ったまま表示密度とコピーを調整する。

## Decision

### 1. ヒーローは製品的なコピーを避け、サイトの実験内容を直接示す

トップページの主見出しは「高校学習コンテンツ」とする。「高校の学びを、ひとつずつ。」のようなブランド・製品的なキャッチコピーは使用しない。

ヒーローでは、生成AIを使って高校範囲の学習コンテンツを構成・改善する実験であることを短く説明する。モバイルではヒーロー自体の文字サイズと上下余白を抑え、実験注記と科目一覧が早い段階で見えるようにする。

### 2. 制作方法を含む実験注記を科目選択前に常時表示する

`ExperimentalNotice.astro` はヒーローと科目一覧の間に配置し、開閉式にはしない。次の点を簡潔に表示する。

- 生成AIを使って学習コンテンツをバイブコーディングする実験であること
- 教材の内容や構成の作成・改善に生成AIを活用していること
- 通常の編集・監修済み教材と同等の正確性を保証しないこと
- 誤りや不正確な記述を含む可能性があること
- 教科書や文部科学省などの公式資料もあわせて確認すること

制作側の事情は単なる内部情報ではなく、このサイトが完成品の教育サービスではなく実験的生成物であることを理解するための情報として扱う。この判断はADR 0024と整合する。

### 3. 科目一覧にはコンパクト密度を追加する

`ContentIndex.astro` の既存 `grid` / `rows` APIを維持したまま、`density="compact"` を追加する。

コンパクト密度では、余白、見出しサイズ、タグ、メタ情報を一段小さくし、モバイルでも一つの科目カードが過度に画面を占有しないようにする。既存の科目・領域・単元ページはデフォルト密度を使い、トップページ以外の視覚階層を変更しない。

### 4. トップページのコピーは内容差が分かる短文にする

各科目の説明は、同じフォーマット文を繰り返さず、「何を学ぶか」と「どの視点で整理するか」を1〜2文で示す。

公開数は「N小教材公開」ではなく「N教材」とし、行動ラベルは「科目の目次を見る」から「目次へ」に短縮する。科目名、領域タグ、公開数そのものは変更しない。

### 5. 紙面色は白に近づけ、面の主張を弱める

`StudyPage.astro` の背景を従来より明るい温白色へ変更し、カード面は白、補助面はごく薄い温グレーとする。トープ系のアクセントとWCAG AAを満たす文字コントラストは維持する。

### 6. 新しい依存関係を追加しない

今回の変更はAstroのテンプレートとscoped CSSだけで実装する。外部フォント、画像、UIライブラリ、状態管理ライブラリは追加しない。

2026-08-30時点で使用中の Astro 7.2.9、MathLive 0.110.0、Biome 2.5.11、pnpm 12.0.0 は維持する。依存関係を変更する場合は、その時点の最新版と既存コードへの影響を別途確認する。

## Consequences

トップページは完成品の教育サービスのような印象を弱め、生成AIを使った制作実験であることを最初に理解できる構成になる。

一方で、実験注記を科目一覧より前に常時表示するため、科目一覧だけを最短で見せる構成より初期表示の情報量は増える。これについては、注記自体を短くし、ヒーローとカードの余白を抑えることでバランスを取る。

科目説明を短くすることでトップページの走査性は維持しつつ、制作方法、生成AI利用、正確性の限界を隠さないことを優先する。
