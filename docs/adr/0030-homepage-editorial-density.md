# ADR 0030: トップページは科目選択を優先して編集紙面の密度を整える

- Status: Accepted
- Date: 2026-08-30
- Related: ADR 0007, ADR 0022, ADR 0023, ADR 0024, ADR 0029

## Context

ADR 0029でサイト全体を「静かな編集ノート」へ寄せた後、実機のモバイル表示を確認すると、トップページでは大きなヒーロー見出しと生成AIに関する長い注記が初期表示の大半を占めていた。その結果、利用者が最初に行う「科目を選ぶ」という操作が画面下方へ押し出され、デザイン検討で意図した低ノイズな学習ノートよりも、説明を読むランディングページに近い印象になっていた。

また、各科目の説明文で「1ページ1技能」など同じ表現が繰り返され、カード内の情報量に対して内容の差が読み取りにくい。トップページはサイトの理念を詳しく説明する場所ではなく、学習を始める入口として科目と学習範囲を短時間で把握できることを優先する必要がある。

ADR 0024では、生成AI利用の注意書きを科目選択前かつヒーロー内に置き、制作手法としてバイブコーディングを説明する方針を採用していた。本ADRは実機での情報優先度を見直し、その配置とコピーに関する判断を置き換える。生成AIを利用した教材であること、誤りを含む可能性、公式資料等との確認が必要であることを明示する原則は継続する。

## Decision

### 1. 初期表示では科目選択を優先する

トップページのヒーローは、サイトの用途を一文で伝える規模に抑える。モバイルではタイトル、短い説明、科目セクションの見出しが早い段階で見えるよう、`display` ヒーローの文字サイズと上下余白を縮小する。

トップページの主見出しは「高校の学びを、ひとつずつ。」とし、説明は「科目を選び、短い解説と例題・練習を順に進める」ことに絞る。

### 2. 生成AIに関する注記は維持しつつ主導線から外す

生成AIを利用した実験的教材であることは引き続き明示する。ただしヒーロー内の大きな説明ブロックにはせず、科目一覧の後に `details` / `summary` を使った開閉可能な補足として配置する。

文言は技術用語や制作手法の説明を避け、次の2点に限定する。

- 教材は生成AIを利用して作成・改善している
- 誤りを含む可能性があるため、教科書や公式資料とあわせて確認する

重要な注意を削除するのではなく、学習開始の操作と説明責任の優先順位を分離する。この配置・文言判断により、ADR 0024を置き換える。

### 3. 科目一覧にはコンパクト密度を追加する

`ContentIndex.astro` の既存 `grid` / `rows` APIを維持したまま、`density="compact"` を追加する。

コンパクト密度では、余白、見出しサイズ、タグ、メタ情報を一段小さくし、モバイルでも一つの科目カードが過度に画面を占有しないようにする。既存の科目・領域・単元ページはデフォルト密度を使い、トップページ以外の視覚階層を変更しない。

### 4. トップページのコピーは内容差が分かる短文にする

各科目の説明は、同じフォーマット文を繰り返さず、「何を学ぶか」と「どの視点で整理するか」を1〜2文で示す。

公開数は「N小教材公開」ではなく「N教材」とし、行動ラベルは「科目の目次を見る」から「目次へ」に短縮する。科目名、領域タグ、公開数そのものは変更しない。

### 5. 紙面色は白に近づけ、面の主張を弱める

`StudyPage.astro` の背景を従来より明るい温白色へ変更し、カード面は白、補助面はごく薄い温グレーとする。トープ系のアクセントとWCAG AAを満たす文字コントラストは維持する。

### 6. 新しい依存関係を追加しない

今回の変更はAstroのテンプレートとscoped CSSだけで実装する。外部フォント、画像、UIライブラリ、状態管理ライブラリは追加しない。

2026-08-30時点で使用中の Astro 7.2.9、MathLive 0.110.0、Biome 2.5.11、pnpm 12.0.0 は最新系であり、今回の変更ではバージョン更新を必要としない。

## Consequences

モバイルの初期表示で大きなタイトルと長い注意文に視線を奪われにくくなり、科目選択へ早く到達できる。PCでは従来の2列構成を保ちながら、カードの情報密度が上がり、より編集インデックスに近い見た目になる。

生成AI利用の注記は残るが、必要な利用者が開いて確認する補足情報となる。科目説明を短くすることでトップページの走査性は上がる一方、詳細な学習方針は各科目・単元ページで説明する責任がより大きくなる。
