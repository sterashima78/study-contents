# ADR 0019: 応用・発展教材を1パターン1ページとし図解を一時停止する

- Status: Accepted
- Date: 2026-08-29

## Context

ADR 0018 では、応用・発展教材を解法パターン単位で構成し、「考え方・着眼点 → 例題 → ステップ練習 → 実践 → 必要に応じて生成問題」という学習フローを採用した。また、図形やグラフを扱う問題ではSVG等の図解を提示する方針とした。

数学I「二次関数」でこの構成を1ページにまとめた結果、複数パターンを連続して掲載することでページが長くなり、1つの解法パターンに集中しにくくなった。また、放物線と接線の概念図に数学的な不整合があり、図の自動生成については教材本文とは別の品質保証が必要であることが分かった。

基礎教材ではADR 0001により短い学習単位を重視している。応用・発展教材でも、1ページで扱う学習対象を明確にし、ページ単位で復習・共有しやすくする方が全体の学習設計と整合する。

## Decision

### 1. ADR 0018を置き換える

ADR 0018のうち、難易度を「応用」「発展」とすること、解法パターン単位で教材を作ること、生成可能なパターンだけに問題生成器を持たせること、ADR 0017の独自作成・権利管理方針に従うことは継続する。

ページ構成と図解方針は本ADRで変更する。

### 2. 応用・発展教材は1パターン1ページとする

1つのページには1つの解法パターンだけを掲載する。

各パターンページは原則として次の順序にする。

1. 考え方・着眼点
2. 例題
3. ステップバイステップの練習問題
4. 実践問題
5. 生成可能な場合は別問題の生成

単元の応用・発展トップページには各パターンの本文を展開せず、次だけを表示する。

- パターン名
- 難易度
- 目安時間
- 主な技能
- 着眼点の短い説明
- 個別ページへのリンク

これにより、一覧ページは学習内容を選ぶための索引とし、実際の学習は個別ページで行う。

### 3. パターンページ間を前後移動できるようにする

パターンページには、一覧へ戻る導線に加えて前後のパターンへのリンクを設ける。

URLはパターンIDから安定したslugを生成し、同じパターンのURLが教材本文の変更で変わらないようにする。

### 4. 図解の表示と新規追加を一時停止する

応用・発展教材では当面、SVG、画像、グラフ等の図解を表示しない。

図形やグラフを扱う問題であっても、必要な条件は問題文と文章による説明だけで完結させる。

既存の図解コンポーネントは使用を停止し、教材データの図解定義も削除する。

図解を再導入する場合は、少なくとも次を保証する検証方法を別ADRで定める。

- 数式・問題条件と図の位置関係が一致している
- 接点、交点、長さ、角度など重要な幾何情報が正しい
- パラメータを変えた場合も図が数学的に成立する
- 自動検証できない要素について人手レビュー手順がある

この検証方針が定まるまでは、理解補助を目的とした概念図も掲載しない。

### 5. 問題生成は継続する

問題生成は図解と分離して扱う。

生成可能なパターンだけに `generatorKey` を持たせ、同一の生成パラメータから問題文、条件、解答、解答過程を作る。生成規則は、解の存在と対象解法パターンが維持される範囲だけを使用する。

生成問題に図は生成しない。

### 6. CIで図解データを禁止する

`src/content/entrance/` 以下の応用・発展教材について、従来の構造・権利検証に加えて `diagram` フィールドが存在しないことを確認する。

これにより、図解の一時停止期間中に未検証の図が再導入されることを防ぐ。

## Consequences

一覧ページの長さを抑えられ、学習者は1つの解法パターンに集中できる。各パターンに固有URLができるため、復習リンクや弱点診断から特定パターンへ直接誘導しやすくなる。

一方、ページ数は増えるため、共通レイアウトとナビゲーションを再利用する必要がある。問題生成のJavaScriptも個別ページで共通化して使う。

図解を一時停止することで視覚的な補助は減るが、数学的に誤った図を教材として提示するリスクを避けられる。図解の再導入は、正しさを検証できる仕組みを整えてから判断する。
