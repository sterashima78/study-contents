# ADR 0059: 座標平面上の位置関係を説明の一部として図示する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0034, ADR 0035, ADR 0036, ADR 0038, ADR 0046, ADR 0058

## Context

ADR 0038 では位置関係、向き、グラフの傾き、極値などを文章だけで説明している箇所を優先して図示する方針を定めた。中学数学の座標・比例・反比例、一次関数、連立方程式とグラフではこの方針に沿った説明図が既に追加されている。

一方、数学Iの `y=a(x−p)²+q` では「`y=ax²` を右に `p`、上に `q` 平行移動する」「頂点は `(p,q)`、軸は `x=p`」と文章で説明しているが、基準の放物線、移動先の頂点、対称軸の位置関係を同じ座標平面で確認する図がなかった。同様に、定義域と頂点、放物線と x 軸の交点、判別式と交点数、二次不等式の正負区間も、座標平面上の位置関係そのものが説明の根拠になるにもかかわらず図示が不足していた。

数学IIの点・直線・円でも、内分点、傾き、平行・垂直、円の中心と半径、円と直線の共有点など、位置関係を文章と式だけで扱うレッスンが残っていた。

## Decision

### 1. 座標平面上の位置関係が推論の根拠になる説明では図を原則必須とする

次のいずれかを学習者が座標平面上で判断するレッスンでは、`rule` または `example`、原則として概念説明を行う `rule` に説明図を配置する。

- 点、頂点、中心、交点、接点、端点などの位置
- 平行移動、対称軸、定義域とグラフの位置関係
- 直線の傾き、平行、垂直
- グラフと x 軸・y 軸の交差、接触、非交差
- グラフが軸より上か下か、正負になる区間
- 円の中心・半径・内部外部、円と直線の共有点

式変形、解の公式の計算、係数代入など、座標上の位置を使わずに完結する手順には図を必須としない。

### 2. 図は本文の結論ではなく、本文の理由を可視化する

座標軸と曲線を置くだけでは不十分とする。図中で、本文が判断に使う対象を直接示す。

- `y=a(x−p)²+q`: 基準の放物線、平行移動の向き、頂点、軸
- 区間上の最大・最小: 定義域内の曲線、端点、頂点、軸
- 方程式とグラフ: x 軸との交点と方程式の解
- 判別式: 2交点、接する、交わらないの3状態
- 二次不等式: x 軸より上または下にある曲線部分と解区間
- 直線: 座標差による傾き、平行・垂直の向き
- 円: 中心、半径、共有点、内部外部

色だけに意味を持たせず、点名、式、区間、軸などの文字ラベルを併記する。`ariaLabel` にも図が担う位置関係を文章で記述する。

### 3. 既存の型付き描画基盤だけを使う

ADR 0038 と同じく、`DiagramScene`、`CartesianTransform`、`sampleFunctionPlot` など既存の型付き描画基盤を利用する。任意SVG、`innerHTML`、ブラウザで評価する数式、新しい外部描画ライブラリは追加しない。

座標は数学座標から `CartesianTransform` で描画座標へ変換し、曲線の形をSVG座標の手入力で作らない。

### 4. トピック別 companion registry を追加する

数学Iの二次関数は `src/content/math1/quadratic-diagrams.ts`、数学IIの座標幾何は `src/content/math2/geometry-diagrams.ts` に分離する。

既存の大きな `diagrams.ts` へ追加し続けず、ADR 0038 の「同一科目内で複数レジストリを持つ場合は科目横断 resolver で合成する」方針に従い、`src/content/lesson-diagrams.ts` で既存レジストリとフォールバック合成する。同じ `lesson.key` を複数レジストリへ重複登録しない。

### 5. 今回の監査対象と対応を明示する

数学I「二次関数」では次を対象とする。

- `basic-parabola`: 既存図を継続利用
- `vertex-form`: 平行移動、頂点、軸を追加
- `completing-square`: 平方完成後の頂点と軸を追加
- `quadratic-extrema-all-real`: 頂点と最大・最小の位置を追加
- `quadratic-extrema-interval`: 定義域、端点、頂点、軸の位置関係を追加
- `quadratic-roots-graph`: 方程式の解と x 軸交点の対応を追加
- `discriminant`: `D>0`、`D=0`、`D<0` と x 軸の位置関係を追加
- `quadratic-inequality-two-roots`: x 軸より上・下になる区間を追加
- `quadratic-inequality-special-cases`: 接する場合と交わらない場合の符号を追加

`quadratic-formula` は主題が代数的な公式導出と代入であり、座標上の位置関係を推論に使わないため今回の必須対象から除外する。最大・最小および二次不等式の文章題は、数量モデルと定義域の設定が主題であるため、グラフが問題理解に不可欠な個別題材が導入された時点で図示する。

数学II「図形と方程式」では次を対象とする。

- `section-formula`: 2点、内分点、比の位置関係を追加
- `line-equations`: 2点と座標差、傾きを追加
- `parallel-perpendicular-lines`: 平行・垂直な直線の向きを追加
- `circle-equations`: 中心、半径、円周上の位置関係を追加
- `circle-line-locus-region`: 円と直線の共有点、内部外部を追加

中学数学は既存実装を確認し、次を今回の基準を満たすものとして継続利用する。

- 中1: `coordinates`、`proportion-graph`、`inverse-proportion-graph`、`function-representations-application`
- 中2: `linear-function-meaning`、`linear-function-rate-of-change`、`linear-function-graph`、`linear-function-from-graph`、`linear-equation-as-function`、`systems-and-graphs`、`linear-function-application`

### 6. 今後の教材追加時も同じ判定を使う

新しい数学レッスンを追加するとき、本文に「右・左・上・下」「交わる・接する」「平行・垂直」「内側・外側」「区間内・区間外」「軸より上・下」など座標平面上の相対位置を表す説明があり、その位置関係が結論の理由になっている場合は、本文と同じ段階で companion diagram の要否を確認する。

図を追加しない判断をする場合は、位置関係が補助的であり、図がなくても主学習目標を損なわない理由を後続ADRまたは関連ADRに記録する。

## Consequences

座標平面上の位置関係を、式と文章だけで頭の中に再構成させる箇所が減り、頂点・軸・交点・定義域・符号などを同じ座標平面で対応付けられる。特に `y=a(x−p)²+q` では、かっこの符号を暗記するのではなく、基準の放物線から頂点がどこへ動くかを図で確認できる。

一方、図の数が増えるため、ラベル衝突、表示範囲、モバイル時の横スクロールを継続して確認する必要がある。図は説明の一部であり装飾ではないため、本文の式や例題を変更した場合は対応する companion diagram の数値・ラベルも同時に更新する必要がある。
