# ADR 0043: 中学1年「一元一次方程式」を8つの技能に分けて構成する

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0041で中学1年数学の縦断実装を開始し、ADR 0042で「文字と式」を1ページ1技能へ分解した。

現行の中学校学習指導要領（平成29年告示）数学第1学年「A 数と式」の方程式では、方程式の必要性と意味及び解の意味、等式の性質を基にした一元一次方程式の解法、一元一次方程式の具体的な場面での活用を扱う。内容の取扱いでは、簡単な比例式を解くことも扱う。

公式解説では、一元一次方程式を `ax + b = cx + d` から `x = k` の形へ変形する過程を、等式の性質と移項を関連付けて理解することが示されている。

これらを一つの教材にまとめると、方程式の意味、等式変形、移項、一般形の解法、比例式、文章題という異なる技能が混在するため、ADR 0001の「1ページ1技能」に合わせて分割する。

## Decision

### 1. 「一元一次方程式」を独立した単元として追加する

中学1年数学の `numbers-expressions` 領域に次の単元を追加する。

```text
linear-equations
```

表示名は「一元一次方程式」とする。

### 2. 単元を8つの小教材に分割する

次の順序で学習する。

1. 方程式と解の意味
2. 等式の性質
3. 加法・減法で方程式を解く
4. 乗法・除法で方程式を解く
5. 移項を使って解く
6. 両辺に文字を含む方程式
7. 比例式を解く
8. 方程式を文章題に利用する

意味理解から等式変形へ進み、その後に一般的な一元一次方程式、比例式、活用へ進む。

### 3. 移項を独立した暗記規則として扱わない

移項は「反対側へ移すと符号が変わる」という手続だけを暗記させず、両辺に同じ数を加減する等式の性質から導かれる変形として扱う。

教材では等式の性質を先に扱い、その後に計算を短く書く方法として移項を導入する。

### 4. 第1学年の範囲に限定する

一元一次方程式 `ax + b = cx + d` を中心とし、連立方程式、二次方程式、不等式の解法は先取りしない。

小数・分数を含む複雑な係数処理は、基本的な一元一次方程式の意味と解法を妨げない範囲で演習へ段階的に追加する。初期教材では整数係数を中心とする。

### 5. 比例式は独立した小教材として扱う

内容の取扱いに基づき、簡単な比例式を一元一次方程式と関連付けて扱う。

外項の積と内項の積が等しい性質を利用し、一元一次方程式へ変形して解く流れを明示する。

### 6. 活用では立式と解の検討を分離して示す

文章題では次の流れを明示する。

1. 求める数量を文字で置く
2. 数量の等しい関係を見つける
3. 方程式を作る
4. 方程式を解く
5. 解が問題の条件に合うか確認する

単なる計算問題との差を明確にし、方程式を使う目的を理解できる構成とする。

### 7. 確認演習を8技能に対応させる

各小教材では3問の確認問題を生成し、単元末演習では8小教材から原則1問ずつ出題する。

採点後の小単元診断と復習リンクは、ADR 0041で導入した中学数学用演習UIを継続利用する。

### 8. 新しい外部依存関係は追加しない

既存のAstro、TypeScript、MathLive、ブラウザ標準APIの範囲で実装する。公開リポジトリに秘密情報、個人情報、外部サービスの認証情報を追加しない。

## Consequences

方程式の意味から文章題までを段階的に学べるため、移項だけを機械的に覚える構成を避けられる。

8小教材と単元末8問を対応させることで、等式の性質、移項、比例式、活用のどこで理解が止まっているかを診断できる。

一方、文字式の同値性や方程式の途中式には複数の正しい表記があるため、確認演習では原則として最終的な解を採点対象とし、途中式の自由入力を必要最小限にする。
