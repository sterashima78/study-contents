# ADR 0029: 静かな編集ノートを基調に集中学習UIへ統一する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0022, ADR 0023, ADR 0028

## Context

既存実装は、トップページ、科目・領域・単元一覧、小単元教材、単元末演習、応用・発展を共通のAstro UIコンポーネントで構成している。教材の構造と学習フローは整理されている一方、従来の緑系アクセント、丸みの大きいカード、広いヒーロー見出し、複数の面表現が重なることで、長時間の読解では教材本文よりUIの存在感が強くなる場面がある。

デザイン検討では「静かな編集ノート / 集中学習モード」を採用候補とした。PCでは広い余白と細い区切り線を使った編集紙面、モバイルでは単一カラムと明確な前後移動を中心にし、学習に必要な情報だけを残す方向である。

一方、現在のサイトには学習時間記録、進捗永続化、お気に入り保存などの状態管理機能は実装されていない。デザイン案だけを理由に存在しない機能を見せると、利用者へ誤った期待を与える。そのため今回の改善は、現在実装済みの情報構造と操作だけを使い、視覚階層、可読性、レスポンシブ挙動を改善する。

## Decision

### 1. 基調を「静かな編集ノート」へ変更する

`StudyPage.astro` が所有するデザイントークンを、白に近い紙色、温かいグレー、低彩度のトープを中心とした配色へ変更する。

- 背景は強いグラデーションを使わず、紙面に近い単色を基本とする
- 境界線は細く、カードの影は原則使わない
- アクセント色は状態や主要操作に限定する
- 大きな角丸や装飾的な面を減らし、本文と数式を主役にする

### 2. 見出しは日本語システムフォントだけで編集紙面らしさを出す

見出しには `Hiragino Mincho ProN`、`Yu Mincho`、`Noto Serif CJK JP` など端末に存在する日本語セリフ系フォントを優先し、本文は既存の日本語サンセリフ系システムフォントを使用する。

外部フォントCDN、Web Font、フォントファイルは追加しない。公開リポジトリで不要な外部通信や配布資産を増やさず、初期表示性能とプライバシーを維持する。

### 3. 現在存在する導線だけを共通ヘッダーへ置く

`StudyPage.astro` に小さな共通ヘッダーを追加し、サイト名、科目一覧へのリンク、このページの先頭へ戻るリンクだけを表示する。

学習記録、お気に入り、通知など未実装の機能は表示しない。状態管理機能を追加する場合は別ADRでデータ保存、プライバシー、アクセシビリティを決定してからUIへ追加する。

### 4. 一覧は「カード」から「編集インデックス」へ寄せる

`ContentIndex.astro` は既存の `grid` / `rows` APIを維持しつつ、角丸、影、高さ固定を弱める。

- 科目一覧は2列を維持し、内容量に応じた自然な高さにする
- 行一覧は番号、タイトル、説明、メタ情報を読み取りやすい順序で見せる
- タグとバッジは低彩度の補助情報として扱う
- 既存URL、項目順、公開数、教材内容は変更しない

### 5. 学習フローと例題・練習は連続した読書体験として整える

`LearningFlow.astro`、`WorkedExample.astro`、`ConceptCard.astro`、`GuidedPractice.astro` などの共通部品は、強い面分割を避け、罫線、余白、番号で構造を示す。

数式、問題文、解法ステップ、入力欄の機能は変更しない。正誤フィードバックには色だけでなく既存のテキストを継続して使う。

### 6. モバイルは単一カラムと前後移動を優先する

760px以下では次を基本とする。

- 学習フローは横方向にスクロールできるコンパクトなステップ列とする
- 一覧は1列にする
- `PageNavigation.astro` は前後移動を優先した2列構成とし、一覧へ戻る導線は下段に置く
- 入力フォームと操作ボタンは十分なタップ領域を保つ

固定ヘッダーや固定フッターで本文領域を過度に狭めない。

### 7. スタイル所有境界は維持する

ADR 0022とADR 0023に従い、各UIの視覚表現は対応するAstroコンポーネントのscoped `<style>` が所有する。新しい共有グローバルCSSは追加しない。

文書ルートの最小スタイルとデザイントークンは引き続き `StudyPage.astro` が所有する。

### 8. 新しい依存関係や外部画像を追加しない

今回の変更はAstroとCSSだけで実装する。UIアイコンライブラリ、外部画像、外部フォント、クライアント状態管理ライブラリは追加しない。

現在の Astro 7.2.9、MathLive 0.110.0、Biome 2.5.11、pnpm 12.0.0 を維持する。

## Consequences

トップページから教材ページまで、同じ低ノイズの紙面表現で連続して学習できる。既存の共通コンポーネントを更新するため、数学、理科、英語、国語、生物を含む現在公開済みの教材へ同じデザイン原則が適用される。

外部フォントや新しいライブラリを追加しないため、依存関係、セキュリティ、配信サイズへの影響は小さい。既存のURL、教材データ、採点処理、学習指導要領参照も維持される。

一方、デザイン案に描かれていた進捗率、学習時間、メモ、お気に入り保存などは今回実装しない。それらを必要とする場合は、永続化方式と個人データの扱いを先に設計する必要がある。
