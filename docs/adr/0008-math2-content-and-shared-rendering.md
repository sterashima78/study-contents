# ADR 0008: 数学IIを既存の科目階層と共通レンダリングへ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0004, ADR 0006, ADR 0007
- Extends: ADR 0007 の科目一覧・科目ホーム構成

## Context

数学Iと数学Aに続き、数学IIの学習コンテンツを追加する。

現行の高等学校学習指導要領では、数学IIの内容は次の5領域で構成される。

- いろいろな式
- 図形と方程式
- 指数関数・対数関数
- 三角関数
- 微分・積分の考え

既存サイトは ADR 0007 により「科目一覧 → 科目 → 領域 → 単元 → 小単元」の階層を採用し、数学Iと数学Aは `MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` を共有している。

数学IIでもこの構造を維持し、科目追加のたびに表示コンポーネントを複製しないことが必要である。また ADR 0002 の確認演習、ADR 0003 の公式導出を数学IIにも適用する必要がある。

## Decision

### 1. 数学IIは5領域・10単元・25小教材で公開する

`src/content/math2/` に教材データを配置し、学習指導要領の5領域を `math2Areas` として定義する。

各領域は2単元に分け、合計25の小教材を1ページ1技能で構成する。

教材ページは既存科目と同様に、次の流れを持つ。

1. 学習目標
2. 考え方・ルール
3. 公式の導出または根拠
4. 例題
5. 直後の誘導付き練習
6. 3問の確認演習
7. まとめ

### 2. URLは `/math2/` 以下に既存科目と対称に配置する

数学IIのURL階層を次とする。

```text
/math2/
/math2/{area}/
/math2/{area}/{unit}/
/math2/{area}/{unit}/{lesson}/
/math2/{area}/{unit}/exercise/
```

トップページ `/` の科目一覧へ数学IIを追加し、数学IIの科目ホームからは `/` の科目一覧へ戻る。

数学I・数学Aの既存URLは変更しない。

### 3. 表示コンポーネントは既存の共通実装を再利用する

数学II専用の教材表示コンポーネントは作らず、次を再利用する。

- `MathAreaIndex`
- `MathUnitIndex`
- `MathLesson`
- `MathUnitExercise`
- `ExerciseSet`

`MathCourseInfo` に `math2` を追加し、科目名、ルート、科目ホームだけを科目データとして渡す。

### 4. 演習生成は既存レジストリのフォールバックとして接続する

`ExerciseSet` の表示実装を複製しないため、既存の演習レジストリで数学Iの単元・追加単元に一致しない場合に数学IIの演習レジストリへフォールバックする。

数学IIでは各小教材に3問の確認問題プールを持ち、単元末演習では単元内の問題を混ぜて16問を構成する。

難易度の配分は既存仕様と同じく次とする。

- 基礎 12問
- 応用 3問
- 難問 1問

採点後の小単元別診断と復習リンクは既存の `ExerciseSet` をそのまま利用する。

### 5. 公式導出のCI検証を数学IIへ拡張する

`formulas` を持つ数学IIの小教材は、`src/content/math2/formula-derivations.ts` に対応する導出または根拠を持たせる。

`scripts/verify-formula-coverage.mjs` の検査対象へ数学IIの教材ファイルと導出ファイルを追加し、ADR 0003 の分類漏れ検出を数学IIにも適用する。

公式表示の取得は既存の共通レジストリから数学IIの導出へフォールバックする。

### 6. 生成HTML検証を数学IIにも追加する

既存の数学I・数学Aの生成HTML検証は変更せず、`scripts/verify-math2-build-output.mjs` を追加する。

次を検証する。

- トップページに数学IIへの導線がある
- `/math2/` に5領域・25小教材が表示される
- 代表的な式・三角関数・積分教材が生成される
- 公式導出が表示される
- 単元末演習ページが生成される

CIとデプロイの両方で既存検証に続けて数学II検証を実行する。

### 7. 教材データのBiome整形方針は数学Aと同じにする

数学Aの大規模教材データと同様に、`src/content/math2/**/*.ts` はBiomeのフォーマッター対象外とする。

リントは引き続き有効とし、手作業で整形された教材データの大規模な機械整形を避ける。

## Consequences

数学IIがトップページから独立した科目として選択でき、5領域すべてを既存と同じ学習体験で利用できる。

共通コンポーネントを複製しないため、数学Bなどを追加する際も同じ階層とレンダリング方式を拡張できる。

一方、演習・公式の共通レジストリは歴史的に `math1` 配下にあるため、数学IIはフォールバックとして接続される。今後さらに科目が増えてレジストリの責務が大きくなった場合は、科目非依存の共有レジストリへ移動するADRを別途検討する。
