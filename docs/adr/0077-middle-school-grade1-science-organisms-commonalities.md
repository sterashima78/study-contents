# ADR 0077: 中学1年「いろいろな生物とその共通点」を外部形態と分類技能で実装する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0075, ADR 0076

## Context

中学1年理科は第1分野（1）「身近な物理現象」と（2）「身の回りの物質」まで公開した。次は第2分野（1）「いろいろな生物とその共通点」を実装する。

現行の中学校学習指導要領解説 理科編では、この内容について、身近な生物の観察、観察器具と記録、共通点・相違点に基づく分類、植物と動物の外部形態による分類を扱う。分類は学問上の系統分類を暗記させることではなく、観察や資料から見いだした観点と基準を用いることが重視されている。

また、植物では被子植物・裸子植物、単子葉類・双子葉類、胞子をつくる植物に触れ、動物では脊椎動物・無脊椎動物、脊椎動物の五つの仲間、節足動物・軟体動物を中心に扱う。

## Decision

- 中学1年理科に `life` 領域を追加し、単元キーを `organisms-commonalities` とする。
- 単元は12技能に分ける。
  - 生物を観察する観点
  - 観察器具と観察記録
  - 分類の観点と基準
  - 植物の基本的なつくりと花
  - 被子植物と裸子植物
  - 単子葉類・双子葉類と胞子
  - 脊椎動物と無脊椎動物
  - 脊椎動物の五つの仲間
  - 節足動物
  - 軟体動物
  - 未知の生物の分類
  - 分類表・検索表
- 分類問題は、名称の暗記だけでなく「観察できる特徴 → 分類基準 → 結論」の順で根拠を示す構成にする。
- 植物と動物は主に外部形態を扱い、体の働き、受精の詳細、進化は後続学年の内容へ残す。
- `life-catalog.ts`、`life-exercise-registry.ts`、`life-diagrams.ts` を専用ファイルとして追加し、Grade 1 の共通resolverから合成する。
- 各教材の確認問題は3問、単元末演習は8問とし、既存の中1理科UIを再利用する。
- Diagramは既存の型付きDiagram APIだけを使用し、観察観点、分類木、花、植物分類、脊椎動物、無脊椎動物、検索表を模式図で表現する。
- 生きた生物の採集、解剖、薬品処理などを再現させる手順は教材化しない。観察結果・模式図・静的な資料の読み取りを中心とする。
- 実在する生徒、学校、観察記録などの個人情報は使用しない。
- 外部API、新規依存関係、package/lock、Study AI runtime/model設定は変更しない。

## Consequences

- 中学1年理科は「エネルギー」「粒子」「生命」の3領域が公開される。
- 生物分類を暗記表ではなく比較・分類技能として学べる。
- 既存の共通ルートをそのまま使うため、生命領域専用のページルート追加は不要になる。
- 次の自然な拡張は第2分野（2）「大地の成り立ちと変化」となる。
