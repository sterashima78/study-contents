# ADR 0091: 中学3年「科学技術と人間」「自然と人間」を4領域横断で統合する

- Status: Accepted
- Date: 2026-09-02
- Related: ADR 0086, ADR 0088, ADR 0089, ADR 0090

## Context

中学校学習指導要領（平成29年告示）解説 理科編の第3学年第1分野（7）「科学技術と人間」は、エネルギーとエネルギー資源、様々な物質とその利用、科学技術の発展、自然環境の保全と科学技術の利用を扱う。内容の取扱いでは、エネルギー変換と保存・効率、熱の伝わり方、放射線の性質と利用、天然・人工の物質、プラスチックなどを扱うことが示されている。

同じく第2分野（7）「自然と人間」は、自然界のつり合い、自然環境の調査と環境保全、地域の自然災害、自然環境の保全と科学技術の利用を扱う。生産者・消費者・分解者、微生物と物質循環、気候変動、外来生物、地域の災害記録などを関連付けて考察することが求められる。

さらに解説は、第1分野（7）と第2分野（7）の「自然環境の保全と科学技術の利用」を関連付けて総合的に扱い、持続可能な社会をつくるために科学的な根拠を基に考察・判断することを求めている。

既存の中学理科は、学年を通して `energy`、`particles`、`life`、`earth` の4領域で構成している。第3学年だけに第5の「総合」領域を追加すると、学年間の構造が崩れ、科学技術・環境問題が既習の科学概念から分離される。したがって、（7）の内容を既存4領域へ配置し、最終的に4領域を横断する判断技能へ収束させる必要がある。

また、放射線や自然災害は安全性の高い扱いが必要である。放射線は性質・利用・管理の概念に限定し、放射線源の取扱いや個人の線量判断を扱わない。自然災害は過去記録や架空資料の分析に限定し、現在の警報・避難・行動判断には静的教材を利用しない。

## Decision

1. 第1分野（7）と第2分野（7）のための第5領域は新設せず、既存4領域へ横断単元を追加する。
2. `energy` に「エネルギー資源と科学技術」6技能を追加し、エネルギー変換、保存と効率、熱伝導・対流・放射、エネルギー資源、放射線、科学技術の発展を扱う。
3. `particles` に「物質の利用と資源」4技能を追加し、天然・人工材料、プラスチック、再使用・再生利用、材料のライフサイクルを扱う。
4. `life` に「生物と環境」6技能を追加し、生産者・消費者・分解者、食物網、微生物と物質循環、環境調査、気候変動、外来生物と環境保全を扱う。
5. `earth` に「自然と人間・持続可能な社会」5技能を追加し、地域災害、自然の恵みと災害、科学技術のトレードオフ、複数根拠による比較、持続可能な社会の提案を扱う。
6. 合計21教材とし、最後の技能ではエネルギー・物質・生命・地球の根拠を統合する。科学的に確認できる事実、データの不確かさ、何を重視するかという価値判断を区別して提示する。
7. Diagramは既存の型付き `DiagramScene` APIだけを利用する。新規描画ライブラリ、任意SVG/HTML、外部可視化APIは導入しない。
8. 演習は各教材3問、単元末8問とし、静的またはブラウザ内生成の架空データ、過去資料を想定した設問だけを利用する。
9. 放射線は自然界での存在、性質、利用、専門的管理の必要性を概念的に扱う。放射線源を扱う実験手順、個人の被ばく線量評価、安全可否の判断は提供しない。
10. 自然災害は過去の記録・地形・地質・気象資料を関連付けて分析する。現在の警報、避難、災害対応については、気象庁・自治体などの最新の公的情報を優先することを教材で明示する。
11. 実在生徒のデータ、個人情報、位置情報、秘密情報を収集せず、外部APIや分析SDKを追加しない。
12. `package.json`、lockfile、Study AI runtime/model設定は変更しない。

## Consequences

- 中学3年の第1分野（5）〜（7）、第2分野（5）〜（7）がそろい、中学1〜3年理科の学習指導要領上の主要内容を4領域構成のまま完結できる。
- エネルギー・物質・生態系・地球環境を別々の知識として終わらせず、持続可能な社会の課題へ横断的に適用できる。
- 科学的事実と価値判断を区別することで、単一の「正解」を押し付けず、根拠・限界・別の観点を明示した提案を学べる。
- 放射線や自然災害の危険な再現・個別判断を避け、安全境界を保ったまま学習指導要領の内容を扱える。
- 中学理科完成後は、全学年の完成監査または中学英語への展開が次の自然な候補となる。
