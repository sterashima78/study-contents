# ADR 0078: パブリックドメイン候補は物語・説明・論説・随筆を偏りなく選定する

- Status: Accepted
- Date: 2026-09-01
- Supersedes: ADR 0074
- Related: ADR 0001, ADR 0025, ADR 0026, ADR 0073

## Context

ADR 0074 では、パブリックドメイン作品を知名度ではなく、5〜10分の教材粒度と作問可能性を基準に選定する方針を採用した。この方針自体は妥当だが、初期候補6作品のうち、国語2作品と英語3作品が物語・寓話・短編小説であり、読解技能が人物、時系列、伏線、認識差、象徴などへ偏っていた。

国語・英語の学習では、物語文だけでなく、説明文、論説、随筆、演説などで、定義、具体例、因果、対比、主張と根拠、段落の役割、要約を読む技能も必要である。

したがって、作品単体の作問可能性だけでなく、候補集合全体のジャンル分布と読解技能の分布を選定条件に加える。

## Decision

### 1. 候補集合全体でジャンルを分散する

初期候補は引き続き国語3作品、英語3作品の計6作品に限定する。ただし、6作品中の物語系は最大2作品までとする。

候補集合には、少なくとも次の3系統を含める。

- 物語・文学的文章
- 説明・観察・科学的文章
- 論説・随筆・演説など、主張と根拠を持つ文章

古文については、現代文とは別の文法・読解技能が必要なため、国語3作品のうち1作品を古典作品に割り当てる。

### 2. 作問可能性の条件はADR 0074から維持する

各候補は、原則として次の短い連続区間で教材化できるものに限定する。

- 現代文・古文: おおむね350〜900字
- 英語: おおむね250〜550語
- 英語の発展長文でも上限の目安を800語とする

区間から、語句・文法、照応、文章構造、内容一致、推論、要約、表現効果などのうち3種類以上の設問を、本文根拠を明示して作れることを要求する。

### 3. 国語の候補を説明・論説・古典へ再構成する

初期候補は次の3作品とする。

1. 寺田寅彦「茶わんの湯」
   - 分類: 科学的説明・随筆
   - 利用候補区間: 茶わんの湯気を観察し、雲や霧との共通性を説明する冒頭付近
   - 主な学習: 観察事実と説明の区別、具体例、因果、指示語、段落の役割、要約
   - 制限: 科学知識を暗記させる問題ではなく、本文がどの観察からどの説明へ進むかを読む教材にする
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000042/card2363.html

2. 夏目漱石「現代日本の開化」
   - 分類: 講演・論説
   - 利用候補区間: 「開化」の定義を置き、一般的な開化と日本の開化を対比する論理が追える連続区間
   - 主な学習: 定義、問いと答え、対比、主張と根拠、具体例、要約
   - 制限: 当時の日本社会に関する評価そのものへの賛否を正答にせず、本文内の論理構造を主対象にする
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000148/card759.html

3. 鴨長明『方丈記』
   - 分類: 古典随筆
   - 利用候補区間: 冒頭の「ゆく河の流れは絶えずして」から始まる短い区間
   - 主な学習: 古語、係り受け、対比、比喩、反復、内容対応
   - 制限: 現代語訳は外部訳を転載せず教材側で独自作成する
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000196/card975.html

これにより、国語の初期候補では現代小説をあえて外し、既存のオリジナル教材で扱える物語読解より、実在文章を使う価値が高い説明・論説・古典の読解を優先する。

### 4. 英語の候補を物語・演説・論説へ再構成する

初期候補は次の3作品とする。

4. Oscar Wilde, “The Selfish Giant”
   - 分類: 物語・寓話
   - 利用候補区間: 子どもが庭で遊ぶ導入から、巨人が壁を築き、庭に冬が残る因果が成立する連続区間
   - 主な学習: 時系列、代名詞、修飾、因果、対比、要約
   - 制限: 全編ではなく250〜550語程度を基本とする
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/902

5. Abraham Lincoln, “Gettysburg Address”
   - 分類: 演説・論説
   - 利用候補区間: 全文約271語を候補とする
   - 主な学習: 指示語、反復、対比、段落ごとの役割、主張と根拠、要約
   - 制限: 米国史の事前知識を正答条件にせず、必要な歴史背景は教材側の短い独自説明として分離する
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/4

6. Francis Bacon, “Of Studies”
   - 分類: 随筆・論説
   - 利用候補区間: “Of Studies” 全体または250〜550語の連続区間
   - 主な学習: 並列、対比、主張と限定、比喩、言い換え、要約
   - 制限: 初期近代英語の語彙・綴り・構文があるため発展教材候補とし、現代英語への書き換えを原文として扱わない
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/575

### 5. 外した作品は候補台帳から削除する

ADR 0074で候補にした次の作品は、作品の価値や権利状態を否定するのではなく、初期候補集合の物語偏重を解消するため候補台帳から外す。

- 夏目漱石『夢十夜』
- 宮沢賢治『注文の多い料理店』
- O. Henry, “After Twenty Years”
- Saki, “The Open Window”

将来、物語文の実作品教材を拡充する段階では再候補化できる。

### 6. 権利承認は引き続き別工程とする

このADRで選定した6作品はすべて `candidate` とする。日本国内での権利状態、底本の編集部分、電子版固有部分、外国作品の戦時加算等はADR 0073に従って個別に確認し、`approved` になるまで教材本文へ取り込まない。

## Consequences

候補集合全体で、物語読解だけでなく、観察から説明する文章、定義と対比で論を進める文章、演説、古典随筆を扱える。作問も人物・時系列中心から、定義、段落構成、主張と根拠、具体例、要約へ広がる。

一方、初期候補から現代日本語の物語作品がなくなる。これは物語文を不要とする判断ではなく、既存のオリジナル教材でも比較的作りやすい物語文より、実在文章を用いる効果が大きい非物語文を初期の外部文章導入で優先するためである。
