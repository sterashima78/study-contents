# ADR 0092: 中学1年英語を基本文16技能から開始する

- Status: Accepted
- Date: 2026-09-02
- Related: ADR 0025, ADR 0033, ADR 0039, ADR 0073, ADR 0091

## Context

中学校学習指導要領（平成29年告示）解説 外国語編では、英語の音声・文字・語彙・表現・文構造・文法事項を、聞くこと、読むこと、話すこと［やり取り］、話すこと［発表］、書くことの五つの領域の目標と関連付け、実際のコミュニケーションの中で活用できるようにすることを求めている。

文及び文構造では、単文、肯定・否定の平叙文、命令文、be動詞・助動詞・疑問詞で始まる疑問文、主語＋be動詞＋名詞／代名詞／形容詞、主語＋動詞＋目的語などを扱う。文法事項には代名詞、助動詞、前置詞、現在・過去・進行形・現在完了等の時制及び相、比較、不定詞、動名詞、分詞、受け身、基本的な仮定法などが含まれる。

一方、学習指導要領はこれらの文法事項を第1学年・第2学年・第3学年へ一律に固定配当していない。したがって本サイトで学年別教材を作る場合、学年配当はサイト上の学習順序であり、公式資料の厳密な学年別配当であるかのように表示しない必要がある。

既存の高校英語は `EnglishArea` / `EnglishUnit` / `EnglishLesson` と専用Astroコンポーネントを持つ。中学英語のために別の表示基盤を複製すると、権利表示、回答入力、学習指導要領参照、レスポンシブUIが分岐するため、英語専用基盤をコース情報で共通化する方が整合的である。

## Decision

1. コースキー `middle-english1`、ルート `middle-school/english/grade1` を追加する。
2. 最初の領域を `foundations`「基本文とやり取り」とし、「be動詞の基本文」8技能、「一般動詞の現在形」8技能の計16教材で公開する。
3. be動詞は I / you、he / she / it、we / they、否定、疑問、短い答え、what / who / where、短い自己紹介に分ける。
4. 一般動詞は I / you の現在形、三人称単数現在、do / does の否定、do / does の疑問、疑問詞、日常のまとまり表現に分ける。
5. 文法名称の暗記だけを目的にせず、自分・相手・身近な人の日常を伝える、尋ねる、短く答えるという意味のある文脈で反復する。
6. 各教材は例題直後の誘導練習に加え、独立した確認3問を持つ。各単元は8問の単元末演習と小単元別診断を持つ。
7. 中学英語の学年配当は本サイト独自の段階配置であることを公開ページと学習指導要領参照に明記する。3学年全体では中学校外国語の言語材料と五つの領域へ段階的に広げる。
8. 例文・設問・短い英文はすべて本リポジトリ向けのオリジナルとし、教科書、市販問題集、入試問題、記事本文を転載しない。承認済みパブリックドメイン作品も今回のPRでは使用しない。
9. 既存の高校英語コンポーネントを `scopeLabel`、`curriculumKey`、単元末演習有無などのコース情報で汎用化し、高校英語の既存URLと教材内容は変更しない。
10. リスニング音声は、音声資産、字幕、再生UI、アクセシビリティ、権利の設計が必要なため今回導入しない。聞くことの実装は別ADRで扱う。
11. `package.json`、lockfile、Study AI runtime/model、外部API、分析SDK、外部フォントを変更・追加しない。秘密情報、個人情報、位置情報を収集しない。

## Consequences

- 中学数学・中学理科に続き、中学英語の公開を開始できる。
- 小学校で触れた基本表現を、中学校で語順と文法の知識として整理しながら再利用できる。
- 高校英語と中学英語が同じ英語専用UIを共有し、表示・権利・学習指導要領参照の重複実装を避けられる。
- 第2段階では can、命令文、現在進行形、過去形、接続表現などへ広げる必要がある。
- 音声を伴う「聞くこと」は未実装であり、現時点の教材は読む・書く・やり取りに必要な基礎文を中心とする。
