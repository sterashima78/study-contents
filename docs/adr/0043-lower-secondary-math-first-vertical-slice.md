# ADR 0043: 中学数学は中学1年「正の数・負の数」の縦断実装から開始する

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0039で、中学生向け教材の初期対象を数学・理科・英語とし、実装は中学数学から開始することを決定した。

既存サイトは高等学校の科目をトップレベルのコースとして扱い、`MathCourseInfo`、`CourseHome`、`MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` などの共通部品で教材を表示している。一方、中学校では学校段階、教科、学年を学習導線として明示する必要があり、学習指導要領も高等学校とは異なる。

全3学年の全単元を先に追加すると、ルーティング、学年情報、学習指導要領参照、演習、ナビゲーションの問題を大量の教材データに埋もれさせる可能性がある。そのため、まず1単元を教材ページから演習まで縦断して実装し、基盤の妥当性を確認してから範囲を広げる。

## Decision

### 1. 最初の縦断実装を中学1年「正の数・負の数」とする

中学1年数学の「A 数と式」のうち「正の数・負の数」を最初の公開単元とする。

初期実装では次の小教材を用意する。

- 正の数・負の数の意味
- 数直線と絶対値
- 正の数・負の数の加法
- 正の数・負の数の減法
- 正の数・負の数の乗法
- 正の数・負の数の除法

各小教材はADR 0001の「1ページ1技能」を維持し、目標、考え方、例題、例題直後の練習、確認問題、まとめを持つ。

### 2. 中学校のURLは学校段階・教科・学年を明示する

中学1年数学の基準URLを次とする。

```text
/middle-school/math/grade1/
```

その下に既存の教材粒度を配置する。

```text
/middle-school/math/grade1/{area}/{unit}/{lesson}/
```

トップページからは次の導線を提供する。

```text
/
→ /middle-school/
→ /middle-school/math/
→ /middle-school/math/grade1/
```

既存の高校科目URLは変更しない。

### 3. 既存の数学表示コンポーネントを学校段階に依存しない形へ一般化する

中学数学専用にページ表示コンポーネント一式を複製しない。

`MathCourseInfo` に必要な表示・参照メタデータを追加し、既存の `CourseHome`、`MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` を中学数学でも利用する。

高校を前提とした説明文は、コースごとの `scopeLabel` を利用して学校段階に応じた表現へ切り替える。

### 4. 学習指導要領参照はコースキーとURLの配置を分離する

中学1年数学は内部識別子として `middle-math1` を使用するが、実際のページは `middle-school/math/grade1` に配置する。

`curriculum-references.js` の参照情報に必要に応じて `routeBase` を持たせ、学習指導要領の識別キーと生成HTMLの配置を分離する。

`StudyPage.astro` はネストしたURLでも正しい参照情報を表示できるよう、明示的な `curriculumKey` を受け取れるようにする。

検証スクリプトは `routeBase` を認識し、中学校のネストしたルートについてもソースと生成HTMLを検証する。

### 5. 中学数学の確認演習は独立した小さな演習レジストリから開始する

高校数学の演習ジェネレータは高校の単元キーや数式入力を前提としているため、中学1年「正の数・負の数」の問題を無理に高校数学レジストリへ混在させない。

初期実装では `src/content/middle-school/math/grade1/exercise-registry.ts` と `MiddleMathExerciseSet.astro` を用意し、次を実現する。

- 各小教材の確認3問
- 単元末の8問
- 問題の再生成
- 自動採点
- 小単元ごとの診断
- 不正解小単元への復習リンク

演習UIのスタイルは既存の `styles/exercise.css` を再利用し、新しい外部依存関係は追加しない。

中学数学の範囲が広がり、高校数学との演習基盤の共通部分が十分明確になった段階で、共通化を別途検討する。

### 6. 中学校の学習指導要領は現行の平成29年告示を参照する

中学1年数学は、文部科学省の「中学校学習指導要領（平成29年告示）」および「中学校学習指導要領（平成29年告示）解説 数学編」を公式参照先とする。

審議中の次期学習指導要領案は教材範囲の根拠として先取りしない。

### 7. 新しいライブラリは追加しない

今回の実装は既存のAstro、TypeScript、ブラウザ標準API、既存CSSだけで構成する。

公開リポジトリであることを前提とし、教材・演習データ・設定・ADRに秘密情報や個人情報を含めない。

## Consequences

中学生向け教材のための学校段階・教科・学年の導線と、既存の1ページ1技能の教材構造を同時に確認できる。

最初の教材範囲は「正の数・負の数」に限定されるが、ルーティング、教材表示、練習、自動採点、診断、学習指導要領参照まで一通り実装されるため、次の単元をデータ中心で追加しやすくなる。

中学2年・3年、中学理科、中学英語はまだ未実装である。中学数学1年の残りの領域を追加しながら共通化の境界を確認し、その後ADR 0039の順序に従って対象を広げる。
