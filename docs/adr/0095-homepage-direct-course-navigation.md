# ADR 0095: トップページから中学教科と高校科目へ直接進める

- Status: Accepted
- Date: 2026-09-03
- Related: ADR 0007, ADR 0024, ADR 0030, ADR 0071, ADR 0091, ADR 0093
- Supersedes: ADR 0071 の Decision 1 のトップページ導線

## Context

中学校教材の公開開始時は、トップページに「中学校」カードを1枚置き、`/middle-school/` で数学・理科・英語を選ぶ構成としていた。一方、高校教材はトップページから数学I、物理、英語など各科目へ直接進める。

その後、中学数学・中学理科・中学英語はいずれも1〜3年まで公開済みとなり、中学校だけが「学校段階 → 教科 → 学年」、高校は「科目 → 領域」という非対称な入口になった。また、トップページの中学校カードは中学3年理科と中学英語を教材数集計に含めておらず、公開状態とのずれも生じていた。

ADR 0007が定めた「トップページを教材選択の入口とする」考え方と、ADR 0030が定めたコンパクトな教材一覧の方針を維持しつつ、学校段階による不要な1遷移を減らす必要がある。

## Decision

### 1. 中学校はトップページから教科へ直接進める

トップページの中学校セクションには、次の3教科を独立したカードとして表示する。

- 中学数学 → `/middle-school/math/`
- 中学理科 → `/middle-school/science/`
- 中学英語 → `/middle-school/english/`

各カードの教材数は1〜3年のカタログから動的に集計し、トップページ固有の固定値を持たない。

### 2. `/middle-school/` は学校段階の案内ページとして維持する

既存の `/middle-school/` は削除・移動しない。トップページでは主要導線ではなく「中学校の教材全体を見る」という補助導線として残す。

これにより既存URL、外部リンク、各教科ページから学校段階へ戻るナビゲーションを壊さない。

### 3. 高校は直接導線を維持し、教科系統でグルーピングする

高校科目は新しい学校段階ページを経由させず、トップページから各科目へ直接進める。科目数が多いため、次の4系統に分けて表示する。

- 高校数学: 数学I・A・II・B・III・C
- 高校理科: 物理基礎・物理・化学基礎・化学・生物基礎・生物
- 地歴・公民: 日本史・世界史・倫理
- 国語・英語: 国語・英語

科目ホーム以下のURLとナビゲーションは変更しない。

### 4. トップページは「何を学ぶか」を最初の選択軸にする

学校段階そのものを選ぶカードではなく、学びたい教科・科目を選ぶカードを主要導線とする。中学校では教科選択後に学年を選び、高校では科目選択後に領域・単元へ進む。

### 5. 生成HTML検証で中学3教科への直接導線を固定する

既存の中学数学生成HTML検証を拡張し、トップページに次のリンクと教科名が含まれることを確認する。

- `middle-school/math/`
- `middle-school/science/`
- `middle-school/english/`

既存の高校教材生成HTML検証、各中学教科・学年ページ、教材ページの検証は維持する。

### 6. 依存関係は変更しない

今回の変更はAstroテンプレート、既存UIコンポーネント、ADR、生成HTML検証だけで実装する。新しいライブラリ、外部サービス、画像、外部フォントは追加しない。

ADR 0005の最新版確認・固定方針は継続する。本変更ではライブラリAPIを変更せず、依存関係更新を伴わない。

## Consequences

- 中学数学・中学理科・中学英語へトップページから1クリックで到達でき、高校科目と入口の粒度が揃う。
- 高校17科目は教科系統ごとに分かれるため、1つの長い科目一覧より走査しやすくなる。
- `/middle-school/` と既存教材URLを維持するため、ブックマークや外部リンクへの影響はない。
- 中学教材数をカタログから集計することで、公開教材追加後にトップページだけ古い数値が残るリスクを下げる。
- トップページのセクション数は増えるが、ADR 0030のcompact表示を継続して画面占有を抑える。

## Security and privacy

- 公開リポジトリへ秘密情報、認証情報、個人情報を追加しない。
- 外部通信、ユーザー入力、ユーザーデータ保存を追加しない。
- 変更対象は静的なナビゲーションと教材カタログ集計のみで、Study AIのruntime・モデル・権限境界は変更しない。
