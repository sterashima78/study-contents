# ADR 0088: 中学3年「化学変化とイオン」を2単元15技能で実装する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0083, ADR 0086

## Context

中学校学習指導要領（平成29年告示）解説 理科編の第3学年第1分野（6）「化学変化とイオン」は、「水溶液とイオン」と「化学変化と電池」を扱う。

「水溶液とイオン」では、電解質と非電解質、原子核と電子、イオンの生成、代表的なイオン式、電気分解の結果、酸・アルカリと水素イオン・水酸化物イオン、pH、中和と塩を関連付ける必要がある。中和はH⁺とOH⁻が反応する現象であり、中和反応が起きたことと水溶液が必ず中性になることは区別する必要がある。

「化学変化と電池」では、金属によるイオンへのなりやすさの違い、金属原子・金属イオンと電子の授受、ダニエル電池の電極変化と電子移動、化学エネルギーから電気エネルギーへの変換を関連付ける。乾電池、蓄電池、燃料電池など社会で使われる代表例にも触れる。

一方、電気分解や電池、酸・アルカリの実験は、薬品、電極、電源、廃液を扱う。公開学習サイトで具体的な薬品量、濃度、印加電圧、電極の作製・組立て、廃棄処理を手順化すると、安全管理や設備条件を外した再現を促すおそれがある。そのため、教材は観察結果、粒子モデル、模式図、架空データの解釈を中心にする。

## Decision

1. 中学3年理科コース `middle-science3` に領域 `particles` を追加する。
2. 「水溶液とイオン」を9技能、「化学変化と電池」を6技能とし、合計15教材で構成する。
3. 「水溶液とイオン」は、電解質/非電解質、原子の構造、イオン生成、イオン式、電気分解とイオン移動、酸/アルカリとイオン、pH、中和の粒子モデル、塩の順で学ぶ。
4. 原子は原子核と電子、原子核は陽子と中性子からなることを扱い、同位体には存在を知る範囲で触れる。
5. イオン式は代表的なものを粒子モデルと対応させる技能として扱い、網羅的な暗記を目的にしない。
6. 中和は `H⁺ + OH⁻ → H₂O` を中心に扱い、「中和が起きた = 必ずpH7」という誤解を明示的に避ける。
7. 「化学変化と電池」は、金属のイオンへのなりやすさ、電子授受、ダニエル電池、電極反応と電子の流れ、エネルギー変換、社会の電池利用の順で学ぶ。
8. ダニエル電池は `Zn → Zn²⁺ + 2e⁻` と `Cu²⁺ + 2e⁻ → Cu` を模式図で結び付け、電子が亜鉛側から銅側へ移動することを理解する教材とする。
9. Diagramは既存の型付き `DiagramScene` APIのみを利用する。任意SVG/HTML、新規描画ライブラリ、外部APIは導入しない。
10. 演習は各教材3問、単元末8問とし、静的またはブラウザ内生成の架空データだけを用いる。
11. 酸・アルカリ、電気分解、電池について、薬品量・濃度、印加電圧、加熱条件、電極の作製・組立て、廃液処理など、再現可能な実験手順は掲載しない。観察結果と粒子モデルの読解に限定する。
12. 使用済み電池の扱いは製品表示や自治体の最新ルールに従うものとし、静的教材で具体的な廃棄方法を固定しない。
13. Grade3の拡張に備え、既存の「運動とエネルギー」のカタログ・Diagram・演習を領域別ファイルへ内容を変えず分離し、共通入口で領域を合成する。
14. `package.json`、lockfile、Study AI runtime/model設定は変更しない。個人情報、位置情報、秘密情報、分析SDKも追加しない。

## Consequences

- 中学3年理科でエネルギー領域に続いて粒子領域を公開できる。
- 中2の原子・分子から、中3の原子構造・イオン・電子移動へ段階的につなげられる。
- 酸・アルカリ、中和、電池を暗記ではなく粒子と電子のモデルで説明できる。
- 危険な実験条件を公開せず、観察結果や模式図から科学的に考察する学習へ集中できる。
- Grade3の生命・地球・科学技術領域を、領域別ファイル追加で拡張できる。
