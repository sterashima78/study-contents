# ADR 0010: 数学IIを既存の科目階層と共通レンダリングへ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0004, ADR 0006, ADR 0007, ADR 0008, ADR 0009
- Extends: ADR 0007 の科目一覧・科目ホーム構成

## Context

数学I・数学A・数学B・数学Cに続き、数学IIの学習コンテンツを追加する。

現行の高等学校学習指導要領では、数学IIの内容は次の5領域で構成される。

- いろいろな式
- 図形と方程式
- 指数関数・対数関数
- 三角関数
- 微分・積分の考え

既存サイトは ADR 0007 により「科目一覧 → 科目 → 領域 → 単元 → 小単元」の階層を採用し、科目共通の表示・演習基盤を利用している。数学IIでもこの構造を維持し、ADR 0002 の確認演習と ADR 0003 の公式導出方針を適用する。

このリポジトリは公開されているため、教材データに秘密情報や個人情報を含めず、回答や学習履歴を外部へ送信する仕組みも追加しない。

## Decision

### 1. 数学IIは5領域・10単元・25小教材で公開する

`src/content/math2/` に教材データを配置し、次の5領域を `math2Areas` として定義する。

- いろいろな式
- 図形と方程式
- 指数関数・対数関数
- 三角関数
- 微分・積分の考え

各領域は2単元に分け、合計25の小教材を1ページ1技能で構成する。

教材ページは既存科目と同様に、学習目標、考え方、公式の導出または根拠、例題、誘導付き練習、3問の確認演習、まとめを持つ。

### 2. URLは `/math2/` 以下に既存科目と対称に配置する

数学IIのURL階層を次とする。

```text
/math2/
/math2/{area}/
/math2/{area}/{unit}/
/math2/{area}/{unit}/{lesson}/
/math2/{area}/{unit}/exercise/
```

トップページ `/` の科目一覧へ数学IIを追加し、科目順は「数学I、数学A、数学II、数学B、数学C」とする。既存科目のURLは変更しない。

### 3. 表示コンポーネントは既存の共通実装を再利用する

数学II専用の教材表示コンポーネントは作らず、`MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise`、`ExerciseSet` を再利用する。

`MathCourseInfo` に `math2` を追加し、科目名、ルート、科目ホームを科目データとして渡す。

### 4. 演習生成は既存レジストリへ数学IIを追加する

数学Bが利用している既存の共通演習レジストリ構成を維持し、数学Bの専用単元を先に判定した後、数学I系・数学A系の生成器に該当しない場合に数学IIの演習レジストリへフォールバックする。

数学IIでは各小教材に3問の確認問題プールを持ち、単元末演習では単元内の問題を混ぜて16問を構成する。難易度は基礎12問、応用3問、難問1問とする。

採点、再出題、弱点診断は既存UIを利用し、ブラウザ内で完結させる。

### 5. 公式導出のCI検証を数学IIへ拡張する

`formulas` を持つ数学IIの小教材は、`src/content/math2/formula-derivations.ts` に対応する導出または根拠を持たせる。

`scripts/verify-formula-coverage.mjs` の検査対象へ数学IIの教材ファイルと導出ファイルを追加し、数学I・数学A・数学II・数学B・数学Cを同じ検査で確認する。

公式表示の取得は既存の共通レジストリから数学Bの導出を保持したうえで数学IIの導出へフォールバックする。

### 6. 生成HTML検証を数学IIにも追加する

既存の数学I・数学A・数学B・数学Cの生成HTML検証は保持し、`scripts/verify-math2-build-output.mjs` を追加する。

次を検証する。

- トップページに数学IIへの導線がある
- `/math2/` に5領域・25小教材が表示される
- 代表的な式・三角関数・積分教材が生成される
- 公式導出が表示される
- 単元末演習ページが生成される

CIとデプロイの両方で既存検証に続けて数学II検証を実行する。

### 7. 教材データのBiome整形方針は既存の大規模教材と揃える

`src/content/math2/**/*.ts` は数学A・数学B・数学Cの教材データと同様にBiomeのフォーマッター対象外とする。リントは引き続き有効とする。

### 8. 依存関係の最新版を維持する

教材追加のための新規依存関係は導入しない。2026-08-29時点で Astro `7.2.9`、MathLive `0.110.0`、Biome `2.5.10` を維持し、pnpm は同日に公開された安定版 `12.0.0` へ更新する。

`packageManager`、CI、デプロイのpnpm指定を同じ `12.0.0` に揃え、ADR 0005も更新する。

## Consequences

数学IIが科目一覧から独立した科目として選択でき、5領域すべてを既存科目と同じ学習体験で利用できる。

数学B・数学Cの既存実装を保持したまま数学IIを追加するため、並行して追加された科目を失わない。今後さらに科目が増えて共通レジストリの責務が大きくなった場合は、科目非依存の共有レジストリへ移動するADRを別途検討する。
