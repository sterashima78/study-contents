# ADR 0065: 中学3年「式の展開と因数分解」を12教材で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0054, ADR 0062, ADR 0063, ADR 0064

## Context

中学校学習指導要領（平成29年告示）解説 数学編の第3学年「A 数と式」A(2)では、簡単な多項式について、単項式と多項式の乗法、多項式を単項式で割る除法、簡単な一次式の乗法、典型的な4公式を用いる展開・因数分解を扱う。また、既習の計算方法と関連付けて展開・因数分解の方法を考察し表現し、文字を用いた式で数量及び数量の関係を捉え説明することが求められている。

解説では、一次式どうしの積を形式的に処理するだけでなく、交換法則・結合法則・分配法則を基に理解することが重要とされる。典型公式は今後の学習で活用される一方、必要以上に複雑で無目的な計算練習にはしないことも示されている。

数量関係の説明例として、連続する2つの偶数を2n、2n+2と表し、2n(2n+2)+1=(2n+1)²へ変形することで「連続する2つの偶数の積に1を足すと、その間の奇数の2乗になる」と説明する活動が示されている。

中学3年ではADR 0063でA(1)「平方根」と中3共通基盤を実装済みである。その後mainではADR 0064によりAndroid実機のAI診断モデルがQwen3 0.6B q0f16へ変更され、ADR 0056はSupersededとなった。本教材変更は最新mainを基点とし、このAI診断条件を変更しない。

## Decision

### 1. A(2)を「式の展開と因数分解」1単元・12教材で構成する

`numbers-expressions` 領域へ `polynomial-expansion-factorization` 単元を追加し、次の12教材に分ける。

1. 単項式と多項式を掛ける
2. 多項式を単項式で割る
3. 分配法則で一次式の積を展開する
4. 和と差の2乗を展開する
5. 和と差の積を展開する
6. `(x+a)(x+b)` を展開する
7. 共通因数で因数分解する
8. 完全平方の形を因数分解する
9. 平方の差を因数分解する
10. `x²+px+q` を因数分解する
11. 展開・因数分解の公式を数の計算に活用する
12. 文字式で数量の関係を説明する

公式の種類ごとに独立教材を設けるが、単なる公式暗記ではなく、分配法則から展開公式へ、展開公式の逆として因数分解へ進む順序を保つ。

### 2. 4つの典型公式を中心にし、過度に複雑な式は扱わない

扱う公式は学習指導要領に明示された次の4つを中心とする。

- `(a+b)²=a²+2ab+b²`
- `(a−b)²=a²−2ab+b²`
- `(a+b)(a−b)=a²−b²`
- `(x+a)(x+b)=x²+(a+b)x+ab`

二次式の係数が複雑な因数分解や、高校範囲を先取りする一般的な多項式操作には広げない。公式を使う理由と形の認識を優先する。

### 3. 分配法則との関連を面積モデルで可視化する

`grade3/polynomial-diagrams.ts` を追加し、既存の型付きDiagram基盤で次を可視化する。

- `(a+b)(c+d)=ac+ad+bc+bd` を長方形の4領域で表す
- `(a+b)²=a²+2ab+b²` を正方形の4領域で表す

面積モデルは分配法則と公式の意味を結び付ける箇所へ限定する。任意SVG、`innerHTML`、外部描画ライブラリは追加しない。

### 4. 因数分解は展開の逆として扱う

共通因数、完全平方、平方の差、`x²+px+q` の順に因数分解する。各教材で、展開して元の式へ戻ることで確認できることを示す。

`x²+px+q` は「和がp、積がqとなる2数」を探す形に限定し、今後の二次方程式で因数分解を活用できる基礎を作る。

### 5. 活用は能率的な数の計算と数量関係の説明まで含める

公式の活用として、`101²` や `13²−12²` のような数の計算を、目的に合う式変形で能率化する教材を設ける。

さらに、連続する2つの偶数を文字で一般化し、`2n(2n+2)+1=(2n+1)²` へ変形して数量関係を説明する教材を独立させる。特定の数で確かめるだけで終わらず、文字式で全ての場合を説明することを学習目標とする。

### 6. 中3演習レジストリを単元追加に対応させる

既存 `grade3/exercise-registry.ts` を拡張し、平方根と本単元の両方を扱う。

- 各教材: 3問
- 各単元末: 8問
- 本単元は12教材のうち連続する8教材を出し、再生成ごとに開始位置を変える
- 特定の4教材が恒常的に単元末演習から除外されないようにする

長い証明文の完全一致は求めず、展開結果、因数分解結果、数値、一般化した式など短い評価点を採点する。

### 7. 公開情報と学習指導要領参照を更新する

中3トップと中学数学入口を、平方根と式の展開・因数分解の2単元公開へ更新する。次の主要対象はA(3)「二次方程式」とする。

`curriculum-references.js` の `middle-math3` noteも、A(1)平方根とA(2)簡単な多項式の公開状態へ更新する。

### 8. 公開リポジトリの安全境界と最新AI診断条件を維持する

教材・演習には固定の数学例またはブラウザ内生成値のみを使用し、実在する生徒・学校・組織のデータ、個人情報、秘密情報、認証情報を追加しない。

新規依存関係、外部API、分析SDKは追加しない。`package.json` と `pnpm-lock.yaml` は変更しない。

ADR 0064でAcceptedとなっているWebLLM 0.2.82、Qwen3 0.6B q0f16、context window 2048、prefill chunk 128、自己診断条件を含むAndroid診断条件も変更しない。

## Consequences

- 中学3年A(2)を、計算技能だけでなく方法の考察と数量関係の説明まで一連の教材として学べる。
- 展開公式と因数分解を逆方向の操作として関連付けられる。
- 次の二次方程式で因数分解を利用する準備が整う。
- 面積モデルにより公式の由来を視覚的に確認できる。
- 中3数と式は平方根と簡単な多項式の2単元公開となる。

## Validation

CIで次を確認する。

- Biome
- ADRの採番・Status・整合性
- 学習指導要領参照
- formula coverage
- application and advanced content
- Diagramデータ
- component style boundaries
- study AI boundaries
- Astro build
- 生成HTML検証

加えて次を確認する。

- `numbers-expressions/polynomial-expansion-factorization` の12教材と単元末演習が静的生成されること。
- 各教材で3問、単元末で8問の演習が生成されること。
- 単元末演習の開始位置が再生成時に変わり、同じ4教材だけが常に除外されないこと。
- 分配法則と和の2乗のDiagramが既存validatorを通ること。
- `middle-math3` の公開情報・学習指導要領参照がA(2)追加を反映すること。
- `package.json`、`pnpm-lock.yaml`、AI runtime・モデル・診断条件が変更されていないこと。

教材内容は文部科学省「中学校学習指導要領（平成29年告示）解説 数学編」第3学年 A(2)を基準に確認する。
