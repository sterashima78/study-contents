# ADR 0068: 中学3年「B 図形」を3単元21教材で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0059, ADR 0063, ADR 0066, ADR 0067

## Context

中学校学習指導要領第3学年B図形は、B(1)図形の相似、B(2)円周角と中心角の関係、B(3)三平方の定理で構成される。第2学年の合同・証明を基礎に、相似条件による論証、平行線と線分の比、面積比・体積比、円周角の定理と逆、三平方の定理と逆、具体的な計量へ発展させる必要がある。

## Decision

### 1. B領域を3単元に分割する

- `similarity`: 8教材
- `circle-angles`: 5教材
- `pythagorean-theorem`: 8教材

学習指導要領のB(1)〜B(3)と単元境界を一致させる。

### 2. 相似は論証と計量を分離する

相似の意味、3つの三角形の相似条件、相似を用いる証明、平行線と線分の比、中点連結定理、面積比、体積比、測量への活用を独立技能とする。

### 3. 円周角では定理の逆を独立技能とする

円周角と中心角、同じ弧に対する円周角、証明できること、円周角の定理の逆、作図・測定への活用に分ける。証明では場合分けの技巧に深入りせず、既習事項を根拠に一般性を確かめる意義を重視する。

### 4. 三平方では定理の逆と空間・実用を扱う

定理の意味、面積からの発見、斜辺、他の辺、定理の逆、座標距離、空間図形、具体的活用を分ける。証明方法の技巧的暗記は要求せず、証明できることを知る扱いとする。

### 5. 既存Diagram基盤と専用演習を使う

外部の幾何ライブラリは追加しない。`DiagramScene`で相似、平行線、円周角、直角三角形を図示する。演習は`geometry-exercise-registry.ts`へ分離し、各教材3問、単元末8問を生成する。

### 6. 安全境界を維持する

教材値は固定例またはブラウザ内生成値のみとし、個人情報・学校の実データ・秘密情報・外部APIを追加しない。`package.json`、`pnpm-lock.yaml`、Study AI runtime/model/診断条件は変更しない。ADR 0067で進行中のLlama 3.2 1B診断条件をそのまま保持する。

## Consequences

- 第3学年B図形が学習指導要領の3項目に対応して公開できる。
- 第2学年の合同・証明、第3学年の平方根との接続が明確になる。
- 図形領域だけを専用演習・Diagramとして保守できる。
