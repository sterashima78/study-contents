# ADR 0028: 学習指導要領の参照情報を全教材ページで共通表示する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0007, ADR 0022, ADR 0023, ADR 0025, ADR 0026, ADR 0027

## Context

このリポジトリの教材が、高等学校学習指導要領のどの教科・科目を参照すればよいかを学習者や教材作成者が確認できる導線が必要である。

教材ページごとに文部科学省のURLを直接記述すると、同一資料へのリンクが多数のファイルへ分散し、資料URLの更新、新科目追加時の登録漏れ、誤った外部サイトへのリンクを検出しにくくなる。また、本サイトの小単元名は学習しやすい粒度に再構成しており、学習指導要領の見出しをそのまま転記したものではないため、ページ名と学習指導要領の小項目が厳密に一対一対応すると表示するのは適切ではない。

2026-08-29時点で、文部科学省は「平成29・30・31年改訂学習指導要領（本文、解説）」から高等学校学習指導要領（平成30年告示）と各教科の解説を公開している。国語、数学、理科、外国語については、次の公式資料を確認した。

- 文部科学省「平成29・30・31年改訂学習指導要領（本文、解説）」 https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm
- 「高等学校学習指導要領（平成30年告示）解説 国語編」 https://www.mext.go.jp/content/20250410-mxt_kyoiku01-100002620_02.pdf
- 「高等学校学習指導要領（平成30年告示）解説 数学編・理数編」 https://www.mext.go.jp/content/20260115-mxt_kyoiku02-100002620_04.pdf
- 「高等学校学習指導要領（平成30年告示）解説 理科編・理数編」 https://www.mext.go.jp/content/20250311-mxt_kyoiku02-100002620_05.pdf
- 「高等学校学習指導要領（平成30年告示）解説 外国語編・英語編」 https://www.mext.go.jp/content/1407073_09_1_2.pdf

## Decision

### 1. 学習指導要領の参照情報をコースキーで一元管理する

`src/content/curriculum-references.js` を参照情報の唯一の登録場所とする。

各エントリは少なくとも次を持つ。

- サイト上のコース名
- 学習指導要領上の教科名
- 学習指導要領上の科目名または対象科目群
- 高等学校学習指導要領の公式参照URL
- 教科別の学習指導要領解説URL
- 参照先を確認した日付

国語、数学I〜III・A〜C、化学基礎、化学、物理基礎、物理、生物基礎、生物、英語を初期登録する。国語の「現代文・古文・漢文」と英語の単一コースはサイト上の学習導線であり、学習指導要領上の正式な科目名とは区別して対象科目群を明示する。

### 2. 学習指導要領本文は文部科学省の一覧ページを基準URLとする

学習指導要領本文への導線は、個別PDFのURLではなく、文部科学省の「平成29・30・31年改訂学習指導要領（本文、解説）」一覧ページを使用する。

個別PDFの配置変更に対する影響を小さくし、利用者が文部科学省の公式な最新版一覧から本文を確認できるようにする。教科別の解説は、対応する公式PDFへ直接リンクする。

### 3. 全教材ページへの表示は `StudyPage.astro` が担当する

`StudyPage.astro` は `import.meta.env.BASE_URL` を考慮して現在URLから先頭のコースキーを取得し、登録済みコースであれば `CurriculumReference.astro` をページ末尾へ表示する。

この方法により、科目トップ、領域、単元、小単元、単元末演習、応用・発展ページを含め、`StudyPage.astro` を利用する教材ページへ同じ参照表示を自動適用する。各ページや各レンダラーへ同じURLを重複記述しない。

### 4. 対応関係を過剰に断定しない

表示する対応粒度は初期実装ではコース単位とする。

「この教材ページ名が学習指導要領の同名項目に厳密に対応する」とは表示せず、「対応の確認先」として教科・科目と公式資料を示す。より細かな単元・小項目単位の対応を導入する場合は、公式資料の項目IDや見出しを別メタデータとして追加し、ページ名とは分離して管理する。

### 5. 外部リンクは文部科学省のHTTPS URLだけを許可する

公開リポジトリであることを踏まえ、`scripts/verify-curriculum-references.mjs` は学習指導要領と解説のURLについて次を検証する。

- `https:` であること
- ホスト名が `www.mext.go.jp` であること
- 必須の参照情報が空でないこと
- `src/pages/` の各静的コースディレクトリに登録が存在すること
- 登録だけが残り対応コースが消えていないこと

ブラウザで新しいタブを開く外部リンクには `rel="noopener noreferrer"` を付与する。

### 6. 生成HTMLでも全教材ページへの表示を検証する

`scripts/verify-curriculum-build-output.mjs` は、登録された各コースの `dist/` 配下にある全HTMLを走査し、次を検証する。

- 学習指導要領参照コンポーネントのマーカーが存在すること
- 対応科目の識別情報が一致すること
- 学習指導要領と解説の公式URLが出力されていること

PR CIとGitHub Pagesデプロイ前の両方で、ソース側の参照登録チェックと生成HTML側のチェックを実行する。

### 7. 表示スタイルはコンポーネントが所有する

`CurriculumReference.astro` のスタイルは同コンポーネントのscoped styleで管理し、新しい共有グローバルCSSを追加しない。ADR 0022とADR 0023のスタイル境界を維持する。

### 8. 新しい依存関係は追加しない

この機能は既存のAstro、Node.js標準機能、既存CIだけで実装する。学習指導要領リンクのためのライブラリは追加しない。

## Consequences

既存の全教材ページで、利用者が対応する高等学校学習指導要領と教科別解説へ移動できる。URLは1か所に集約されるため、文部科学省側で資料URLが変更された場合も参照レジストリを更新すればよい。

新しいコースを `src/pages/` に追加した場合、学習指導要領の参照情報を登録しない限りCIが失敗するため、対応付けの追加漏れを検出できる。また、生成HTMLを全件検査するため、レジストリに情報が存在していても画面へ表示されない回帰を検出できる。

一方、このADRだけでは各小単元と学習指導要領の細目の厳密な対応表までは提供しない。必要になった場合は、現在のコース単位レジストリを基準に、単元単位のメタデータを段階的に追加する。
