# ADR 0098: 正負の数の乗法は意味と規則性から符号規則を導く

- Status: Accepted
- Date: 2026-09-03
- Related: ADR 0001, ADR 0034, ADR 0038, ADR 0043, ADR 0059, ADR 0097

## Context

中学1年「正の数・負の数の乗法」は、従来「同符号の積は正、異符号の積は負」を最初に提示し、そのあと絶対値どうしを掛ける構成だった。この構成では計算手順は短いが、特に「負の数どうしを掛けるとなぜ正になるか」を規則として暗記するだけになりやすい。

正負の数の導入では、数直線上の向きや0を基準とした増減を使って数量を理解している。乗法でも、既習の「同じ数を何回か足す」という意味から始め、0を越えて積の並びを延長するときに分配法則との整合性を確認してから、最後に符号規則へ要約する方が、既習事項と新しい規則の関係を説明できる。

ADR 0097では、数直線上の位置・向き・距離・区間が推論の根拠になる説明では図を原則必須とした。今回の乗法説明では、正の回数による負の数の反復加法を数直線上の移動として推論根拠にするため、この方針に従ってcompanion diagramも追加する。

## Decision

### 1. 符号規則を導入ではなく結論として扱う

「正の数・負の数の乗法」は次の順序で説明する。

1. 正の回数の乗法を、同じ数の繰り返し加法として捉える。
2. 一方の因数を固定し、もう一方を1ずつ変えたときの積の並びを0の先まで延長する。
3. 分配法則と0の性質を使い、負の数どうしの積が正になる必要性を確認する。
4. 最後に「同符号は正、異符号は負」を計算用の短い規則として整理する。

これにより、符号規則は暗記の出発点ではなく、既習の乗法と演算法則を負の数へ矛盾なく拡張した結果として提示する。

### 2. 「負の回数」を繰り返し加法として説明しない

繰り返し加法として直接扱うのは回数が0以上の整数の場合に限定する。例えば `(+3)×(−2)` は `−2` を3回足すこととして数直線上で説明する。

`(−3)×(−2)` のように左側の因数が負になる場合を「−3回足す」とは説明しない。代わりに、`3×(−2), 2×(−2), 1×(−2), 0×(−2)` の積の並びと分配法則を使って0の先を決める。

### 3. 分配法則を理論的な根拠として明示する

積の並びを単なるパターン当てにしない。例えば次の関係を示し、`(−1)×(−2)=2` が必要になることを確認する。

`0 = {1 + (−1)}×(−2) = 1×(−2) + (−1)×(−2) = −2 + (−1)×(−2)`

左辺が0であるため、最後の積は `+2` でなければならない。同じ考えを延長すると、負の数どうしの積が正になることと積の絶対値が絶対値どうしの積になることを整合的に理解できる。

### 4. 数直線は正の回数による反復移動の意味を可視化する

`(+3)×(−2)` を、0から左へ2ずつ3回進んで−6に到達する数直線として `rule` のcompanion diagramに追加する。

図は装飾ではなく、「−2を3回足す」と「0から左へ2ずつ3回進む」が同じ内容であることを示す。色だけに依存せず、各移動量、目盛り、式をラベルで併記し、`ariaLabel` でも移動と結果を説明する。

### 5. 既存の型付きDiagram基盤と中1resolverを使う

新しい外部描画ライブラリや任意SVGは追加しない。`DiagramScene` と既存要素だけで数直線を構成する。

正負の数に関する図は `src/content/middle-school/math/grade1/signed-number-diagrams.ts` に分離し、`src/content/middle-school/math/grade1/lesson-diagrams.ts` から既存レジストリとフォールバック合成する。ADR 0038のcompanion registry分割方針を継続し、既存の大きな図ファイルへ異なる主題の図を追加し続けない。

### 6. 例題と練習も理由を再現する形にする

例題は負の数どうしの積について、0までの積の並びを確認してから0の先を延長し、最後に符号規則で答えを確認する。

練習も最初から符号だけを問うのではなく、`0×(−5)=0` を起点に積が5ずつ増えることを使って `(−1)×(−5)` を求め、その後に最終結果へ進む構成とする。

## Consequences

- 学習者は「負×負=正」を独立した暗記事項ではなく、乗法の意味、0、分配法則との整合性から説明できる。
- 数直線による直感的理解と、分配法則による理論的理解を同じレッスン内で接続できる。
- 計算時には従来どおり符号規則を短く利用できるため、理解を深めても計算手順自体は複雑化しない。
- 説明量と図が増えるため、長い式の横スクロールとモバイル表示を既存検証で継続して確認する必要がある。
