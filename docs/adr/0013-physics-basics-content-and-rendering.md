# ADR 0013: 物理基礎を現行学習指導要領に沿って追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0005, ADR 0007, ADR 0008, ADR 0009, ADR 0010, ADR 0011, ADR 0012
- Updates: ADR 0007 の公開科目一覧を教科横断へ拡張し、数学II・数学B・数学C・化学基礎と共存させる

## Context

学習サイトには数学I・数学A・数学II・数学B・数学C・化学基礎の教材があり、領域 → 単元 → 小単元、小単元内の考え方・根拠・例題・直後練習・確認問題、単元末演習という学習体験が確立している。

物理基礎を追加するにあたり、公式だけを列挙する教材ではなく、物理量の意味、向き、単位、成り立つ条件、観察・実験との関係を明示し、数式を現象と結び付けて理解できる構成が必要である。

文部科学省「高等学校学習指導要領（平成30年告示）解説 理科編 理数編」（平成30年7月、令和3年8月一部改訂）では、物理基礎に「物体の運動とエネルギー」と「様々な物理現象とエネルギーの利用」が示され、運動の表し方、様々な力とその働き、力学的エネルギー、波、熱、電気、エネルギーとその利用、物理学が拓く世界を扱う。

このリポジトリは公開されているため、学習履歴・回答・個人情報を外部へ送信する仕組みは追加しない。

## Decision

### 1. 学習指導要領の内容を5領域・18小教材へ再編する

`src/content/physics-basics/catalog.ts` を物理基礎の教材カタログとし、次の5領域を公開する。

- `motion`: 運動の表し方
- `forces-energy`: 力と力学的エネルギー
- `waves`: 波
- `thermal-electricity`: 熱と電気
- `energy-world`: エネルギーと物理学が拓く世界

初期公開は18小教材とする。学習指導要領上の項目を欠落させず、学習上連続して扱いやすい単位へまとめる。

「物理学が拓く世界」では特定製品や技術を無条件に推奨せず、センサー、音、電力、熱、放射線などを例に、物理概念と測定、安全性、利点・リスクを分けて考える。

### 2. 既存の階層・ナビゲーションを再利用し、物理固有の教材・演習表示だけを分離する

領域ページと単元ページは既存の `MathAreaIndex`、`MathUnitIndex` が実質的に科目非依存の構造であるため、科目メタデータ `physicsBasicsCourse` を追加して再利用する。

小単元では数値だけでなくSI単位、向き、物理用語を回答として扱うため、`PhysicsLesson` と `PhysicsExerciseSet` を追加する。既存の数学用MathLive入力や演習レジストリへ物理固有の判定を混在させず、表示スタイルと学習フローは共通化する。

物理基礎のURLは次とする。

```text
/physics-basics/
/physics-basics/{area}/
/physics-basics/{area}/{unit}/
/physics-basics/{area}/{unit}/{lesson}/
/physics-basics/{area}/{unit}/exercise/
```

### 3. 物理法則は「導出可能な関係」と「定義・基本法則」を区別する

ADR 0003の「公式を根拠なく提示しない」方針を物理基礎にも適用する。ただし物理では、ニュートンの運動法則やオームの法則のように、高校物理基礎の範囲内で数学的に導出する対象ではなく、観察・実験に基づく基本法則として扱うものがある。

`src/content/physics-basics/formula-derivations.ts` には、既習事項から説明できる関係を掲載する。例として次を含む。

- 単位換算 `1 m/s = 3.6 km/h`
- 平均速度と位置―時間グラフの傾き
- `v = v₀ + at`
- 自由落下で `a = g` となる関係
- 運動エネルギー `K = 1/2 mv²`
- 力学的エネルギー保存
- 波の基本式 `v = fλ`
- 片側閉管の基本振動 `L = λ/4`
- 電力量 `E = Pt`

一方、運動方程式、オームの法則、重ね合わせの原理、比熱・熱量の関係、効率の定義などは `scripts/verify-formula-coverage.mjs` で「定義・基本法則」として理由付きで分類する。

### 4. 演習はブラウザ内で生成・採点し、単位を含む入力を許容する

各小単元に3問確認、各単元に基礎12問・応用3問・難問1問の全16問を用意する。

物理の回答は `20` と `20 m/s` のような妥当な表記を許容し、空白や一部記号差を正規化して採点する。問題ごとに対応小単元を保持し、単元末演習では正答率の低い小単元への復習リンクを表示する。

生成・採点・診断はブラウザ内で完結する。回答値、学習履歴、端末情報を外部サービスへ送信しない。

### 5. トップページへ物理基礎を追加する

物理基礎を数学I・数学A・数学II・数学B・数学C・化学基礎と並ぶ科目としてトップページへ追加する。

この変更はADR 0007で採用した「トップページ → 科目ホーム → 領域 → 単元 → 小単元」という導線を維持したまま、教科をまたいで拡張するものである。既存科目の導線・URLは変更しない。

### 6. 新しい依存関係は追加しない

物理基礎は既存のAstro、TypeScript、Biomeとブラウザ標準APIだけで実装する。新規ライブラリや外部スクリプトは追加しない。

依存バージョン方針はADR 0005を継続し、この変更ではlockfileと依存関係を変更しない。mainで採用済みのpnpm 12.0.0をそのまま利用する。

### 7. CIで公式分類と代表ページの生成結果を検査する

`scripts/verify-formula-coverage.mjs` の対象へ物理基礎を追加する。教材に `formulas` を追加した場合、導出データまたは理由付きの基本法則分類がなければCIを失敗させる。

`scripts/verify-build-output.mjs` では次の代表ページを確認する。

- 物理基礎の科目ホーム
- 加速度
- 力学的エネルギー保存
- 音・気柱の共鳴
- 電気の単元末演習

ADR 0012で導入されたADR整合性チェックにより、本ADR自身の採番、見出し、Status、Date、参照先の存在もPR CIで検証する。

これによりカタログ、静的ルート、根拠表示、演習ページ、ADR管理の欠落をデプロイ前に検出する。

## Consequences

現行学習指導要領の物理基礎を一通りたどれる入口が追加され、既存科目と同じ粒度の学習フローで学べる。

物理固有の演習入力を数学用UIから分離したため、数学の既存挙動を変えずに単位・用語を含む採点ができる。一方、`MathAreaIndex`、`MathUnitIndex`、`MathCourseInfo` という既存名称には数学由来の名前が残る。実装上は科目共通に利用できるが、今後さらに理科科目を追加する際は、互換性を保ちながら `CourseAreaIndex`、`CourseUnitIndex`、`CourseInfo` などへ一般化することを別ADRで検討する。
