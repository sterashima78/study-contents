# ADR 0002: 小単元確認演習と単元末弱点診断

- Status: Accepted
- Date: 2026-08-29

## Context

例題直後の誘導付き練習だけでは、自力で解法を選べるかの確認と、単元全体で理解不足の小単元を特定する機会が不足する。

## Decision

### 小単元

各小単元は「考え方 → 例題 → 誘導付き練習 → 3問程度の確認演習 → まとめ」の順にする。確認演習は自動採点でき、同じ技能から別の問題を再生成できるようにする。

### 単元末

複数の小単元を束ねる単元には総合演習を設ける。問題数は次を目安とする。

- 基礎: 10〜20問
- 応用: 2〜5問
- 難問: 1〜2問

初期実装では基礎12問、応用3問、難問1問とする。

### 小単元との対応

各問題は確認対象の小単元キーを1つ以上持つ。単元末演習では問題ごとに対応小単元を表示し、採点後に小単元別の正答数と出題数を集計する。不正解がある小単元には復習リンクを表示する。

複数技能を組み合わせる応用問題・難問は、複数の小単元へ対応付けてよい。

### 採点と問題生成

問題文と正答は同じ生成パラメータから作り、ブラウザ内で採点する。空白、括弧、マイナス記号などの表記揺れは可能な範囲で正規化する。数式として同値な全表現を判定する数式処理系は現段階では導入しない。

問題生成、採点、弱点集計はクライアント側で完結させ、解答や個人情報を外部サービスへ送信しない。公開リポジトリへ秘密情報を追加しない。

## Consequences

小単元では解き方を確認した直後に自力で解けるかを検証できる。単元末では総合点だけでなく小単元別の弱点を確認できる。同じ問題生成ロジックを小単元確認と単元末基礎問題で再利用できる。
