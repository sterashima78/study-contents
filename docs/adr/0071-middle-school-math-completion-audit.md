# ADR 0071: 中学数学完成後の導線と生成HTML回帰検証を固定する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0054, ADR 0058, ADR 0059, ADR 0063, ADR 0065, ADR 0066, ADR 0068, ADR 0069, ADR 0070

## Context

中学数学は第1〜3学年のA「数と式」、B「図形」、C「関数」、D「データの活用」まで実装を完了した。一方で、サイトの最上位ページと `/middle-school/`、第1学年トップには段階公開中だった時期の説明が残っており、実装状態と表示が一致していなかった。

また、通常のAstro buildは全静的ルートを生成するが、中学数学3学年の入口、代表教材、単元末演習が生成HTMLとして存在し、主要表示を保っていることを明示的に検証する専用チェックはなかった。

## Decision

1. サイト最上位の科目一覧に「中学校」を追加し、`/middle-school/` へ直接到達できるようにする。
2. `/middle-school/` と中学1年数学トップの説明を、3学年・4領域公開済みの状態へ同期する。
3. `scripts/verify-middle-school-math-build-output.mjs` を追加し、以下をbuild後にCIで検証する。
   - サイト最上位から中学校への導線
   - 中学校トップと中学数学トップ
   - 中学1〜3年の各学年トップ
   - 各学年の代表教材
   - 各学年で利用する単元末演習
4. `package.json` にはbuild後検証用の `check:middle-math-build` スクリプトだけを追加し、依存関係は変更しない。
5. 現在AcceptedのStudy AI診断条件、モデル、runtime、学習指導要領に基づく教材内容は変更しない。

## Consequences

- 中学数学の完成状態がトップページから発見でき、公開状況の説明と実装が一致する。
- 将来のリファクタリングで学年トップ、教材、単元末演習の静的生成が欠落した場合、CIで検出できる。
- 中学理科を追加するときも `/middle-school/` を教科入口として拡張できる。
- CIに小さな生成HTML検証コストが追加されるが、新規依存関係や外部サービスは増えない。

## Security and privacy

- 公開リポジトリに秘密情報、認証情報、個人情報を追加しない。
- 検証対象はビルド済みの静的HTMLだけで、外部通信やユーザーデータを利用しない。
- 一時的なwrite権限や外部APIは導入しない。
