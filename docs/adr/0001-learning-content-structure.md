# ADR 0001: 学習コンテンツを「1ページ1技能」で構成する

- Status: Accepted
- Date: 2026-08-28

## Context

このリポジトリでは、生成AIを利用して高校数学を中心とした学習コンテンツを構築する。

初期実装では「式の展開と因数分解」「実数」「一次不等式」「集合と命題」のように、教科書上のまとまりを1ページに収めていた。しかし、1ページ内に複数の異なる技能が混在すると、学習者が一区切りを判断しにくく、例題と練習問題の距離も長くなる。

また、初学者向け教材では、熟練者なら省略する途中式を明示し、「なぜ次の式になるのか」を追えることを重視する必要がある。

## Decision

### 1. 1ページにつき1つの小さな学習目標を扱う

ページを終えたときに「何が1つできるようになるか」が明確になる粒度に分割する。

例として「式の展開と因数分解」は、少なくとも次のように分ける。

- 多項式の展開
- 乗法公式 `(a + b)²`
- 乗法公式 `(a − b)²`
- 乗法公式 `(a + b)(a − b)`
- 共通因数による因数分解
- `x² + px + q` の因数分解
- `ax² + bx + c` の因数分解

教科書上の大きなまとまりは、個別教材を束ねる単元トップページとして残す。

### 2. 1ページは5〜10分程度で一区切りつく量を目安にする

1ページでは、次の流れを完結させる。

1. このページでできるようになること
2. 考え方・ルール
3. 例題
4. 例題直後の練習問題
5. まとめ
6. 前後の小単元へのナビゲーション

複数の異なる技能を1ページに追加してページを長くするより、新しい小単元ページを作ることを優先する。

### 3. 例題では計算の途中を可能な限り細かく示す

最終結果まで大きく飛ばさず、分配法則、符号の処理、同類項の整理など、各操作を1段階ずつ示す。

例えば `(2x + 3)(x − 4)` の展開では、次の段階を省略しない。

1. `(2x + 3)(x − 4)`
2. `= 2x(x − 4) + 3(x − 4)`
3. `= 2x·x + 2x·(−4) + 3·x + 3·(−4)`
4. `= 2x² − 8x + 3x − 12`
5. `= 2x² − 5x − 12`

各段階には「何をしたか」「なぜその変形ができるか」の短い説明を添える。

### 4. 例題の直後に練習問題を置く

説明をまとめて読ませた後に練習をまとめて置く構成にはしない。

基本単位を「考え方 → 例題 → 練習問題」とし、学んだ操作を直後に使わせる。

最初の練習では、必要に応じて途中式も入力させる。例えば展開では、分配法則を使った1段目、各積を計算した2段目、同類項をまとめた最終結果を順に入力させる。

### 5. 公式・ルール・解法パターンごとに例題と練習問題を対応させる

1つの小単元で複数の公式、独立したルール、解法パターンを紹介する場合、説明だけを並べて代表例1問で済ませない。学習者が「どの形に、どの公式やルールを使うか」を個別に確認できるよう、それぞれに対応する例題と練習問題を用意する。

例えば乗法公式では、次の3公式を1組として一括練習するのではなく、それぞれについて「考え方 → 例題 → 練習問題」を成立させる。

- `(a + b)² = a² + 2ab + b²`
- `(a − b)² = a² − 2ab + b²`
- `(a + b)(a − b) = a² − b²`

複数の公式やルールがそれぞれ独立して適用できる場合は、原則として公式・ルールごとに小単元ページを分割する。分割するとかえって理解しにくい場合に限り同一ページに置くが、その場合でも各公式・各ルールの直後に専用の例題と練習問題を置く。

### 6. 練習問題は段階的に自立度を上げる

可能な場合は次の順序を採用する。

1. 例題とほぼ同じ形の誘導付き問題
2. 数字や符号を変えた問題
3. 学習者が方法を選ぶ確認問題

インタラクティブな問題では、即時採点、ヒント、再挑戦を提供する。

### 7. サイトの階層は「領域 → 単元 → 小単元」とする

数学Iでは、例えば次のように構成する。

```text
数学I
└─ 数と式
   ├─ 式の展開と因数分解
   │  ├─ 多項式の展開
   │  ├─ 乗法公式：(a + b)²
   │  ├─ 乗法公式：(a − b)²
   │  ├─ 乗法公式：(a + b)(a − b)
   │  ├─ 共通因数による因数分解
   │  └─ 二次式の因数分解
   ├─ 実数
   ├─ 一次不等式
   └─ 集合と命題
```

既存の単元URLは単元トップページとして維持し、ブックマークや外部リンクを壊さない。

### 8. 実装上の共通ルール

- 外部ライブラリを増やす前にブラウザ標準機能で実現できるか検討する。
- 問題の判定結果は `aria-live` などを利用し、キーボードでも操作できるようにする。
- 数式入力では表記揺れを可能な範囲で正規化する。
- 正答だけでなく、誤答時に次に確認すべき観点を示す。
- 教材内容は現行学習指導要領の範囲を基準にする。
- 公開リポジトリであることを前提とし、秘密情報や個人情報を教材・コード・設定に含めない。

## Consequences

ページ数は増えるが、各ページの責務が明確になり、学習者が短い単位で進捗を感じやすくなる。

教材制作時には、1つの大きなページを作るより、小単元の分割と前後関係の設計に時間が必要になる。一方で、例題・練習・まとめの型を共通化しやすくなり、新規教材の品質を揃えやすくなる。

既存の大単元URLを単元トップとして維持することで、ページ分割後もURL互換性を保つ。
