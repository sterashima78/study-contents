# ADR 0027: 生物基礎・生物を既存の科目共通教材基盤へ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0005, ADR 0011, ADR 0013, ADR 0016, ADR 0017, ADR 0019, ADR 0021, ADR 0023, ADR 0025
- Updates: ADR 0021 の数学・理科科目カバレッジを生物基礎・生物にも適用する

## Context

数学、物理、化学では、科目ごとの教材データを `MathArea` / `MathUnit` / `MathLesson` 互換の構造で保持し、`CourseHome.astro`、`MathAreaIndex.astro`、`MathUnitIndex.astro`、`MathLesson.astro`、`MathUnitExercise.astro` などの共通Astroコンポーネントで表示している。

生物基礎・生物を追加するにあたり、科目固有のページレイアウトを新設すると、パンくず、一覧、例題、誘導練習、単元末演習、応用・発展導線の実装が重複する。一方、生物では数式入力よりも用語、因果関係、実験・資料解釈の確認が中心となるため、確認演習の生成だけは科目特性に合わせる必要がある。

また、現行の高等学校学習指導要領における主な学習内容は、生物基礎が「生物の特徴」「ヒトの体の調節」「生物の多様性と生態系」の3領域、生物が「生物の進化」「生命現象と物質」「遺伝情報の発現と発生」「生物の環境応答」「生態と環境」の5領域である。公開教材の目次はこの領域構造と対応させる。

ADR 0021では数学・理科の公開科目について各領域に応用・発展教材を配置する方針を採用しているため、新しく公開する生物系2科目についても同じ基準へ含める。英語はADR 0025により初期実装では大学入試向け応用・発展パターンを範囲外としているため、本ADRの応用・発展カバレッジには含めない。

## Decision

### 1. 生物基礎は3領域、生物は5領域を科目目次の最上位構造とする

生物基礎は次の3領域を公開する。

- 生物の特徴
- ヒトの体の調節
- 生物の多様性と生態系

生物は次の5領域を公開する。

- 生物の進化
- 生命現象と物質
- 遺伝情報の発現と発生
- 生物の環境応答
- 生態と環境

各領域の内部は既存科目と同様に、領域 → 単元 → 小単元の階層で構成する。

### 2. 教材本文は既存の科目共通Astroコンポーネントを再利用する

生物専用の表示コンポーネントを新設せず、既存の次のコンポーネントを利用する。

- `CourseHome.astro`
- `MathAreaIndex.astro`
- `MathUnitIndex.astro`
- `MathLesson.astro`
- `MathUnitExercise.astro`
- 各 `ui/*` コンポーネント

コンポーネント名に数学由来の名称が残っていても、表示責務が科目共通である限り重複実装を避ける。表示文言については「技能」「途中式」など特定科目に寄り過ぎた表現を科目共通の「テーマ」「内容」「例題」に一般化する。

### 3. 生物の確認演習は小単元の誘導練習データから生成する

`src/content/biology-exercises.ts` に生物系2科目共通の演習レジストリ生成処理を置く。

各小単元の `practice.steps` に保持している問いと許容解答を確認演習のソースとして再利用し、次を保証する。

- 小単元本文と確認演習の対象知識を一致させる
- 問題文・許容解答の二重管理を避ける
- 生物基礎と生物で同じ生成ロジックを使う
- 回答欄はテキスト入力とする

小単元では3問、単元末では最大6問を生成し、単元末では基礎・応用・難問が少なくとも1問ずつ含まれるようにする。

### 4. 生物の問題は暗記だけでなく因果関係・実験・資料解釈を含める

本文の例題と応用・発展教材では、用語の確認だけに偏らず、次の観点を扱う。

- 条件と結果の因果関係
- 対照実験と操作条件の比較
- 時間変化や量の変化の読み取り
- 複数段階にわたる生態系への影響
- 分子、細胞、個体、個体群、生態系の階層をまたぐ説明

図解はADR 0019の一時停止方針を継続し、今回の教材にも追加しない。

### 5. 応用・発展教材の数学・理科カバレッジを12科目へ拡張する

ADR 0021の「数学・理科の公開科目の各領域に最低1つの `advanced` パターンを置く」基準を、生物基礎・生物にも適用する。

- 生物基礎: 3領域
- 生物: 5領域

これにより応用・発展教材の対象は、既存10科目から数学・理科12科目へ増える。英語の応用・発展教材はADR 0025の範囲外方針を維持する。

`verify-entrance-content.mjs` の必須領域へこの8領域を追加し、欠落をCIで検出する。

各発展問題はADR 0017の権利管理方針に従い、`rights.origin: "original"`、`rights.reviewStatus: "reviewed"`、有効な `reviewedAt` を保持する。外部問題本文、図表、解答を転載・言い換えして保持しない。

### 6. 生物機能のための新しい外部依存関係は追加しない

今回の生物機能は既存のAstro、TypeScript、MathLive、Biome、ブラウザ標準APIだけで実装する。生物の回答欄は既存の `ExerciseSet.astro` のテキスト入力を使うため、生物専用のフォームライブラリや採点ライブラリは追加しない。

作業中に既存開発依存のBiome 2.5.11が利用可能になったため、ADR 0005のバージョン方針に従って `@biomejs/biome` を2.5.10から2.5.11へ更新する。この保守更新に伴い `package.json`、`pnpm-lock.yaml`、`biome.json` のスキーマ参照を同期するが、生物機能固有の新規依存は導入しない。

### 7. 公開リポジトリに外部教材の原文や秘密情報を置かない

教材本文と問題は独自作成とし、第三者教材の問題文・解答・画像の保存場所としてリポジトリを使用しない。

APIキー、認証情報、個人情報を必要とする機能は追加せず、教材データと採点処理は静的サイトとブラウザ内で完結させる。

## Consequences

生物基礎・生物が既存科目と同じURL階層、学習フロー、単元末診断、応用・発展導線で利用できる。

確認演習を誘導練習データから生成するため、教材本文を更新した際に別の問題バンクとの不整合が起こりにくい。一方で、確認演習の問題バリエーションは各小単元の `practice.steps` に依存するため、今後問題数を増やす場合は、教材データへ追加の演習候補を持たせるか、独立した問題バンクへ移行するかを別ADRで判断する。

応用・発展教材のCI対象は数学・理科12科目へ増え、今後これらの科目に新領域を追加する場合も、公開と同時に発展教材のカバレッジを検討する必要がある。
