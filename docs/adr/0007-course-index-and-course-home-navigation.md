# ADR 0007: トップページを科目一覧とし科目ホームを独立させる

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0004, ADR 0006
- Supersedes: ADR 0006 の科目ホームに関する決定の一部

## Context

数学Aの追加後、ルート `/` は数学Iの科目ページを兼ね、数学Aは `/matha/` に独立した科目ページを持つ構成になっていた。

そのため、数学Iから数学Aへの直接リンクを置く必要が生じ、科目と科目の関係が階層ではなく横断リンクとして表現されていた。今後、数学II・数学Bなどの科目を追加する場合にも同じ問題が拡大する。

科目、領域、単元、小単元という情報階層をURLとナビゲーションにも反映し、トップページが特定科目に依存しない構造にする必要がある。

## Decision

### 1. ルート `/` を科目一覧とする

トップページは高校数学全体の入口とし、公開中の科目を同列のカードで表示する。

初期状態では次の2科目を表示する。

- 数学I
- 数学A

各カードには科目名、領域名、公開小教材数を表示し、科目ごとの目次へ遷移する。

### 2. 数学Iの科目ホームを `/math1/` に独立させる

数学Iの科目ホームを新たに `/math1/` とする。

数学Aは既存の `/matha/` を維持する。

これにより科目ホームのURLを次のように対称化する。

```text
/
  /math1/
  /matha/
```

既存の領域・単元・小単元URLは変更しない。

```text
/math1/{area}/...
/matha/{area}/...
```

### 3. 科目間の直接リンクを廃止する

数学Iから数学A、数学Aから数学Iへ直接移動するリンクは設けない。

各科目ページのフッターは `/` の科目一覧へ戻る導線に統一する。別科目へ移動するときは一度科目一覧へ戻る。

### 4. 領域以下のパンくずは各科目ホームへ戻す

`MathCourseInfo.homePath` は科目ホームを表し、数学Iでは `math1/`、数学Aでは `matha/` とする。

これにより領域・単元・小単元から「数学I」「数学A」の科目ホームへ戻る導線が科目ごとに一貫する。

### 5. 生成HTML検査で階層を固定する

`scripts/verify-build-output.mjs` で次を検証する。

- `/` に数学I・数学Aの科目一覧が表示される
- `/math1/` に数学Iの4領域と55小教材が表示される
- `/matha/` に数学Aの3領域と23小教材が表示される
- 数学I・数学Aの科目ページに「科目一覧へ」の導線がある

## Consequences

サイト全体の情報階層が「科目一覧 → 科目 → 領域 → 単元 → 小単元」と明確になる。

今後科目を追加する場合はトップページの科目一覧へ追加し、他科目のページへ相互リンクを増やす必要がない。

一方、以前 `/` を数学Iの科目ページとして利用していたブックマークは科目一覧を表示するようになる。ただし数学Iの領域以下の既存URLは維持されるため、教材ページへの直接リンクには影響しない。
