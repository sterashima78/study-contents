# ADR 0073: 著作権保護期間満了文章を権利台帳で確認してから教材利用する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0012, ADR 0017, ADR 0025, ADR 0026, ADR 0028

## Context

ADR 0025 は英語教材の本文を `original` に限定し、外部資料を扱う場合は引用要件、ライセンス、保存方法を別ADRで定義するとしている。ADR 0026 も国語教材では独自文章を原則とし、著作権保護期間が満了した作品等を利用する場合は、出典、権利状態、表示方法、レビュー方法を別ADRで定めるとしている。

国語・英語では、実在する文学作品を読解対象にすること自体に学習上の価値がある。一方、このリポジトリは公開され、Git履歴も公開されるため、権利確認前の本文を一度コミットして後から削除する運用は採用できない。削除後も履歴から取得できるためである。

日本では著作権の保護期間は原則として著作者の生存期間と死後70年であるが、無名・変名著作物、団体名義、映画、旧法、条約、戦時加算などの例外がある。また、原著がパブリックドメインでも、後年の翻訳、校訂、注釈、挿絵、電子版固有の追加部分には別の権利が成立し得る。

そのため、Project Gutenberg、青空文庫、Internet Archive等で本文を取得できることだけを、日本で自由利用できる法的根拠として扱わない。取得元の利用条件と、日本国内での権利状態を分離して確認する必要がある。

- 文化庁「著作物等の保護期間の延長に関するQ&A」 https://www.bunka.go.jp/seisaku/chosakuken/hokaisei/kantaiheiyo_hokaisei/pdf/r1408266_05.pdf

このADRは法的助言の代替ではなく、公開教材へ第三者文章を持ち込む際の保守的な内部制作ルールを定める。

## Decision

### 1. 権利確認と本文収録を二段階に分離する

外部文学作品は、最初に `src/content/text-sources/public-domain.json` の権利台帳へメタデータだけを登録する。権利確認が完了するまで作品本文、翻訳文、挿絵、スキャン画像等をリポジトリへ保存しない。

権利台帳の `reviewStatus` が `approved` の項目だけを、将来の国語・英語教材実装で参照可能とする。`candidate` と `rejected` は教材本文から参照してはならない。

今回の準備段階では権利台帳の構造と検証だけを導入し、実作品の本文は追加しない。

### 2. 日本での利用可否を基準に確認する

公開サイトでの利用可否は日本法上の状態を基準に確認し、`jurisdiction` は初期実装では `JP` のみ許可する。

単に「著作者の死亡から70年以上経過した」と機械判定して承認しない。少なくとも次を人手で確認する。

- 著作者の特定と死亡年
- 無名・変名・団体名義等の例外に該当しないか
- 旧法の影響がないか
- 外国著作物の場合は戦時加算その他の条約上の特例がないか
- 翻訳、校訂、注釈、挿絵等を利用する場合は、それぞれの権利が別途満了または利用許諾済みか

判断が明確でない作品は `approved` にしない。

### 3. 配布元の表示と日本での権利判断を分離する

権利台帳には次の情報を保持する。

- 作品ID
- 作品名
- 著作者名
- 原文言語
- 本文取得元の名称とURL
- 取得元を確認した日
- 日本国内でのレビュー状態
- 権利判断の根拠区分
- 著作者死亡年または公表年など、判断に使った事実
- 戦時加算確認状態
- 権利判断を裏付ける一次資料または公的資料のURL
- 権利レビュー日
- 補足事項

本文取得元が「Public Domain」と表示していても、それだけで `approved` にしてはならない。反対に、日本で著作権が満了していても、取得元サイト固有の利用条件や電子版固有部分がある場合は、それを確認してから本文を取り込む。

### 4. 原文と翻訳を別の著作物として扱う

英語作品では、原著が承認済みでも既存の日本語訳を自動的に利用可能とは扱わない。既存訳を利用する場合は翻訳者と翻訳の権利状態を別途確認する。

教材側で新規に和訳、現代語訳、語注、設問、解説を作成する場合、それらは教材独自部分として管理し、既存の市販訳やWeb上の訳文を参照元としてコピーまたは軽微改変しない。

国語でも、現代語訳、校訂、ルビ、注釈、挿絵など、原作品とは別に創作性を持ち得る部分は原作品のパブリックドメイン判定へ含めない。

### 5. 権利根拠は一次資料・公的資料を優先する

著作者の生没年、作品の公表年、法的な保護期間の判断には、国立国会図書館、国立公文書館、文化庁、e-Gov法令検索、著作者本人・権利管理団体等の一次資料または公的資料を優先する。

青空文庫やProject Gutenberg等は本文取得元または補助情報として利用できるが、日本法上の権利判断をそれらの表示だけへ依存しない。

権利台帳の `evidenceUrls` には、レビュー判断を再現できるHTTPS URLを1件以上保存する。URL先の内容をリポジトリへ転載する必要はない。

### 6. 公開リポジトリへ権利未確認本文を置かない

Issue、Pull Request、ADR、ソースコード、テストfixtureを含め、権利確認前の外部本文を公開リポジトリへ貼り付けない。

レビューでは作品名、著作者、必要最小限の書誌情報、URL、権利判断だけを扱う。権利確認のためにローカルで一時取得したファイルはコミットしない。

秘密情報、アカウント情報、有料データベース由来の本文、アクセス制限を回避して取得したデータを権利台帳へ含めない。

### 7. CIで権利台帳の構造を検証する

`scripts/verify-public-domain-sources.mjs` を追加し、Node.js標準APIだけで次を検証する。

- スキーマバージョン
- 作品IDの形式と重複
- 許可された言語・管轄・レビュー状態
- HTTPSの取得元URLと根拠URL
- 実在する `YYYY-MM-DD` 形式の日付
- `approved` 項目に必要な権利根拠と戦時加算確認状態
- `rejected` 項目に却下理由があること
- 権利台帳自体に作品本文を保持するフィールドがないこと

`package.json` に `check:text-rights` を追加し、通常の `check`、PR CI、GitHub Pagesデプロイ前の検証へ含める。

新しいnpm依存関係は追加しない。

### 8. 教材型の変更は実作品導入時の別PRで行う

今回の変更では `EnglishLesson.rights: "original"` を緩和せず、国語教材型にも外部文章参照を追加しない。

最初の実作品を導入するPRで、承認済み台帳IDを参照する型と表示コンポーネントを追加し、次を必須にする。

- 作品名・著作者・出典の表示
- 台帳IDとの一致
- `approved` 以外をビルド対象にしない検証
- 原文と教材独自の翻訳・注釈・設問の区別

これにより、権利管理の仕組みを先に導入し、教材実装と同時に権利ルールを設計する状態を避ける。

## Consequences

外部文学作品を使う前に、権利判断を再現可能なメタデータとして残せる。権利未確認本文がGit履歴へ残るリスクも低減できる。

一方、作品ごとに人手レビューが必要になり、単純な死亡年計算だけでは承認できないため、教材追加速度は下がる。しかし外国作品の戦時加算や翻訳の別権利を見落とすより、安全側の運用になる。

既存の英語・国語教材は引き続き独自本文のみを受け付けるため、このADRを追加しただけで第三者文章が公開されることはない。実作品導入は、権利台帳で承認された作品についてのみ別PRで行う。
