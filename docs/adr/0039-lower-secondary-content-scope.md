# ADR 0039: 中学生向け教材の初期対象を数学・理科・英語とする

- Status: Accepted
- Date: 2026-08-30

## Context

このリポジトリでは、これまで高等学校段階の数学、理科、英語、国語、地理歴史・公民に相当する教材を中心に整備してきた。ADR 0001に基づき、教材は「1ページ1技能」を基本とし、短い学習単位で説明、例題、練習、まとめを完結させる。

中学生向け教材を追加するにあたり、最初から中学校の全教科を対象にすると、教材モデル、ナビゲーション、学習指導要領参照、作図、演習形式の検証範囲が急激に広がる。一方、数学、理科、英語は既存の高校教材との接続が明確で、既存の教材レンダリング、演習、作図などの基盤を再利用しやすい。

特に数学と理科はADR 0034およびADR 0038で整備した共有作図基盤を活用できる。英語はADR 0025で定めた既存の英語教材構造と権利上の方針を参考にしつつ、中学校段階に適した独立した教材内容を設計できる。

また、ADR 0028の学習指導要領参照は高等学校段階を前提としているため、中学生向け教材の追加では学校段階を区別して参照情報を扱えるようにする必要がある。

## Decision

### 1. 中学生向け教材の初期対象を3教科とする

初期対象は次の3教科とする。

- 中学数学
- 中学理科
- 中学英語

各教科は中学校第1学年から第3学年までを対象とする。

国語、社会、技術・家庭、保健体育、音楽、美術、道徳などは初期対象には含めない。ただし、将来の追加を否定するものではなく、今回の対象範囲外として扱う。

### 2. 実装・教材整備は数学、理科、英語の順を基本とする

最初に中学数学を整備し、そこで中学校段階のナビゲーション、教材データ、学年情報、学習指導要領参照、演習、作図の共通方式を検証する。

次に中学理科へ展開し、現象図、回路図、光線図、力の図、粒子モデル、天体図など、作図が理解に寄与する単元を優先的に扱う。

その後、中学英語へ展開し、文法、語順、読解、表現を中学校段階に合わせて構成する。

この順序は作業の優先順位であり、サイト上で教科間に上下関係を設けるものではない。

### 3. 中学校と高等学校の教材内容は独立して管理する

中学校と高等学校で同じ概念を扱う場合でも、説明文、例題、練習問題、学習目標、前提知識は原則として別の教材データとして管理する。

例えば、中学3年の因数分解と数学Iの因数分解は概念上接続するが、同一教材データを共有しない。中学生向けでは中学校までの既習事項だけを前提とし、高校教材では高校段階の学習目的に合わせて説明する。

一方、次の実装基盤は可能な範囲で共有する。

- ページレイアウト
- ナビゲーション部品
- 例題・練習問題のUI
- 採点、ヒント、再挑戦の仕組み
- 作図コンポーネントと検証基盤
- アクセシビリティ対応

### 4. 学年を教材の明示的な属性として扱う

中学生向け教材では、教科だけでなく中学1年、中学2年、中学3年の区別が学習導線上重要になるため、学年を教材の明示的な属性として扱う。

サイト上の基本的な学習導線は次を想定する。

```text
中学校
└─ 教科
   └─ 学年
      └─ 領域
         └─ 単元
            └─ 小単元
```

ADR 0001の「領域 → 単元 → 小単元」という教材内部の粒度は維持し、その上位に学校段階、教科、学年を配置する。

具体的なURL設計や既存トップページの移行方法は、実装時に別途決定する。

### 5. 高校への接続を学習設計上の要件とする

中学生向け教材は中学校範囲だけで完結させつつ、高校教材へ自然につながる概念については、将来的に前後関係を示せるデータ構造を採用する。

例として次の接続がある。

- 中学数学の文字式・方程式・関数・因数分解 → 数学I
- 中学数学の図形・確率 → 数学A
- 中学理科の力・運動・電気・波 → 物理基礎
- 中学理科の物質・化学変化 → 化学基礎
- 中学理科の生命・生態系 → 生物基礎
- 中学英語の文法・語順・読解 → 高校英語

ただし、高校内容を中学校教材へ前倒しして必修化しない。

### 6. 現行の中学校学習指導要領を基準とする

教材範囲は、実装時点で有効な文部科学省の中学校学習指導要領および各教科の解説を基準とする。

将来の学習指導要領改訂案や審議中の内容は、正式に適用されるまでは教材範囲の根拠として先取りしない。改訂への追従は参照情報と教材データを更新することで対応できる構造にする。

ADR 0028で導入した学習指導要領参照の考え方は維持するが、中学校教材を追加する際には学校段階を区別できるよう参照モデルと検証を拡張する。

### 7. 図示が有効な箇所では共有作図基盤を優先して利用する

中学数学と中学理科では、文章だけより図示の方が理解しやすい内容について、ADR 0034およびADR 0038の共有作図基盤を利用する。

代表例は次の通りとする。

- 一次関数、比例・反比例、二次関数的な変化のグラフ
- 平面図形、空間図形、合同、相似、円、三平方の定理
- 力と運動
- 光の反射・屈折
- 電気回路
- 化学変化の粒子モデル
- 地層
- 天体の位置関係

図を置くこと自体を目的にせず、図が概念理解、比較、推論、問題解決に寄与する場合に使用する。

### 8. 新規依存関係は対象拡張だけを理由に追加しない

中学生向け教材の追加では、既存のAstro、TypeScript、ブラウザ標準機能、既存の作図・演習基盤を優先して利用する。

新しい外部ライブラリが必要になった場合は、ADR 0005のバージョン方針に従い、用途、保守性、セキュリティ上の影響を確認した上で判断する。

公開リポジトリであることを前提とし、教材、設定、テストデータ、ADRに秘密情報や個人情報を含めない。

## Consequences

中学生向け教材の初期スコープが明確になり、全教科を同時に設計することによる複雑化を避けられる。

中学数学を最初の実装対象とすることで、既存の数学教材、演習、作図基盤を利用しながら、中学校段階に必要な学年別ナビゲーションや学習指導要領参照方式を小さい範囲で検証できる。そこで確立した方式を中学理科、中学英語へ展開できる。

一方、国語や社会などは当面サイトに中学生向け教材が存在しない状態となる。これらを追加する場合は、本ADRの対象範囲を変更するのではなく、追加対象と教材特性を別のADRで決定する。
