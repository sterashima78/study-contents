# ADR 0020: 数学Iの全領域に応用・発展パターン教材を実装する

- Status: Accepted
- Date: 2026-08-29

## Context

ADR 0001 では基礎教材を「1ページ1技能」で構成する方針を定めた。ADR 0017 では大学入試を見据えた教材を完全独自作成し、権利状態を管理する方針を定めた。ADR 0019 では応用・発展教材を「1パターン1ページ」とし、図解を品質保証方法が確立するまで一時停止する方針を定めた。

数学Iでは最初に「二次関数」を試行対象として、解法パターンごとに考え方、例題、ステップバイステップ練習、実践、必要に応じた生成問題を提供した。この構造が学習単位として妥当であることを確認できたため、数学Iの残りの領域にも同じ構造を適用する。

一方で、単に問題数を増やすだけでは、領域間で教材構造や難易度の意味がずれる可能性がある。数学I全体をひとつの品質基準で揃え、今後数学A・数学II以降へ横展開できる共通実装を先に確立する必要がある。

## Decision

### 1. 数学Iの4領域すべてに応用・発展教材を持たせる

対象は次の4領域とする。

- 数と式 (`algebra`)
- 図形と計量 (`geometry`)
- 二次関数 (`quadratic`)
- データの分析 (`data-analysis`)

各領域は `src/content/entrance/math1-<topic>.json` に独立した教材データを持つ。

### 2. 各領域に4パターン以上を持たせる

数学Iの各領域は、最低4つの解法パターンを持つ。

また、各領域には次の両方を最低1パターン含める。

- `application`: 応用
- `advanced`: 発展

これは問題数のノルマではなく、同一領域内で「既習技能の組合せ」から「複数条件・場合分け・解釈を含む判断」へ段階を作るための最低条件である。

### 3. 各パターンの学習構造はADR 0019に従う

各パターンページは次の順序を維持する。

1. 考え方・着眼点
2. 例題
3. ステップバイステップの練習
4. 実践
5. 生成が安全な場合のみ別問題生成

特に「問題文のどの条件を見て、その解法を選ぶか」を考え方で明示する。

### 4. 数学Iの領域ページから応用・発展へ直接進める

基礎教材と応用・発展教材を別サイトのように分離しない。

各領域の目次ページに応用・発展への導線を追加し、基礎技能を学んだ後に同じ領域のパターン演習へ進めるようにする。

数学Iトップにも4領域すべての応用・発展教材を一覧表示する。

### 5. 公開済みの二次関数URLは維持する

二次関数は既に次のURLで公開しているため、URLを変更しない。

- `/math1/entrance/quadratic/`
- `/math1/entrance/quadratic/<pattern>/`

残り3領域は動的ルートを共通利用するが、二次関数の既存ルートと競合しないよう対象から除外する。

### 6. 共通レンダラーを導入する

残り3領域は次の共通コンポーネントを利用する。

- 応用・発展パターン一覧
- 1パターンの学習ページ

教材固有の文章・問題・解答はJSONへ置き、ページ構造やステップ練習の動作を共通化する。

これにより数学A・数学II以降へ展開するとき、教材データの追加を中心にできるようにする。

### 7. CIで数学I全領域のカバレッジを保証する

`verify-entrance-content.mjs` で次を検証する。

- 数学Iの4領域がすべて存在する
- 同じ `topic` の重複がない
- 各領域に4パターン以上ある
- 各領域に応用と発展が最低1件ずつある
- 各パターンに考え方、例題、ステップ練習、実践がある
- 権利メタデータがADR 0017に従う
- ADR 0019に従い `diagram` フィールドを含まない

### 8. 問題生成は全パターンへ強制しない

数学的な成立条件を単純に保証できるパターンのみ生成対象とする。

数学I全領域のカバレッジを増やすことを理由に、検証が不十分な生成器を追加しない。二次関数で既に検証済みの生成器は継続して利用する。

## Initial pattern coverage

### 数と式

- 応用: 条件式から対称式の値を求める
- 応用: 絶対値不等式を区間へ直す
- 発展: 共役を使って無理数の逆数を扱う
- 発展: 対偶を使って整数の命題を証明する

### 図形と計量

- 応用: 余弦定理で辺を求めて面積へつなぐ
- 応用: 正弦定理で辺と外接円半径をまとめて求める
- 発展: 2辺が固定された三角形の面積を最大化する
- 発展: 面積条件から角の2候補を残して処理する

### 二次関数

ADR 0019までに実装した5パターンを継続する。

### データの分析

- 応用: データの一次変換後の平均と散らばりを求める
- 応用: 平均が同じデータの散らばりを比較する
- 発展: 相関から因果を言い過ぎない
- 発展: 事前に決めた基準で帰無仮説を判断する

## Consequences

数学Iでは、4領域すべてについて基礎教材から応用・発展へ進む導線が揃う。

応用・発展教材の構造と最低カバレッジをCIで保証できるため、新しい領域や科目へ展開するときに「ページはあるが学習構造が欠けている」という状態を防ぎやすくなる。

一方、4パターンは完成形の上限ではない。入試問題の分析や学習上の不足が見つかった場合は、既存パターンと重複しない着眼点を追加する。

図解はADR 0019に従い引き続き停止する。問題生成も、安全な成立条件と検証方法が定義できたパターンだけに追加する。
