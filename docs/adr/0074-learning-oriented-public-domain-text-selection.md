# ADR 0074: パブリックドメイン作品は作問可能な短区間を基準に選定する

- Status: Superseded
- Date: 2026-09-01
- Superseded by: ADR 0078
- Related: ADR 0001, ADR 0025, ADR 0026, ADR 0073

## Context

ADR 0073 により、第三者の文学作品は権利台帳で候補登録と権利レビューを分離し、`approved` の作品だけを将来教材から参照する方針を採用した。

次の課題は、権利上利用できる作品を網羅的に集めることではなく、学習教材として有効な作品だけを候補にすることである。このサイトでは ADR 0001、ADR 0025、ADR 0026 により、原則として1ページ1技能、5〜10分程度で一区切りつく教材を採用している。

文学作品は知名度が高くても、前後関係を大量に必要とする長編、背景知識なしでは設問が成立しない文章、象徴解釈だけに正答を置く文章などは、この粒度の教材には向かない。また、作品全体を収録できることと、作品全体を収録すべきことは別である。

そのため、権利確認に進める候補自体を、作問可能性と教材粒度から限定する。

## Decision

### 1. 候補作品は短い連続区間で教材が成立するものに限定する

初期候補では、作品全体の収録を前提にしない。次の目安で、原文の連続した区間だけを利用できる作品を優先する。

- 現代文・古文: おおむね350〜900字
- 英語: おおむね250〜550語
- 英語の発展的な長文読解でも上限の目安を800語とする

区間を短くするために離れた文を継ぎ合わせない。途中を省略する場合は省略位置を明示し、必要な前提だけを教材側の独自説明として補う。

### 2. 本文根拠を持つ設問を3種類以上作れることを候補条件とする

候補区間から、次のうち3種類以上の設問を無理なく作れることを要求する。

- 語句、文法、構文
- 指示語、照応、主語、人物関係
- 接続、対比、因果、時系列などの文章構造
- 本文の明示情報に基づく内容一致
- 複数箇所を結び付ける推論
- 要約、言い換え
- 表現効果を本文根拠とともに説明する短答

作者の生涯、文学史、当時の社会状況を知らなければ解けない問題は、その知識自体を学習目標にする教材を除いて主設問にしない。

### 3. 解釈の多様性が大きい問いだけで教材を構成しない

象徴、主題、作者の意図などは学習価値があるが、単一の正答を置きにくい。これらを扱う場合は、本文のどの表現を根拠にしたかを説明する記述問題として扱い、自動採点や単純な正誤問題の中心にはしない。

少なくとも1問は本文から客観的に判定できる問題を含める。

### 4. 初期候補を国語3作品、英語3作品に限定する

権利台帳へ登録する初期候補は次の6作品とする。いずれもこの時点では `candidate` であり、権利確認済みを意味しない。

#### 国語

1. 夏目漱石『夢十夜』
   - 利用候補区間: 「第一夜」のみ
   - 主な学習: 語り手、時間表現、出来事の順序、反復表現、描写からの推論
   - 制限: 象徴の意味を唯一の正答として問わない
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000148/card799.html

2. 宮沢賢治『注文の多い料理店』
   - 利用候補区間: 二人の紳士が料理店へ入り、扉の指示を順に解釈していく場面を中心にした連続区間
   - 主な学習: 指示文の解釈、因果、情報更新、題名の意味の反転、人物の認識変化
   - 制限: 作品全体を初期教材へ収録せず、区間だけで必要な前提を独自説明する
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000081/card43754.html

3. 鴨長明『方丈記』
   - 利用候補区間: 冒頭の「ゆく河の流れは絶えずして」から始まる短い区間
   - 主な学習: 古語、係り受け、対比、比喩、反復、内容対応
   - 制限: 現代語訳は外部訳を転載せず教材側で独自作成する
   - 取得候補: 青空文庫 https://www.aozora.gr.jp/cards/000196/card975.html

#### 英語

4. Oscar Wilde, “The Selfish Giant”
   - 利用候補区間: 子どもが庭で遊ぶ導入から、巨人が壁を築き、庭に冬が残る因果が成立する連続区間
   - 主な学習: 時系列、代名詞、修飾、因果、対比、要約
   - 制限: 全編ではなく250〜550語程度を基本とする
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/902

5. O. Henry, “After Twenty Years”
   - 利用候補区間: 再会の約束と人物情報が分かる場面、または終盤の正体判明を含む連続区間
   - 主な学習: 会話文、時制、人物同定、伏線、情報の再解釈、推論
   - 制限: 全編使用は初期実装では避け、必要なら独自の短い状況説明を添える
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/2776

6. Saki, “The Open Window”
   - 利用候補区間: Veraの説明とFramtonの受け取り方のずれが追える連続区間
   - 主な学習: 会話文、照応、人物の認識差、推論、語りの信頼性、皮肉
   - 制限: Project Gutenberg掲載コレクション全体の読解難度は8〜9学年相当とされるため、初期実装では発展寄り候補とし、語彙注を増やしすぎて本文読解を置き換えない
   - 取得候補: Project Gutenberg https://www.gutenberg.org/ebooks/269

### 5. 漢文は今回の候補登録から除外する

現在の権利台帳の言語は `ja` と `en` に限定されている。漢文原文、訓読文、書き下し文、現代語訳では権利主体と教材上の扱いも異なるため、既存の日本語区分へ便宜的に押し込まない。

漢文の実作品導入は、原文と教材独自の訓読・書き下し・訳をどのように区別するかを決めてから別ADRで扱う。

### 6. 候補登録と権利承認を分離する

このADRで選定した6作品は `src/content/text-sources/public-domain.json` に `candidate` としてのみ登録する。

候補であることは、日本国内での権利状態、底本の編集部分、電子版固有部分、外国作品の戦時加算等を確認済みであることを意味しない。ADR 0073 のレビューを通過するまで教材本文へ取り込まない。

## Consequences

候補数を少数に保ち、権利確認の作業を教材化の見込みが高い作品へ集中できる。作品選定時点で利用区間と作問方針を定めるため、権利承認後に「有名だが教材には使いにくい」と判明する無駄も減る。

一方、文学史上重要な作品であっても、短区間で設問を作りにくい場合は初期候補から外れる。これは作品の価値を評価するものではなく、このサイトの教材粒度への適合性だけを判断するものである。
