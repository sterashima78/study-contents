# ADR 0016: 高等学校科目「物理」を独立した学習コースとして追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0005, ADR 0007, ADR 0012, ADR 0013, ADR 0014, ADR 0015
- Updates: ADR 0007 の公開科目一覧を「物理」まで拡張し、ADR 0013 の物理用UIを物理基礎と物理で共有できるよう一般化する

## Context

学習サイトには「物理基礎」があるが、高等学校学習指導要領上の「物理」は別科目であり、物理基礎の内容を深めた平面内の運動、運動量、円運動、万有引力、気体分子運動、光、電磁気、原子・原子核などを扱う必要がある。

文部科学省「高等学校学習指導要領（平成30年告示）解説 理科編 理数編」（平成30年7月、令和3年8月一部改訂）では、「物理」の内容を次の4項目で構成している。

1. 様々な運動
2. 波
3. 電気と磁気
4. 原子

「様々な運動」には平面内の運動と剛体のつり合い、運動量、円運動と単振動、万有引力、気体分子の運動を含む。「波」には波の伝わり方、音、光を含む。「電気と磁気」には電気と電流、電流と磁界を含む。「原子」には電子と光、原子と原子核、物理学が築く未来を含む。

既存の「物理基礎」は `/physics-basics/` で公開済みであり、内容・URL・演習挙動を維持する必要がある。また、このリポジトリは公開されているため、学習履歴、回答、個人情報を外部へ送信する機能は追加しない。

## Decision

### 1. 「物理」を `/physics/` の独立科目として公開する

`src/content/physics/catalog.ts` を教材カタログとし、学習指導要領の4領域をそのまま最上位の領域として採用する。

- `motion`: 様々な運動
- `waves`: 波
- `electricity-magnetism`: 電気と磁気
- `atoms`: 原子

4領域を13単元・33小教材へ分割する。小教材の粒度は、1ページで一つの主要概念・法則・計算法を学習できる大きさとする。

「物理基礎」を「物理」へ改名したり置き換えたりせず、両科目をトップページから個別に選択できるようにする。

### 2. 学習指導要領の各内容を欠落させず教材へ対応付ける

「様々な運動」では、平面運動、投射運動、剛体、運動量・力積、運動量保存、衝突、円運動、単振動、ケプラーの法則、万有引力、気体分子運動、内部エネルギー、熱力学第一法則を扱う。

「波」では、波の式と位相、ホイヘンスの原理、干渉・回折、音の干渉・回折・周波数分析、ドップラー効果、光の反射・屈折・分散・偏光、鏡・レンズ、ヤングの実験、回折格子、薄膜干渉を扱う。

「電気と磁気」では、クーロン力、電界、電位、コンデンサー、直流回路、内部抵抗、半導体、電流がつくる磁界、磁気力・ローレンツ力、電磁誘導、自己・相互誘導、交流、電磁波を扱う。

「原子」では、電子の電荷と質量、光電効果、光量子、物質波、X線、原子スペクトル、エネルギー準位、原子核、半減期、核分裂・核融合、質量とエネルギー、素粒子、物理学が築く未来を扱う。

### 3. 物理基礎のUIを一般化し、教材データと演習生成器は科目ごとに分離する

領域・単元ページは既存の `MathAreaIndex`、`MathUnitIndex` が科目メタデータを受け取れるため、そのまま再利用する。

小単元と単元末演習では、既存の `PhysicsLesson`、`PhysicsExerciseSet`、`PhysicsUnitExercise` を `physicsLevel` と科目ルートを受け取れるよう一般化する。物理基礎のデフォルト挙動は変更しない。

教材データ、公式根拠、問題生成は次のように科目ごとに分離する。

- `src/content/physics-basics/*`: 物理基礎
- `src/content/physics/*`: 物理

この分離により、物理の追加・修正が物理基礎の問題バンクや教材内容へ影響しないようにする。

### 4. 各小単元は現象・条件・根拠から演習まで一続きにする

各小単元では次の順序を基本とする。

1. 学習目標
2. 現象・物理量・法則の意味と成り立つ条件
3. 必要に応じた式の根拠・導出
4. 途中過程を示す例題
5. 例題直後の誘導付き練習
6. 誘導なしの3問確認
7. 要点整理

各単元末には基礎12問・応用3問・難問1問の16問演習を置き、問題と対応小単元を記録して復習候補を表示する。

### 5. 公式は導出可能な関係と基本法則・定義を区別してCI管理する

ADR 0003、ADR 0013の方針を継続する。

既習事項と高校物理の範囲内で説明できる関係は `src/content/physics/formula-derivations.ts` に根拠を記録する。例えば次を含む。

- 投射運動の水平・鉛直成分
- 力積と運動量変化
- 等速円運動の向心加速度
- ばね振り子の周期
- 単原子分子理想気体の内部エネルギー
- 進行波の位相と `v=fλ`
- ヤングの干渉縞
- コンデンサーに蓄えられるエネルギー
- 磁界中の荷電粒子の円運動
- 半減期による残存量

一方、ケプラーの法則、万有引力の法則、クーロンの法則、ファラデーの電磁誘導の法則、量子論の基本関係などは、教材内で実験・観測・理論上の基本法則として位置付け、CIの理由付き分類に登録する。

`src/content/physics/catalog.ts` は教材生成用ヘルパーを使うため、公式を含む小単元キーを `physicsFormulaLessonKeys` として明示する。`scripts/verify-formula-coverage.mjs` では、実際の `formulas` ブロック数とこの一覧の数、導出・分類の存在を検証する。

### 6. 演習・採点はブラウザ内で完結させる

`src/content/physics/exercise-registry.ts` で各小単元・単元末の問題を生成する。SI単位、向き、比、物理用語、式をテキスト入力として採点する。

演習生成、回答の正規化、採点、弱点表示はブラウザ内で行う。回答値、学習履歴、端末情報を外部APIへ送信しない。外部スクリプトや解析サービスも追加しない。

### 7. 新しい依存関係を追加しない

既存のAstro、TypeScript、Biome、MathLiveとブラウザ標準APIだけで実装する。`package.json` とlockfileは変更しない。

2026-08-29時点で使用中のAstro `7.2.9`、MathLive `0.110.0`、Biome `2.5.10` は公開パッケージの最新リリースとして確認し、プロジェクト方針どおりpnpm `12.0.0`を維持する。

長い教材データは既存の数学III・化学と同じくBiomeのフォーマット対象から除外するが、リント対象には残す。

### 8. CIで物理の代表ページとADR整合性を検査する

`scripts/verify-build-output.mjs` に次の代表ページを追加する。

- 物理の科目ホーム
- 等速円運動
- 光の回折と干渉
- 電磁誘導
- 原子核・崩壊・核反応
- 電気と電流の単元末演習

`scripts/verify-formula-coverage.mjs` では物理の公式分類を検査する。

ADR 0012で採用したADR整合性チェックにより、本ADRの採番、Status、Date、Related参照をPR CIで検証する。

## Consequences

「物理基礎」と「物理」を別科目として学習でき、高等学校学習指導要領の「物理」の4領域を一通りたどれるようになる。

物理基礎で確立した単位・向きを含む演習UIを再利用しつつ、教材カタログと問題生成器を分離するため、既存科目への変更範囲を抑えられる。

数学III・化学を含む最新の科目一覧・CI検証を保持したまま物理を追加するため、並行して追加された科目を巻き戻さない。

一方、科目共通に使うコンポーネント名には `Math*` や `Physics*` が残る。今後、理科科目をさらに共通化する場合は、互換性を保ちながら `CourseAreaIndex`、`CourseLesson`、`CourseExerciseSet` などへ一般化することを別ADRで検討する。
