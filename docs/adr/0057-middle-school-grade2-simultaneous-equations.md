# ADR 0057: 中学2年「連立二元一次方程式」を8技能で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0054, ADR 0055, ADR 0056

## Context

ADR 0054で中学2年数学コースを開始し、第2学年「A 数と式」のうち「式の計算と文字式の活用」を8技能で実装した。同ADRでは、連立二元一次方程式を後続の独立単元として分離することを決定している。

現行の中学校学習指導要領（平成29年告示）解説 数学編の第2学年 A(2)では、二元一次方程式とその解の意味、連立二元一次方程式の必要性と意味及びその解の意味、簡単な連立二元一次方程式を解くこと、一元一次方程式と関連付けて解法を考察し表現すること、具体的な場面で活用することが求められる。解法は、一方の文字を消去して既習の一元一次方程式へ帰着させる考え方を基に、加減法と代入法を扱う。

また、解の意味は後続の一次関数と二元一次方程式のグラフを関連付けることでさらに深められるが、本単元では代数的な解の意味と解法・活用に集中し、グラフとの対応は「C 関数」の一次関数単元へ接続する。

ADR 0055とADR 0056ではAndroid実機のブラウザ内AIの互換性・精度検証を継続している。今回の教材追加はAIランタイム、モデル、生成設定、依存関係を変更せず、最新mainで定義された検証条件をそのまま維持する。

## Decision

### 1. `numbers-expressions` に `simultaneous-equations` 単元を追加する

単元名を「連立二元一次方程式」とし、「式の計算と文字式の活用」の後に配置する。

### 2. 8技能を次の順で扱う

1. 二元一次方程式の解を捉える
2. 連立方程式とその解を捉える
3. 加減法で文字を消去する
4. 式を倍してから加減法を使う
5. 代入法で文字を消去する
6. 解き方を選んで連立方程式を解く
7. 文章から連立方程式をつくる
8. 連立方程式を具体的な問題に活用する

解の意味を先に扱い、機械的な計算だけにしない。加減法では、係数が既にそろう場合と、式全体を倍して係数をそろえる場合を別技能にする。代入法の後に、式の形から解法を選ぶ技能を置く。

### 3. 具体的な場面では立式と解釈を分ける

文章題は「立式」と「活用」の2技能に分ける。前者では未知量の設定と二つの条件の式化に集中し、後者では連立方程式を解いた後、元の数量として意味付けし、条件を満たすか確認するところまで扱う。

教材と演習で扱う人数、個数、代金などは全て説明用に作成した架空データまたはブラウザ内で生成した数値とし、実在する学習者や組織のデータを使用しない。

### 4. 一次関数のグラフとの対応は後続単元へ送る

二元一次方程式の解と直線、連立方程式の解と二直線の交点の対応は、学習指導要領上も一次関数との関連で理解を深める内容である。本単元では先取りして独立技能化せず、後続の一次関数実装時に接続する。

### 5. 既存の中2演習レジストリを拡張する

`grade2/exercise-registry.ts` に連立方程式の8技能を追加する。各小教材は3問、単元末は8問とし、単元末では8技能を1問ずつ扱う。

中学数学共通の表示・採点UI、ルーティング、診断UIはADR 0054で整備済みのため、新しいコンポーネント分岐は追加しない。

### 6. 外部依存関係を追加・更新しない

今回の教材はAstro、TypeScript、既存の中学数学共通UIだけで実装する。新しい外部ライブラリ、外部API、分析サービス、認証情報は追加しない。

Android向けブラウザ内AIについてはADR 0055・0056の検証方針を尊重し、本教材PRではpackage.json、pnpm-lock.yaml、AIモデル設定を変更しない。

## Consequences

第2学年「A 数と式」の文字式と連立二元一次方程式を、同じコース内で連続して学習できる。解の意味から始めることで、加減法・代入法を単なる手順ではなく、一方の文字を消して既習の一元一次方程式へ帰着させる方法として扱える。

一方、グラフによる解の解釈は本単元だけでは扱わない。一次関数を実装するときに、`simultaneous-equations` の既習事項と明示的に接続する必要がある。

## Validation

- `simultaneous-equations` に8教材が登録されていること。
- 各教材で3問、単元末で8問を生成できること。
- 単元末8問が8技能を1問ずつ診断できること。
- 中2の既存ルーティングから教材・単元末演習を静的生成できること。
- 学習指導要領参照が第2学年「A 数と式」の実装状況と一致すること。
- `pnpm check` と `pnpm build` を含むCIが成功すること。
- package.json、pnpm-lock.yaml、AIモデル設定を変更せず、最新mainのADR 0055・0056で定義された検証条件を維持すること。
