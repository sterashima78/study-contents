# ADR 0009: 数学Bの3領域を共通教材基盤へ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0006, ADR 0007, ADR 0008
- Updates: ADR 0007 の公開科目一覧を数学Bまで拡張し、ADR 0008 の数学C追加と共存させる

## Context

現行の高等学校学習指導要領（平成30年告示）では、数学Bは標準単位数2単位で、次の3つの内容から構成される。

1. 数列
2. 統計的な推測
3. 数学と社会生活

学習指導要領解説では、3内容すべてを履修させる場合には3単位程度を要する一方、標準単位数は2単位であり、生徒の特性や学校の実態、単位数等に応じて内容を適宜選択することとしている。

このサイトは学校ごとの履修範囲を限定するのではなく、学習者が必要な内容へアクセスできる教材カタログとして運用するため、数学Bについては3領域すべてを掲載する。

既存の数学I・数学A・数学Cでは、科目 → 領域 → 単元 → 小単元という情報階層と、例題直後の練習、小単元3問確認、単元末16問演習、公式・定理の導出分類を共通の学習体験としている。数学Bも同じ情報設計と検証方針へ統合する必要がある。

## Decision

### 1. 数学Bの3領域をすべて公開する

`src/content/mathb/` に数学Bの教材データを追加し、次の28小教材を公開する。

- 数列: 12小教材
  - 数列の基本と等差・等比数列: 5
  - いろいろな数列と和: 3
  - 漸化式: 2
  - 数学的帰納法: 2
- 統計的な推測: 12小教材
  - 確率変数と確率分布: 4
  - 正規分布: 4
  - 標本調査と統計的な推測: 4
- 数学と社会生活: 4小教材
  - 数理的な問題解決の過程: 2
  - 結果の解釈・評価と意思決定: 2

数学Bの標準単位数が2単位であることと、サイトが3領域すべてを掲載することは区別して表示する。科目トップでは「本サイトでは学習指導要領に示される3領域をすべて掲載」と明示する。

### 2. URLは既存科目と同じ階層にする

数学Bの科目ホームを `/mathb/` とし、以下を静的生成する。

```text
/mathb/
/mathb/{area}/
/mathb/{area}/{unit}/
/mathb/{area}/{unit}/{lesson}/
/mathb/{area}/{unit}/exercise/
```

表示には既存の `MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` を再利用する。

### 3. 科目一覧へ数学Bを追加する

ADR 0007で定めた科目一覧の構造を維持し、ルート `/` に数学Bのカードを追加する。ADR 0008で追加された数学Cも保持し、数学I・数学A・数学B・数学Cを同列に表示する。

科目間の直接リンクは追加せず、数学Bの科目トップもフッターから `/` の科目一覧へ戻す。

### 4. 演習基盤は既存の共通表示を再利用する

数学B専用の問題データは `src/content/mathb/exercise-registry.ts` に置く。

既存 `ExerciseSet.astro` の表示・採点・数式入力・弱点診断を再利用するため、数学I側の演習レジストリを既存のフォールバック経路として利用し、数学Bの単元キーを数学Bレジストリへ委譲する。数学A・数学Cの科目別分岐は維持する。

これにより、表示コンポーネントを複製せず、数学Bでも次を提供する。

- 小単元ごとのランダム3問
- 単元末の基礎12問・応用3問・難問1問
- 小単元ごとの正答率と復習リンク

### 5. 公式・定理の根拠を既存方針へ統合する

数学Bで公式を表示する小単元について、次のいずれかへ分類する。

- 既知の規則から導出し、`src/content/mathb/formula-derivations.ts` に記録する
- 定義、記法、基本法則、判断ルールとして `scripts/verify-formula-coverage.mjs` の例外分類に理由を記録する

数学Bの教材ファイルと導出ファイルを公式分類CIの対象へ追加し、数学Cの検査対象も維持する。

### 6. 生成HTML検査へ数学Bを追加する

`scripts/verify-build-output.mjs` で少なくとも次を確認する。

- `/` に数学Bと数学Cが表示される
- `/mathb/` に3領域と28小教材が表示される
- 数列の公式導出が生成HTMLへ出力される
- 統計的な推測の区間推定教材が生成される
- 数学と社会生活の評価教材が生成される
- 数学Bの単元末演習ページが生成される
- ADR 0008で追加された数学Cの代表ページ検査も引き続き成功する

## Dependencies and security

この変更では新しい外部ライブラリを追加しない。

2026-08-29時点で、既存依存の Astro 7.2.9、MathLive 0.110.0、Biome 2.5.10 はnpmのlatestである。pnpmはプロジェクト方針に従い12系の最新プレリリースを使用する。

公開リポジトリへ追加するのは教材データ、ルーティング、検証コード、ADRのみとし、資格情報、個人情報、外部サービスの秘密値は含めない。

## Consequences

数学Bが既存科目と同じ操作感で利用でき、学習指導要領に示される3領域を横断して学べるようになる。

教材表示、演習、公式導出の仕組みを既存コンポーネントへ統合するため、科目追加によるUI実装の重複を抑えられる。

一方、数学Bは標準2単位で学校ごとに扱う内容が異なり得るため、サイト上の28小教材すべてが個々の学校で必修であると誤解されない表示を維持する必要がある。
