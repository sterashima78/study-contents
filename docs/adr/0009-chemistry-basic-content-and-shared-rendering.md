# ADR 0009: 化学基礎を現行学習指導要領に沿って追加し既存の教材レンダリングを再利用する

- Status: Accepted
- Date: 2026-08-29

## Context

高校「化学基礎」の教材を、既存の数学科目と同じく科目、領域、単元、小単元の階層で提供する。

文部科学省「高等学校学習指導要領（平成30年告示）解説 理科編 理数編」では、化学基礎の内容は次の3領域で構成されている。

1. 化学と人間生活
2. 物質の構成
3. 物質の変化とその利用

また、内容には「化学の特徴」「物質の分離・精製」「単体と化合物」「熱運動と物質の三態」「原子の構造と電子配置」「イオンとイオン結合」「分子と共有結合」「金属と金属結合」「物質量と化学反応式」「酸・塩基と中和」「酸化と還元」「化学が拓く世界」などが含まれる。

既存サイトには、1ページ1技能で考え方、例題、直後の練習、確認演習、まとめを表示する共通コンポーネントがある。一方で型名やコンポーネント名は `Math*` という数学向けの名称のままである。化学基礎の追加と同時にこれらを全面的に改名すると、既存科目や並行して追加される科目との変更競合を大きくする。

化学基礎では、数学の数式入力だけでなく、用語、化学式、反応の意味など文字列で答える問題が多い。また概念問題を無理に16問へ増やすと類似問題の重複が増えやすい。

依存関係はADR 0005の方針に従う。2026-08-29時点でリポジトリが使用しているAstro、MathLive、Biome、pnpm 12系の公開版は確認済みであり、化学基礎の追加に新しい外部ライブラリは必要ない。

## Decision

### 1. 化学基礎の科目構成は現行学習指導要領の3領域に合わせる

科目トップでは次の3領域を直接示す。

- 化学と人間生活
- 物質の構成
- 物質の変化とその利用

各領域の下に学習指導要領解説の内容を学習しやすい単元へ整理し、各小単元は既存教材と同じ1ページ1技能の粒度とする。

### 2. 既存の教材レンダリングを再利用する

`MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` と既存の教材データ型を化学基礎でも再利用する。

科目固有のタイトル、URL、パンくずリストは `chemistryBasicCourse` で切り替える。`Math*` という名称は現状の実装上の名前として残し、表示上は化学基礎として扱う。

非数学科目が増え、改名による便益が変更競合や移行コストを上回る段階で、共通コンポーネントと型を `Course*` / `Lesson*` などへ一般化する。

### 3. 化学基礎専用の演習問題レジストリを持つ

化学基礎の確認問題は `src/content/chemistry-basic/exercise-registry.ts` で管理する。

小単元ページでは既存と同じ3問の確認演習を出題する。化学基礎の単元末演習は、概念・計算・化学式を混ぜた6問を基本とし、基礎4問、応用1問、難問1問を目安にする。

回答は化学式や用語を扱いやすくするため原則としてテキスト入力を用いる。既存の採点・弱点診断UIは共通利用する。

### 4. 科目一覧を高校学習コンテンツの入口として拡張する

ルートの科目一覧に化学基礎を追加し、数学科目と並列に表示する。

ADR 0007で決定した「科目一覧 → 科目ホーム → 領域 → 単元 → 小単元」というナビゲーション構造は維持する。

### 5. 教材データのBiome方針は既存科目とそろえる

長い教材データは内容差分の可読性を優先し、既存の数学I・数学A・数学Cの教材データと同様に `src/content/chemistry-basic/**/*.ts` のフォーマッタを無効化する。一方、Biomeのリントは有効なままとし、ページ・コンポーネント・スクリプトは通常どおりフォーマット検査する。

### 6. 実行時の外部データ取得を追加しない

教材内容と演習問題はリポジトリ内の静的データとして保持し、ブラウザから外部API、秘密情報、利用者データへアクセスする処理は追加しない。公開リポジトリであることを前提に、資格情報や非公開データをコードへ含めない。

## Consequences

化学基礎を既存科目と同じ操作感で追加でき、現行学習指導要領との対応も科目トップから確認しやすい。

既存コンポーネントの再利用により変更量と並行開発時の競合を抑えられる。一方、内部の `Math*` という名称と実際の利用範囲が一致しなくなるため、今後非数学科目が増えた段階で一般化を検討する技術的負債が残る。

化学基礎の単元末演習は数学の16問より少ないが、類似した概念問題の水増しを避け、各小単元の3問確認と組み合わせて理解度を確認する。

新規依存関係を追加しないため、サプライチェーン上の追加リスクやライブラリ更新作業は発生しない。
