# ADR 0028: 日本史・世界史・倫理を科目共通教材基盤へ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0005, ADR 0007, ADR 0017, ADR 0019, ADR 0023, ADR 0025, ADR 0026, ADR 0027
- Updates: 科目共通教材基盤の対象を地理歴史・公民の選択科目へ拡張する

## Context

このサイトでは、数学・理科の多くの科目を `MathArea` / `MathUnit` / `MathLesson` 互換のデータ構造で保持し、`CourseHome.astro`、`MathAreaIndex.astro`、`MathUnitIndex.astro`、`MathLesson.astro`、`MathUnitExercise.astro` などの共通表示コンポーネントを再利用している。

日本史・世界史・倫理を追加するにあたり、科目ごとに独立したレイアウトやナビゲーションを実装すると、既存の学習フローと表示責務が重複する。一方で、社会科の確認演習は数式入力を必要とせず、用語暗記だけでなく、因果関係、比較、史料や思想の読み取り、判断理由の整理を扱う必要がある。

現行の高等学校学習指導要領では、「日本史探究」「世界史探究」は「歴史総合」を踏まえて学習を深める選択科目として構成されている。「倫理」は「公共」で身に付けた見方・考え方を基礎に、古今東西の思想と現代の倫理的諸課題を探究する選択科目である。本サイトの科目名は利用者に分かりやすい「日本史」「世界史」「倫理」とし、教材範囲は現行課程の探究科目を意識して構成する。

公開リポジトリであるため、第三者教材の問題文・史料画像・解答を保存することや、APIキー・認証情報・個人情報を教材へ含めることは避けなければならない。また、政治・経済統計など頻繁に変わる現況データを静的教材へ無期限に固定すると、内容が陳腐化するリスクがある。

## Decision

### 1. 日本史・世界史・倫理を領域 → 単元 → 小単元の既存構造で公開する

初期実装では次の構造とする。

日本史は5領域、10小単元とする。

- 古代国家の形成
- 中世社会と武家政権
- 近世国家と社会
- 近代国家と国際関係
- 現代日本と社会

世界史は5領域、10小単元とする。

- 古代文明と古典世界
- 東アジアとイスラーム世界
- 海域世界と近世国家
- 革命と帝国主義
- 二つの世界大戦と現代世界

倫理は4領域、8小単元とする。

- 青年期と人間としての在り方
- 西洋思想
- 東洋・日本思想
- 現代の倫理的諸課題

各小単元は、学習目標、概念解説、例題、誘導練習、3問確認、まとめを持つ。

### 2. 既存の科目共通表示コンポーネントを再利用する

科目ホーム、領域一覧、単元一覧、教材本文、単元末演習は既存の共通コンポーネントを利用する。

- `CourseHome.astro`
- `MathAreaIndex.astro`
- `MathUnitIndex.astro`
- `MathLesson.astro`
- `MathUnitExercise.astro`
- 各 `ui/*` コンポーネント

`MathArea` や `MathLesson` など数学由来の型名は現時点では変更しない。型名の一括改名は多数の既存科目へ影響するため、本変更では表示・データ構造の再利用を優先し、必要なら別ADRで一般化する。

社会科ページで数式入力ライブラリを読み込まないよう、確認演習は `SocialExerciseSet.astro` へ分離する。数学・理科向けの `ExerciseSet.astro` の既存ロジックには社会科の分岐を追加しない。

### 3. 社会科の確認演習は小単元の練習データから生成する

`src/content/social-exercises.ts` で3科目共通のテキスト演習生成処理を持つ。

- 小単元では `practice.steps` から3問を出す
- 単元末では最大6問を出す
- 単元末では基礎・応用・難問を可能な限り含める
- 回答欄は通常のテキスト入力とする
- 本文と確認問題の対象知識を同じデータから生成し、二重管理を避ける

### 4. 暗記だけでなく、関係・比較・解釈を教材の中心に含める

日本史・世界史では、人物名・年代・制度名の確認に加え、次を扱う。

- 出来事の原因と結果
- 制度と社会構造の関係
- 同時代の地域比較
- 日本と東アジア、各地域間の交流
- 支配する側と支配される側など複数の立場

倫理では、思想家名・用語の確認に加え、次を扱う。

- 概念間の共通点と相違点
- 思想が置かれた歴史的・社会的背景
- 判断の結論と、その結論を支える理由の区別
- 現代的課題における価値の衝突
- 異なる立場を比較した上での公共的な検討

史料・図版を扱う教材は将来拡張とし、ADR 0019の図解生成一時停止方針を継続する。初期実装では第三者の史料画像・地図・教科書図版を取り込まない。

### 5. 教材本文・問題文は独自作成し、外部教材を転載しない

公開リポジトリに保存する解説、例題、確認問題は独自に作成する。

- 教科書、問題集、模試、入試問題の本文・解答を転載しない
- 第三者の史料画像・地図・図版をコピーしない
- 外部サイトの文章を言い換えただけの教材を保存しない
- 引用が必要な将来機能では、出典・権利状態を明示する仕組みを先に設計する

### 6. 更新頻度が高い現況データを初期教材へ固定しない

政治家の現職情報、直近の選挙結果、最新のGDP・人口・政策金利など、更新頻度が高い情報は今回の静的教材へ含めない。

現代史は、評価が定まった主要な歴史過程を中心に扱う。最新ニュースや現在進行中の政策評価を教材へ追加する場合は、更新日、出典、更新責任、失効条件を管理する仕組みを別ADRで決める。

### 7. 新しい外部依存関係は追加しない

日本史・世界史・倫理の実装は、既存のAstro、TypeScript、Biome、ブラウザ標準APIで完結させる。社会科の回答欄は通常のHTMLテキスト入力であり、専用の採点・フォーム・可視化ライブラリは追加しない。

依存関係のバージョンはADR 0005の方針を継続し、本機能のための更新は行わない。依存更新が必要になった場合は、公開レジストリの最新版確認、lockfile更新、CI確認を同じ変更で行う。

### 8. 公開リポジトリへ秘密情報・個人情報を持ち込まない

教材・採点は静的サイトとブラウザ内で完結させる。APIキー、アクセストークン、個人情報を必要とする機能は追加しない。

将来、外部APIやユーザー学習履歴を扱う場合は、本ADRの範囲外とし、データ分類・保存期間・認証・秘密情報管理を別ADRで決めてから実装する。

## Consequences

3科目を既存科目と同じナビゲーションと学習フローで利用できる。社会科固有の確認演習だけをテキスト専用コンポーネントへ分離するため、数式入力ライブラリを不要なページで読み込まず、既存の数学・理科演習への影響も限定できる。

初期実装は各科目の全範囲を細分化した完全版ではなく、主要領域を横断する基礎カタログである。今後は、歴史総合との接続、史料読解、年代横断比較、思想原典の適切な引用、大学入試向け応用・発展問題などを段階的に追加する必要がある。
