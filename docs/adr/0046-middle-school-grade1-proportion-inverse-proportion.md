# ADR 0046: 中学1年「比例・反比例」を8つの技能とグラフ図示で構成する

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0043から0045で、中学1年数学の「数と式」を1ページ1技能で実装した。次に、現行の中学校学習指導要領（平成29年告示）数学第1学年「C 関数」の「比例，反比例」を扱う。

学習指導要領解説では、関数関係の意味、比例・反比例、座標、表・式・グラフによる表現を知識・技能として扱い、表・式・グラフを用いて変化や対応の特徴を見いだすこと、比例・反比例を用いて具体的な事象を捉え考察し表現することが求められている。また、表・式・グラフを別々に扱わず、相互に関連付けることが重視されている。

比例・反比例は視覚化の効果が大きい単元であり、既存のDiagram基盤を用いて座標とグラフを教材内に直接表示する価値が高い。

## Decision

### 1. 「関数」を独立領域として追加する

中学1年数学に `functions` 領域を追加し、その中に次の単元を置く。

```text
proportion-inverse-proportion
```

表示名は「比例・反比例」とする。

### 2. 単元を8つの小教材に分割する

次の順序で学習する。

1. 関数関係の意味
2. 変数と変域
3. 比例を式と表で表す
4. 座標の意味と読み取り
5. 比例のグラフ
6. 反比例を式と表で表す
7. 反比例のグラフ
8. 表・式・グラフを結び付けて活用する

関数の意味を先に確認し、比例、座標、グラフ、反比例へ進み、最後に複数の表現を相互に関連付けて具体的事象へ利用する。

### 3. 第1学年の範囲に限定する

比例は `y = ax`、反比例は `y = a/x` を中心とし、第2学年の一次関数 `y = ax + b` や第3学年の `y = ax²` は先取りしない。

変域は具体的な数量の取り得る範囲として扱い、高度な集合記号や区間記法は導入しない。

### 4. 表・式・グラフを相互に関連付ける

表から対応する値を読み、式から表を作り、座標として点を取り、グラフの形と変化の特徴を説明する流れを明示する。

単元末の小教材では、どれか一つの表現だけを使うのではなく、表・式・グラフの対応を往復して確認する。

### 5. グラフを既存Diagram基盤で図示する

`src/content/middle-school/math/grade1/diagrams.ts` を追加し、少なくとも次を図示する。

- 座標平面上の点と座標
- 比例 `y = ax` の直線と原点
- 反比例 `y = a/x` の二つの曲線
- 表・式・グラフを関連付ける代表例

`lesson-diagrams.ts` に `middle-math1` のresolverを追加し、既存の `MathLesson.astro` と `DiagramView` をそのまま利用する。新しい描画ライブラリは追加しない。

### 6. 確認演習を8技能に対応させる

`src/content/middle-school/math/grade1/exercise-registry.ts` に8小教材それぞれの問題生成を追加する。

各小教材では3問の確認問題を生成し、単元末演習では8小教材から原則1問ずつ出題する。採点後の診断と復習リンクは既存の中学数学用演習UIを継続利用する。

### 7. 公開リポジトリの安全性と依存関係を維持する

教材、図解、演習生成、ADRに秘密情報、個人情報、外部サービスの認証情報を含めない。

実装は既存のAstro、TypeScript、MathLive、Diagram基盤、ブラウザ標準APIで行い、この単元追加を理由とする外部依存関係の追加は行わない。

## Consequences

中学1年の「C 関数」を、関数の意味から比例・反比例の活用まで段階的に学べる。

表・式・グラフを相互に関連付ける構成と教材内の図示により、式操作だけに偏らず、変化と対応を視覚的に捉えられる。

一方、グラフの自由作図や点のドラッグ操作までは今回の範囲に含めない。まず静的で正確な図示と自動採点を整備し、操作型作図が必要かは利用状況を見て別ADRで判断する。
