# ADR 0024: 生成AIによる実験的コンテンツであることをトップページで明示する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0022, ADR 0023, ADR 0030

## Context

このサイトは、生成AIを使って学習コンテンツをバイブコーディングすることを試す実験として構築している。

一方、公開される画面だけを見る利用者には、教材が通常の編集・監修済み教材であるか、生成AIを活用した実験的生成物であるかを判別できない。学習用途では、生成AI由来の誤りや不正確な記述が含まれる可能性を利用者が認識できることが重要である。

また、ADR 0022およびADR 0023では、静的な教材UIの視覚表現をAstroコンポーネント自身のscoped styleで管理する方針を採用している。

## Decision

### 1. トップページで実験的生成物であることを明示する

学習コンテンツのトップページに、次の点を利用者が科目選択前に確認できる表示を置く。

- 生成AIを使って学習コンテンツをバイブコーディングすることを試した実験的な生成物であること
- 内容と構成の作成・改善に生成AIを活用していること
- 通常の編集・監修済み教材と同等の正確性を保証するものではないこと
- 誤りや不正確な記述を含む可能性があること
- 学習時には教科書や公式資料などもあわせて確認すること

制作方法は利用者に不要な内部事情として隠さず、このサイトの性格を理解するための前提情報として扱う。

### 2. 注意書きは専用Astroコンポーネントとして表現する

注意書きは `src/components/ui/ExperimentalNotice.astro` が所有する。

トップページを構成する `CourseCatalog.astro` から、ヒーローと科目一覧の間に配置する。長いランディングページ的な説明にはせず、実験の目的、生成AIの利用、正確性に関する注意を簡潔に常時表示する。

### 3. 注意書きのスタイルはコンポーネント内に限定する

`ExperimentalNotice.astro` が自身のscoped styleを所有し、グローバルCSSや親コンポーネントから内部クラスへ依存する指定は追加しない。

既存の `StudyPage.astro` が提供するデザイントークンを利用し、サイト全体の見た目との整合を保つ。

## Consequences

利用者は教材へ進む前に、このサイトの生成方法と実験的位置づけを把握できる。

生成AIを利用した教材であることだけでなく、どのような制作実験であるかも隠さず示すため、完成品の教育サービスや通常の監修済み教材と誤認されにくくなる。

注意書きの表示責務とスタイル責務は専用コンポーネントに閉じるため、今後文言や表現を変更する場合も他の教材UIへ影響しにくい。
