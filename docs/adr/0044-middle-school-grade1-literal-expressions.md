# ADR 0044: 中学1年「文字と式」を8つの技能に分けて構成する

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0043で、中学数学は中学1年「正の数・負の数」の縦断実装から開始し、教材本文は1ページ1技能で追加していく方針を決定した。

現行の中学校学習指導要領（平成29年告示）数学第1学年「A 数と式」の「文字を用いた式」では、文字を用いることの必要性と意味、乗法と除法の表し方、簡単な一次式の加法と減法、数量の関係や法則を文字を用いた式で表したり読み取ったりすることを扱う。また、用語・記号として項、係数、≤、≥を扱う。

これらを1ページにまとめると、文字の意味、表記規則、代入、式の計算、数量関係の表現という異なる技能が混在する。ADR 0001の「1ページ1技能」を維持するため、学習指導要領の内容を教材上の小さな技能へ分解する必要がある。

## Decision

### 1. 「文字と式」を独立した単元として追加する

中学1年数学の `numbers-expressions` 領域に、次の単元を追加する。

```text
literal-expressions
```

表示名は「文字と式」とする。

### 2. 単元を8つの小教材に分割する

次の順序で学習する。

1. 文字を使って数量を表す
2. 文字式の乗法の表し方
3. 文字式の除法の表し方
4. 文字式の値と代入
5. 項と係数
6. 同類項をまとめる
7. 一次式の加法と減法
8. 数量の関係を式で表す

表記規則を先に扱い、その後に代入と式の構造、計算、具体的な数量関係の表現へ進む。

### 3. 第2学年以降の内容を先取りしない

第1学年では、一つの文字への代入、簡単な一次式の加法と減法、数量関係の表現に範囲を限定する。

複数種類の文字を含む整式の本格的な四則計算、単項式の乗法・除法、式を用いた一般的な説明は第2学年以降の教材として扱い、この単元では先取りしない。

### 4. 等式と不等式は数量関係の表現として扱う

最後の小教材で、数量の等しい関係を `=`、大小関係を `≤`、`≥` で表す練習を行う。

記号操作そのものを独立した目的にはせず、具体的な数量関係を文字式へ翻訳する技能として扱う。

### 5. 確認演習を単元に対応させる

`src/content/middle-school/math/grade1/exercise-registry.ts` に8小教材それぞれの問題生成を追加する。

各小教材では3問の確認問題を生成し、単元末演習では8小教材から原則1問ずつ出題する。採点後の診断と復習リンクはADR 0043で導入した中学数学用演習UIを継続利用する。

### 6. 新しい外部依存関係は追加しない

教材データと演習生成は既存のAstro、TypeScript、ブラウザ標準APIだけで実装する。

公開リポジトリであるため、教材例・問題生成データ・ADRには秘密情報、個人情報、外部サービスの認証情報を含めない。

## Consequences

「文字と式」を学習指導要領上のまとまりに対応させながら、1ページごとの認知負荷を小さくできる。

単元末演習の8問を8小教材へ対応させられるため、どの技能を復習すべきかを診断しやすい。

一方、文字式の同値変形には複数の正しい表記が存在するため、自動採点では入力の正規化と許容解の設計が必要になる。現段階では第1学年で必要な簡単な表記に限定して正規化し、高度な数式同値判定は導入しない。
