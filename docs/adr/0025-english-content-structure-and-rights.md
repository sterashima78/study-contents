# ADR 0025: 英語教材を独立した型と表示責務で構成する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0007, ADR 0022, ADR 0023, ADR 0024

## Context

既存の数学・理科教材は、領域、単元、小単元という階層と、1ページ1技能の学習単位を共有している。一方、教材データ型や表示コンポーネントの一部は数学を起点としており、英文、段落、構文分析、言い換え、英作文などをそのまま数学用の語彙へ押し込むと責務が不明確になる。

現行の高等学校学習指導要領では、英語コミュニケーション系科目で聞くこと、読むこと、話すこと、書くことを実際のコミュニケーションで活用する学習が求められ、論理・表現系科目では話すことと書くことを中心に論理の構成や展開を扱う。2026-08-29時点で、令和8年度大学入学共通テストの英語はリーディングとリスニングが公開されている。

また、このリポジトリは公開されているため、教科書、市販問題集、入試問題、ニュース記事などの英文を教材本文として転載する構成は避ける必要がある。大学入試センター自身も公開過去問について、著作権処理等の関係で一部を省略して掲載する場合があることを明記している。

参考:

- 文部科学省「高等学校学習指導要領」 https://www.mext.go.jp/content/20220324-mxt_kouhou02-000021499_1.pdf
- 大学入試センター「令和8年度 本試験の問題」 https://www.dnc.ac.jp/kyotsu/kakomondai/r8/r8_honshiken_mondai.html

## Decision

### 1. 英語は独立したコースとして追加する

`/english/` を英語コースの入口とし、初期実装では次の4領域を提供する。

- 英語基礎
- 英文解釈
- 長文読解
- 論理・表現

各領域は2単元、各単元は2小教材とし、合計16小教材から開始する。1ページ1技能というADR 0001の方針は維持する。

### 2. 英語教材は専用のデータ型を持つ

`src/content/english/types.ts` に `EnglishArea`、`EnglishUnit`、`EnglishLesson`、`EnglishPassage` などを定義する。

数学用の `MathArea` や `MathLesson` に英語教材を合わせない。階層構造が同じであっても、英文本文、構文分析、権利情報など英語固有の意味を型として表現する。

### 3. 表示は英語専用コンポーネントと共通UIを組み合わせる

ページ構成は次の英語専用Astroコンポーネントが所有する。

- `EnglishCourseHome.astro`
- `EnglishAreaIndex.astro`
- `EnglishUnitIndex.astro`
- `EnglishLesson.astro`
- `EnglishPassage.astro`

パンくず、ヒーロー、一覧、概念カード、例題、誘導練習、ページナビゲーションなど、科目に依存しない表現は `src/components/ui/` の既存コンポーネントを再利用する。

英語固有のスタイルは英語コンポーネントのscoped styleが所有し、別の共有グローバルCSSは追加しない。これはADR 0022およびADR 0023のスタイル境界を維持する。

### 4. 収録する英文・設問はオリジナルを原則とする

英語教材の `EnglishLesson` は `rights: "original"` を必須とする。長文は `EnglishPassage.astro` で `ORIGINAL ENGLISH` と表示する。

教科書、市販問題集、大学入試問題、報道記事、Web記事など第三者の本文を教材データへ転載しない。外部資料を扱う将来機能を追加する場合は、引用要件、ライセンス、保存方法を別ADRで定義する。

### 5. 初期実装ではリスニングを扱わない

リスニングは音声ファイルの権利、音声生成方針、字幕・スクリプト、再生UI、キーボード操作、アクセシビリティをまとめて設計する必要があるため、今回の初期実装には含めない。

音声教材を追加する際は、リーディング教材へ単純に音声ファイルを付けるのではなく、別ADRで音声資産とアクセシビリティの方針を決定する。

### 6. ビルド出力をCIで検証する

英語コースの入口、基礎教材、長文読解教材、論理・表現教材について生成HTMLの代表マーカーを検証する `scripts/verify-english-build-output.mjs` を追加する。

PR CIとGitHub Pagesデプロイ前の両方でこの検証を実行し、静的ルートの欠落やAstroコンポーネントの未解決出力を検出する。

### 7. 新しい依存関係は追加しない

英語教材の初期実装は既存のAstroコンポーネントとブラウザ標準機能で実現する。2026-08-29時点で既存のAstro、Biome、MathLiveは利用中の公開最新版と一致しており、英語追加のためのライブラリ更新・追加は行わない。

## Consequences

英語教材を数学由来の型へ無理に合わせず、英文・構造分析・長文・表現という英語固有の概念を明示できる。共通UIは再利用するため、サイト全体の見た目とナビゲーションは既存科目と揃う。

初期段階でも基礎文法だけに偏らず、英文解釈、長文読解、論理・表現まで一つのコースで移動できる。一方、リスニング、単元末の総合演習、大学入試向け応用・発展パターンは今回の範囲外であり、今後の拡張として扱う。
