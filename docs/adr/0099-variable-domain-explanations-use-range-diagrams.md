# ADR 0099: 変域の説明では不等式と数直線の区間を対応させる

- Status: Accepted
- Date: 2026-09-04
- Related: ADR 0034, ADR 0035, ADR 0038, ADR 0043, ADR 0059, ADR 0097

## Context

ADR 0097 では、不等式や値の範囲において区間・端点が推論の根拠になる説明では、数直線の図を原則必須とした。

中学1年「変数と変域」では、変域を `0 ≤ x ≤ 5` のような不等式で表している一方、従来は文章と式だけで、0から5までのどの値を取るのか、0と5を含むことが図として示されていなかった。変域は後続の関数・グラフ学習の前提になるため、不等式の記号だけでなく、軸上の区間として理解できるようにする必要がある。

ただし、この段階で任意の関数 `y=f(x)` を導入すると、変域そのものと関数の値の変化を同時に学ばせることになり、学習目標が増える。変域の説明では、関数の形を持ち込まず、変数 x が取り得る範囲だけを直接図示する方が適切である。

## Decision

### 1. 「変数と変域」の概念説明に数直線グラフを配置する

`variables-domain` の `rule` 図として、x軸上の `0 ≤ x ≤ 5` を可視化する companion diagram を追加する。

図では次を同時に示す。

- x軸の周辺目盛り
- 0から5までの対象区間
- 0と5の塗りつぶした端点
- `0 ≤ x ≤ 5` の式
- 「この区間が x の変域」という説明
- 0と5も変域に含まれること

これにより、「最小値0」「最大値5」「その間の値」「端点を含む」という不等式の意味を一つの図で対応付ける。

### 2. 関数のグラフは導入しない

変域を説明するためだけに `y=x` や `y=x²` などの関数を例示しない。変域はまず1次元の区間として理解させ、関数の対応関係や座標平面上のグラフは後続レッスンで扱う。

将来、関数に定義域を指定したときの値域を扱う教材では、ADR 0059 の座標平面図の方針と本ADRの区間・端点の方針を併用する。

### 3. 本文も図の読み方と一致させる

概念説明に、不等式と数直線のグラフを対応させる説明を追加する。例題でも `0 ≤ x ≤ 5` を求めた後、数直線では0から5までの区間と端点で確認することを明記する。

学習目標とまとめにも、変域を不等式と数直線の両方で確認できることを反映する。

### 4. 既存の型付き描画基盤だけを使う

ADR 0034、ADR 0035、ADR 0097 に従い、`DiagramScene` と `segment`、`point`、`label` を利用する。任意SVG、`innerHTML`、外部画像、外部描画サービス、新しい描画ライブラリは追加しない。

図の `ariaLabel` には、0から5までの区間、端点、0と5を含むことを文章で記述する。色だけに意味を依存させず、式と文字ラベルを併記する。

### 5. 変数に関する図は既存ルーターから解決する

変域専用の図定義は `src/content/middle-school/math/grade1/variable-diagrams.ts` に置き、既存の `lesson-diagrams.ts` から取得する。既存の関数グラフ、符号付き数、幾何、データ活用などの図定義を変更せず、教材分野ごとの責務を保つ。

### 6. 依存関係は変更しない

今回の実装は既存の教材モデルと型付き描画基盤だけで完結する。新しい依存パッケージは追加せず、`package.json` と lockfile は変更しない。

ADR 0005 の依存バージョン方針は継続する。

## Consequences

- 変域を不等号の暗記ではなく、軸上の連続した区間として確認できる。
- 「以上」「以下」が端点を含むことを、式と塗りつぶした端点で対応付けられる。
- 関数のグラフを早期に持ち込まないため、変域という学習目標に集中できる。
- 後続の関数教材では、xの変域をグラフ上の対象部分へつなげやすくなる。
- 今後、`<` や `>` を含む変域を扱う場合は、端点を含まない表現を同じ図解方針で追加する必要がある。

## Security and privacy

- 公開リポジトリへ秘密情報、認証情報、個人情報を追加しない。
- 外部通信、ユーザー入力、ユーザーデータ保存を追加しない。
- 図は静的な型付きデータとして構成し、任意HTML・任意SVG・任意コード実行の経路を追加しない。
