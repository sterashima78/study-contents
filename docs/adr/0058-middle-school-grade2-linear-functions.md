# ADR 0058: 中学2年「一次関数」を8技能と図解で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0005, ADR 0054, ADR 0057

## Context

ADR 0054で中学2年数学コースを開始し、ADR 0057までに第2学年「A 数と式」の式の計算・文字式の活用・連立二元一次方程式を実装した。

現行の中学校学習指導要領（平成29年告示）解説 数学編の第2学年「C 関数」では、一次関数について理解すること、事象の中に一次関数として捉えられるものがあることを知ること、二元一次方程式を関数を表す式とみることが求められている。また、一次関数として捉えられる二つの数量について変化や対応の特徴を見いだし、表・式・グラフを相互に関連付けて考察し表現すること、一次関数を具体的な事象の考察に用いることが求められている。

同解説では、変化の割合が一次関数 y=ax+b のaに等しいこと、aがグラフの傾き、bがy軸との交点のy座標を表すこと、二元一次方程式のグラフが直線となり連立二元一次方程式の解を二直線の交点として捉えられることが示されている。

中学1年「比例・反比例」では、座標平面や関数グラフを既存のDiagram基盤で表示している。一次関数は式とグラフの相互関連が学習の中心になるため、中学2年でも文章説明だけではなく同じDiagram基盤を利用する必要がある。

## Decision

### 1. `functions` 領域に `linear-functions` 単元を追加する

第2学年の「C 関数」として、`middle-math2` に `functions` 領域と `linear-functions` 単元を追加する。

「A 数と式」とは別領域にしつつ、連立二元一次方程式で学んだ解の意味を既習事項として接続する。

### 2. 一次関数を8技能で構成する

1. 一次関数の意味を捉える
2. 変化の割合を求める
3. 表から一次関数の式を求める
4. 一次関数のグラフをかく
5. グラフから一次関数の式を求める
6. 二元一次方程式を直線として捉える
7. 連立方程式の解をグラフで捉える
8. 一次関数を具体的な事象に活用する

`y=ax+b` の形式だけを暗記させず、変化の割合、切片、表、式、グラフを相互に関連付ける。第7技能ではADR 0057で代数的に学んだ連立方程式の解を、二直線の交点として捉え直す。

### 3. 中学2年の関数図解を既存Diagram基盤へ接続する

`grade2/diagrams.ts` を追加し、`src/content/lesson-diagrams.ts` の `middle-math2` resolverへ接続する。

図解では次を可視化する。

- 一次関数の直線と切片
- xとyの増加量による変化の割合
- 傾きと切片から直線をかく手順
- 二点から式を求めるためのグラフ
- 二元一次方程式の直線
- 二直線の交点と連立方程式の解
- 具体的な事象を一次関数とみなした予測

独自のSVG文字列や外部グラフライブラリは導入せず、既存の `createCartesianTransform`、`createCartesianAxes`、`sampleFunctionPlot` などのDiagram APIを使用する。

### 4. 一次関数演習を領域専用レジストリへ分離する

`grade2/linear-function-exercise-registry.ts` を追加する。各教材は3問、単元末は8問とし、単元末では8技能を原則1問ずつ扱う。

中学1年で図形・データ演習を領域別レジストリへ分離している既存構成と合わせ、`MiddleMathExerciseSet.astro` は `middle-math2` かつ `functions` の場合だけ一次関数レジストリを選択する。

### 5. 具体的な事象はモデル化と解釈まで扱う

単なる代入計算にせず、1単位あたりの変化をa、開始時の値をbとして意味付けし、得られた値を温度や水量など元の数量として解釈する。

教材と演習の数値は全て説明用の架空データまたはブラウザ内で生成した数値とする。実在する学習者、学校、組織のデータは使用しない。

### 6. 外部依存関係とAI実行条件を変更しない

今回の教材追加では新しい外部ライブラリ、外部API、分析サービス、認証情報を追加しない。

ADR 0055・0056で進行中のAndroid向けWebLLM互換性・精度検証に関するruntime、model、context、prefill、自己診断などの条件には触れない。公開リポジトリに秘密情報、個人情報、認証情報を含めない。

## Consequences

中学1年の比例・反比例から中学2年の一次関数へ、表・式・グラフを同じ操作体系で発展させられる。連立方程式の解を二直線の交点として再解釈することで、「数と式」と「関数」の領域を接続できる。

一方、中学2年にもDiagram resolverと関数専用演習レジストリが追加される。今後の中学3年関数教材でも同様の構成を採る場合、学年間で共通化できる座標軸生成処理を別モジュールへ切り出すことを検討する。

## Validation

- `linear-functions` に8教材が登録されていること。
- 一次関数の主要教材でDiagram図解が表示されること。
- 各教材で3問、単元末で8問を生成できること。
- 単元末8問が8技能を1問ずつ診断できること。
- `middle-math2` の `functions` ルートが既存の汎用ページで静的生成されること。
- 学習指導要領参照が「A 数と式」と「C 関数」の公開状況と一致すること。
- `pnpm check` と `pnpm build` を含むCIが成功すること。
- package.json と pnpm-lock.yaml を変更していないこと。
