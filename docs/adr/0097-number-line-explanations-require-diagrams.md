# ADR 0097: 数直線を使う説明では位置関係と距離を図示する

- Status: Accepted
- Date: 2026-09-03
- Related: ADR 0034, ADR 0035, ADR 0038, ADR 0043, ADR 0059, ADR 0063

## Context

ADR 0038 では、位置関係や向きなどを文章だけで説明している箇所を優先して図示する方針を定めた。ADR 0059 では、そのうち座標平面上の位置関係が推論の根拠になる説明について図を原則必須とした。

一方、1次元の数直線については同じ基準が明文化されていなかった。中学1年「数直線と絶対値」では「0の右側に正の数、左側に負の数を並べる」「右にある数ほど大きい」「絶対値は0からの距離」と、位置と距離そのものを説明の根拠にしているにもかかわらず、companion diagram が登録されていなかった。また「正の数・負の数の意味」も、0を基準に反対向きの量を導入するため、数直線を併用すると正負の向きと基準を同時に確認できる。

中学3年「平方根」では、√2の近似位置や測定値の範囲を数直線で既に図示している。今後も教材ごとに個別判断すると、同じ種類の説明で図の有無がばらつくため、数直線を概念理解に使う場合の共通基準を定める。

## Decision

### 1. 数直線上の位置・向き・距離・区間が推論の根拠になる説明では図を原則必須とする

次のいずれかを学習者が数直線上で判断するレッスンでは、`rule` または `example`、原則として概念説明を行う `rule` に説明図を配置する。

- 0を基準にした正の数・負の数の位置
- 数の大小と左右の位置関係
- 絶対値と0からの距離
- 数直線上の移動として説明する加法・減法
- 不等式や値の範囲における区間・端点
- 平方根などの近似値の位置
- 測定値や誤差による真の値の範囲

式変形や符号規則だけで完結し、数直線上の位置を推論に使わない説明には図を必須としない。座標平面上の位置関係については ADR 0059 を適用する。

### 2. 図は本文の結論ではなく、本文の理由を可視化する

数直線を置くだけでは不十分とする。本文が判断に使う要素を図中で直接示す。

- 0と主要な目盛り
- 対象となる数の点
- 正負や大小を判断する左右の向き
- 絶対値を説明する0からの距離
- 区間を説明する端点と対象範囲

色だけに意味を持たせず、数値、距離、向き、区間などの文字ラベルを併記する。`ariaLabel` にも図が担う位置関係や距離を文章で記述する。

### 3. 既存の型付き描画基盤だけを使う

ADR 0034、ADR 0035、ADR 0038 と同じく、`DiagramScene` と既存の `DiagramElement` を利用する。任意SVG、`innerHTML`、実行可能な式、新しい外部描画ライブラリは追加しない。

数直線の目盛り、点、距離表示は `segment`、`point`、`label` など既存要素で構成し、教材データから任意コードを実行できる経路を増やさない。

### 4. 初期対応として中学1年の導入2教材を図示する

`src/content/middle-school/math/grade1/diagrams.ts` に次を追加する。

- `positive-negative-meaning`: 0を基準に、左側へ負の数、右側へ正の数が並ぶ `rule` 図
- `number-line-absolute-value`: −5と+5がどちらも0から距離5である `rule` 図
- `number-line-absolute-value`: −6から0までの距離6を示し、`|−6| = 6` と対応させる `example` 図

現在の `addition` と `subtraction` は、本文の主説明が符号と絶対値による計算規則であり、数直線上の移動を推論根拠としていないため今回の必須対象から除外する。将来、加法・減法を数直線上の移動として説明する内容を追加した場合は、その説明と同時に図を追加する。

中学3年「平方根」で既に実装済みの数直線図は、この方針を満たすものとして継続利用する。

### 5. 今後の教材追加時も同じ判定を使う

新しい数学レッスンや既存レッスンの改訂で、本文に「数直線」「右・左」「0からの距離」「区間」「範囲」などの表現があり、その位置関係が結論の理由になっている場合は、本文と同じ変更で companion diagram の要否を確認する。

図を追加しない判断をする場合は、数直線上の位置関係が補助的であり、図がなくても主学習目標を損なわない理由を関連ADRまたは後続ADRに記録する。

### 6. 依存関係は変更しない

今回の変更は既存の教材レジストリ、型付き描画基盤、ADRだけで実装する。新しいライブラリ、外部サービス、外部画像、外部フォントは追加しない。

ADR 0005の最新版確認・固定方針は継続する。本変更ではライブラリAPIを変更せず、依存関係更新を伴わない。

## Consequences

- 数直線を頭の中だけで再構成させる説明が減り、0、正負、大小、距離を同じ図で対応付けられる。
- 絶対値を単なる符号除去の規則ではなく、0からの距離として理解しやすくなる。
- 数直線を使う新規教材で、図を付けるかどうかの判断基準が統一される。
- 図と本文の数値が対応するため、本文の例や範囲を変更した場合は companion diagram も同時に更新する必要がある。
- 図の追加に伴い、ラベル衝突、モバイル表示、`ariaLabel` の内容を継続して確認する必要がある。

## Security and privacy

- 公開リポジトリへ秘密情報、認証情報、個人情報を追加しない。
- 外部通信、ユーザー入力、ユーザーデータ保存を追加しない。
- 図は静的な型付きデータとして構成し、任意HTML・任意SVG・任意コード実行の経路を追加しない。
