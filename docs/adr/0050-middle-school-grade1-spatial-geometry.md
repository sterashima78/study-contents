# ADR 0050: 中学1年「空間図形」を位置関係・表現と計量の2単元に分ける

- Status: Accepted
- Date: 2026-08-30

## Context

ADR 0048までに、中学1年数学の「数と式」「比例・反比例」「平面図形」を1ページ1技能で整備した。

現行の中学校学習指導要領（平成29年告示）数学第1学年「B 図形」の空間図形では、空間における直線や平面の位置関係、扇形の弧の長さと面積、基本的な柱体・錐体・球の表面積と体積を扱う。また、空間図形を直線や平面図形の運動によって構成されるものと捉えること、見取図・展開図・投影図を用いて空間図形を平面上に表現し、その表現から性質を見いだすことが求められる。

これらを一つの単元にまとめると、位置関係の認識、立体表現の読み書き、図形の運動、扇形の計量、立体の表面積・体積という異なる技能が混在する。さらに、既存の単元末演習は8問を基本としており、8技能程度に分けると各技能を1問ずつ診断しやすい。

## Decision

### 1. 学習指導要領上の「空間図形」をサイト上では2単元に分ける

中学1年数学の `geometry` 領域に次の2単元を配置する。

- `spatial-relationships-representations`: 空間図形：位置関係と表現
- `solid-measurement`: 空間図形：計量

これは学習指導要領の内容を変更するものではなく、ADR 0001の「1ページ1技能」を維持するための教材上の分割である。

### 2. 「位置関係と表現」を8技能に分割する

次の順序で学習する。

1. 空間の直線どうしの位置関係
2. 直線と平面の位置関係
3. 平面どうしの位置関係
4. 見取図から立体を読む
5. 展開図と立体を対応させる
6. 投影図を読む
7. 平面図形の平行移動でできる立体
8. 回転体

直線や平面の位置関係では、平行・垂直に加えて「ねじれの位置」を扱う。投影図では立面図と平面図を扱う。

### 3. 「計量」は8技能に分割する

後続実装では次の8技能を基本とする。

1. 扇形の弧の長さ
2. 扇形の面積
3. 柱体・円柱の表面積
4. 錐体・円錐の表面積
5. 柱体・円柱の体積
6. 錐体・円錐の体積
7. 球の表面積
8. 球の体積

一つのページで表面積と体積を同時に新規導入せず、計量技能を分離する。

### 4. 空間図形の理解に共有Diagram基盤を利用する

見取図、展開図、投影図、直線・平面の位置関係、平面図形の運動、回転体は既存のDiagram基盤で図示する。

図は立体感を装飾的に表すためではなく、どの辺・面・対応が問題になっているかを明示するために用いる。見取図だけでは保存されない長さや角度があることにも注意を促し、必要に応じて展開図や投影図と関連付ける。

### 5. 図形領域の演習レジストリを継続利用する

ADR 0048で導入した `geometry-exercise-registry.ts` に空間図形の問題生成を追加する。

各小教材は3問、各単元末は8問とし、単元末では原則として8技能から1問ずつ出題する。自由な3D作図そのものの自動採点は導入せず、位置関係、図の読み取り、対応関係、図形の運動を問う。

### 6. 新しい外部依存関係は追加しない

既存のAstro、TypeScript、ブラウザ標準API、共有Diagram基盤を使用する。

公開リポジトリであることを前提とし、教材、図解データ、演習データ、ADRに秘密情報、個人情報、外部サービスの認証情報を含めない。

## Consequences

空間図形を「位置関係と表現」と「計量」に分けることで、立体を読む技能と計算技能を別々に身に付けられる。

各単元を8技能にするため、既存の単元末8問による診断と対応しやすい。見取図・展開図・投影図や図形の運動を図示することで、文章だけでは捉えにくい空間的な関係を比較できる。

一方、教材上の単元名は学習指導要領の見出しより細かくなる。そのため、学習指導要領参照では両単元が同じ第1学年「B 図形」の空間図形に属することを維持する。
