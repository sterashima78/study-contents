# ADR 0014: 化学を現行学習指導要領に沿って追加し練習データから確認演習を構成する

- Status: Accepted
- Date: 2026-08-29

## Context

高校「化学」の教材を、既存の数学科目、化学基礎、物理基礎と同じ科目、領域、単元、小単元の階層で提供する。

文部科学省「高等学校学習指導要領（平成30年告示）解説 理科編 理数編」では、化学の内容は次の5領域で構成されている。

1. 物質の状態と平衡
2. 物質の変化と平衡
3. 無機物質の性質
4. 有機化合物の性質
5. 化学が果たす役割

化学基礎で採用した共通教材レンダリングは、科目情報と教材データを差し替えることで化学にも利用できる。一方、化学は計算、化学式、用語、反応の説明など回答形式が混在し、小単元数も化学基礎より多い。教材本文と確認問題を別々に大量管理すると、問題文・用語・正答の不整合が生じやすい。

依存関係はADR 0005の方針に従う。2026-08-29時点で使用中のAstro 7.2.9、MathLive 0.110.0、Biome 2.5.10は各公開パッケージの最新リリースとして確認できており、化学追加に新しい外部ライブラリは必要ない。pnpmはプロジェクト方針どおり12.0.0を維持する。

公開リポジトリであるため、教材表示や採点のために秘密情報、外部APIキー、利用者データをコードへ含めないことも継続して必要である。

## Decision

### 1. 化学の科目構成は現行学習指導要領の5領域に合わせる

科目トップでは次の5領域を直接示す。

- 物質の状態と平衡
- 物質の変化と平衡
- 無機物質の性質
- 有機化合物の性質
- 化学が果たす役割

各領域を学習しやすい単元へ分割し、全32小教材を1ページ1技能の粒度で提供する。各小教材は、目標、概念説明、例題、直後の練習、3問確認、まとめを持つ。

### 2. ADR 0011で採用した共通教材レンダリングを再利用する

`MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` と既存の教材データ型を化学でも再利用する。

`chemistryCourse` を共通科目情報へ追加し、表示タイトル、URL、パンくずリストを `/chemistry/` 配下へ切り替える。内部の `Math*` 名称はADR 0011と同じく現行実装名として維持し、この追加だけを理由に全面改名しない。

### 3. 小教材の直後の練習を3問確認演習の単一の情報源として利用する

化学では、各小教材の `practice.steps` に3つの問いと許容解答を持たせる。`src/content/chemistry/exercise-registry.ts` はこのデータを読み取り、小教材の3問確認と単元末演習を生成する。

これにより、教材本文の練習と別の問題レジストリへ同じ概念・正答を二重登録することを避ける。化学基礎の既存レジストリは変更せず、化学だけをこの方式へ移行する。

単元末演習は化学基礎と同じ6問を基本とし、基礎問題を優先しつつ応用・難問を混ぜる。単元内の問題数や難易度候補が不足する場合は、重複しない残りの問題から6問まで補完する。

### 4. 科目一覧と静的ルートへ化学を追加する

ルートの科目一覧へ化学を追加し、`/chemistry/` から5領域、単元、小教材、単元末演習へ進めるようにする。

ADR 0007の「科目一覧 → 科目ホーム → 領域 → 単元 → 小単元」というナビゲーション構造は維持する。

### 5. CIで化学の代表的な生成HTMLを検証する

既存の生成HTML検査へ次を追加する。

- 化学トップに5領域と全32小教材が表示されること
- 理想気体の状態方程式を含む代表小教材が生成されること
- 電池と電気分解の単元末演習が6問構成で生成されること
- 合成高分子の小教材が生成されること

ADRの採番・Status・参照整合性はADR 0012で導入した既存CIをそのまま適用する。

### 6. 教材データは静的に保持し、実行時の外部依存を追加しない

教材本文と演習データはリポジトリ内のTypeScriptデータとして保持し、ブラウザから外部APIへ教材や解答を送信しない。秘密情報、認証情報、非公開データは追加しない。

長い教材データは既存科目と同様にBiomeのフォーマット対象から除外するが、リントは有効なまま維持する。ページ、共通コンポーネント、検証スクリプトは通常のBiome検査対象とする。

## Consequences

現行学習指導要領の5領域を、既存サイトと同じ操作感で化学として追加できる。化学基礎から続けて、状態・平衡、無機、有機、高分子、社会での利用まで学習できる。

確認演習を `practice.steps` から構成することで、教材本文と演習の正答が乖離するリスクと重複管理量を減らせる。一方、直後の練習と3問確認で同じ問いを再利用するため、将来問題の多様性を増やす場合は、教材データへ追加問題プールを持たせる拡張を検討する。

新規依存関係、実行時外部API、秘密情報を追加しないため、公開リポジトリにおけるサプライチェーンリスクや情報漏えい面の変更は最小限に保たれる。
