# ADR 0093: 中学英語を3学年79教材で完成させる

- Status: Accepted
- Date: 2026-09-02
- Related: ADR 0005, ADR 0025, ADR 0039, ADR 0073, ADR 0092

## Context

ADR 0092では中学英語の公開を開始し、中学1年のbe動詞と一般動詞の現在形を16技能で実装した。一方、中学校学習指導要領（平成29年告示）解説 外国語編が示す言語材料には、現在・過去・進行形、現在完了・現在完了進行、未来表現、助動詞、比較、不定詞、動名詞、分詞、受け身、関係代名詞、基本的な仮定法、重文・複文、SVOO・SVOC、There + be、It + be ... for ... to、疑問詞を含む節などが含まれる。

学習指導要領はこれらの文法事項を第1〜3学年へ一律に固定配当していない。したがって、本サイトでは3学年全体で中学校外国語の言語材料を扱いながら、学年表示は学習の難易度と前提関係を考慮したサイト独自の段階配置として明示する必要がある。

また、中学校外国語は「聞くこと」「読むこと」「話すこと［やり取り］」「話すこと［発表］」「書くこと」の五つの領域を関連付ける。静的教材サイトで自動音声評価や自由会話を安全かつ一貫して実装するには、マイク権限、音声データ、評価基準、アクセシビリティ、プライバシーの追加設計が必要である。一方、端末・ブラウザ内蔵のSpeech Synthesis APIを利用すれば、外部APIや音声ファイルを追加せず、掲載するオリジナル英文を聞く補助練習を提供できる。

## Decision

1. 中学英語を中学1〜3年の3コースとして公開し、3学年合計79個の小教材を「1ページ1技能」で構成する。
2. 中学1年は既存16教材を保持し、can、命令文、提案、現在進行形、過去形、目的格・所有表現、指示語、前置詞、疑問詞、接続詞、統合表現を追加して36教材とする。
3. 中学2年は未来表現・助動詞、不定詞・動名詞・比較、過去進行形、There is / are、SVOO・SVOC、疑問詞 + to不定詞、because / when / if、that節を21教材で扱う。
4. 中学3年は現在完了・現在完了進行・受け身、関係代名詞、現在分詞・過去分詞による名詞修飾、人 + to不定詞、形式主語、形容詞 + that節、疑問詞節、動詞 + 人 + 動詞原形、基本的な仮定法、感嘆文・選択疑問、統合表現を22教材で扱う。
5. 学年配当はサイト独自の段階配置であり、学習指導要領上の固定配当ではないことを、中学英語トップと学習指導要領参照表示に明記する。
6. 各教材は要点、オリジナル例文、分析、誘導練習、独立した確認3問、まとめを持つ。各単元は8問の単元末演習と小単元別診断を持つ。
7. 最初の16教材では既存の専用問題バンクを維持する。追加教材は教材自身の練習データを演習生成の単一の情報源として再利用し、教材と演習の内容ずれを避ける。
8. 英文、例文、短い読解文、設問、解説はすべて本リポジトリ向けのオリジナルとする。教科書、市販問題集、入試問題、記事本文、歌詞等を転載しない。
9. 語彙は中学校段階で必要となる高頻度・身近な語を各教材の文脈へ段階的に配置する。特定の教科書や市販単語集の語彙一覧を複製しない。
10. 「聞くこと」の補助として、教材の代表英文をブラウザ内蔵Speech Synthesis APIで再生できるようにする。外部音声API、外部音声資産、マイク、録音、音声アップロード、個人データ保存は使用しない。端末ごとに声質・発音が異なるため、音声は補助教材であり発音の唯一の正解とは扱わない。
11. 自動音声認識による発音採点や自由会話の自動評価は今回導入しない。「話すこと」は例文・質問応答・発表用の文構成を声に出して練習できる教材設計までとし、録音を要求しない。
12. 学習指導要領参照は中1・中2・中3で同じ文部科学省の中学校外国語資料を参照しつつ、表示上の学年とルートを個別に持たせる。既存の全科目参照表を複製せず、英語3学年の参照を合成するリゾルバを使う。
13. 高校英語の既存URL、教材内容、演習仕様は変更しない。中学英語は既存の英語共通コンポーネントを利用する。
14. 公開リポジトリであることを踏まえ、秘密情報、個人情報、位置情報、外部分析SDK、新規外部APIを追加しない。

## Consequences

- 中学1〜3年の主要な言語材料を、79個の短い教材として一続きに学習できる。
- 文法事項を単独の暗記項目ではなく、身近な情報のやり取り、短い読解、説明、理由・意見の表現へ段階的に接続できる。
- 各教材の練習データを追加教材の自動採点にも再利用するため、問題バンクを二重管理する範囲を抑えられる。
- Speech Synthesis APIは端末依存であり、利用できない環境もある。その場合でも本文・例文・演習は完全に利用できるよう、音声を必須機能にはしない。
- 五領域すべてを人間教師と同等に自動評価するものではない。特に発音、流暢さ、対話の適切さは自動採点対象外である。
- 学年別教材数は本サイトの教材粒度による値であり、学習指導要領の項目数を意味しない。
