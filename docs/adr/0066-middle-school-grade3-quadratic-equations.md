# ADR 0066: 中学3年「二次方程式」を9教材で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0054, ADR 0062, ADR 0063, ADR 0065

## Context

中学校学習指導要領（平成29年告示）解説 数学編の第3学年「A 数と式」A(3)では、二次方程式の必要性と意味及び解の意味を理解し、因数分解、平方の形への変形、解の公式を用いて解くことが求められている。また、因数分解や平方根の考えを基に解法を考察・表現し、二次方程式を具体的な場面で活用することが求められている。

内容の取扱いでは、実数の解をもつ二次方程式を対象とし、因数分解や平方完成では `ax²=b`（a、bは有理数）及び `x²+px+q=0`（p、qは整数）を扱う。因数分解はA(2)の公式を利用できるものを中心とし、平方の形への変形はxの一次項の係数が偶数のものを中心にする。

解説では、因数分解による方法を「AB=0ならA=0またはB=0」から一次方程式へ帰着させる方法、平方完成による方法を `X²=k` へ帰着させて平方根の考えを用いる方法として位置付けている。解の公式は平方完成の操作の反復を省略して能率的に解くためのもので、数値係数の平方完成と対比しながら導かれる過程を知ることが重視される。

具体的な活用では、求めたい数量を文字で表し、数量関係から方程式をつくり、解き、得られた解を問題に即して解釈する一連の活動が示される。二次方程式では解が二つあることや平方根を含むことがあるため、得られた解が元の事象で適切か吟味することが特に重要である。

中学3年「A 数と式」はADR 0063の平方根、ADR 0065の式の展開と因数分解まで実装済みである。本単元はこれら二つの既習事項を直接利用してA(3)へ接続する。

## Decision

### 1. A(3)を「二次方程式」1単元・9教材で構成する

`numbers-expressions` 領域へ `quadratic-equations` 単元を追加し、次の9教材に分ける。

1. 二次方程式の意味と解を捉える
2. 平方根の考えで二次方程式を解く
3. 因数分解して二次方程式を解く
4. 平方の形に変形して二次方程式を解く
5. 解の公式が生まれる流れを知る
6. 解の公式で二次方程式を解く
7. 二次方程式の解法を選ぶ
8. 具体的な場面から二次方程式をつくる
9. 二次方程式の解を場面に戻して吟味する

1ページ1技能を維持し、公式の暗記、方程式化、解の吟味を同じページへ詰め込まない。

### 2. 解法を既習事項への帰着として関連付ける

- `X²=k` は平方根の考えへ帰着する。
- 因数分解は `AB=0` から二つの一次方程式へ帰着する。
- 平方完成は `X²=k` の形を作って平方根へ帰着する。
- 解の公式は平方完成の反復を一般化・省略したものとして扱う。

解法選択の教材を独立させ、計算を始める前に式の形を見る習慣を作る。

### 3. 学習指導要領の取扱い範囲を超えない

実数解をもつ二次方程式を扱う。因数分解はA(2)で扱った公式を利用できるものを中心とし、平方完成は一次項の係数が偶数の例を中心にする。

判別式による解の個数の体系的分類、複素数解、高次方程式など高校以降の内容へ広げない。`b²−4ac` は解の公式内の計算として扱い、判別式の単元にはしない。

### 4. 解の公式は導出過程と利用を分ける

「解の公式が生まれる流れ」と「解の公式で解く」を別教材にする。前者では数値係数の平方完成と一般式の変形を対応させ、公式が突然与えられた手順に見えないようにする。

後者では標準形への整理、a・b・cの符号、`−b`、根号内、`2a`を順に確認して計算する。

### 5. 活用は方程式化と解の吟味を分ける

文部科学省解説の例に対応して、正方形の一辺をxとし、一方を1長く他方を1短くした長方形の面積から `(x+1)(x−1)=24` を作る場面を扱う。

方程式をつくる教材では数量関係のモデル化に集中し、次の教材で得られた二つの解を長さなどの条件へ戻して吟味する。方程式の解と問題の答えが一致しない場合があることを明確にする。

### 6. 既存の型付きDiagram基盤で必要性とモデル化を可視化する

`grade3/quadratic-diagrams.ts` を追加し、1辺xの正方形から辺 `x+1`、`x−1` の長方形へ変形する場面を型付きDiagramで示す。

任意SVG、`innerHTML`、外部描画ライブラリは追加しない。Diagramは二次方程式の必要性、方程式化、解の吟味の3教材で共有する。

### 7. 中3演習レジストリを3単元対応へ拡張する

既存 `grade3/exercise-registry.ts` へ本単元の9教材を追加する。

- 各教材: 3問
- 単元末: 8問
- 9教材のうち連続する8教材を出し、再生成ごとに開始位置を変える
- 解の組は原則として「小さい順にカンマ区切り」と問題文で回答形式を固定する
- 方法選択は「平方根」「因数分解」「解の公式」など短い評価点を採点する
- 活用は長い説明文の完全一致を求めず、方程式または事象に即した数値を採点する

### 8. 公開情報と学習指導要領参照を更新する

中3トップと中学数学入口を、数と式3単元公開へ更新する。次の主要対象はC(1)「関数 y=ax²」とする。

`curriculum-references.js` の `middle-math3` noteもA(3)二次方程式までの公開状態へ更新する。

### 9. 公開リポジトリの安全境界とAI診断条件を維持する

教材・演習には固定の数学例またはブラウザ内生成値のみを使用し、実在する生徒・学校・組織のデータ、個人情報、秘密情報、認証情報を追加しない。

新規依存関係、外部API、分析SDKは追加しない。`package.json` と `pnpm-lock.yaml` は変更しない。

既存ADRでAcceptedとなっているStudy AIのruntime、model ID、context/prefill、自己診断条件も変更しない。

## Consequences

- 中学3年「A 数と式」の平方根、簡単な多項式、二次方程式が一連の流れとして接続される。
- 因数分解と平方根が二次方程式の解法として再利用される意味を確認できる。
- 解の公式を平方完成と関連付けて理解できる。
- 方程式をつくることと、得られた解を事象に戻して吟味することを別技能として練習できる。
- 次の関数 `y=ax²` へ、二次式を扱う経験を接続できる。

- 学習指導要領参照
- formula coverage
- application and advanced content
- Diagramデータ
- component style boundaries
- study AI boundaries
- Astro build
- 生成HTML検証

加えて次を確認する。

- `numbers-expressions/quadratic-equations` の9教材と単元末演習が静的生成されること。
- 各教材で3問、単元末で8問の演習が生成されること。
- 単元末演習で同じ1教材だけが恒常的に除外されないこと。
- 正方形から長方形へのDiagramが既存validatorを通ること。
- 実数解の範囲、因数分解・平方完成の取扱いが学習指導要領の範囲と整合すること。
- `middle-math3` の公開情報・学習指導要領参照がA(3)追加を反映すること。
- `package.json`、`pnpm-lock.yaml`、Study AI runtime・モデル・診断条件が変更されていないこと。

教材内容は文部科学省「中学校学習指導要領（平成29年告示）解説 数学編」第3学年 A(3)を基準に確認する。
