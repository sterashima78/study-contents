# ADR 0053: 中学1年「データの活用」を分布と多数回の試行の2単元で実装する

- Status: Accepted
- Date: 2026-08-31

## Context

ADR 0043以降、中学1年数学について「A 数と式」「C 関数」「B 図形」を1ページ1技能で段階的に実装してきた。ADR 0050で空間図形を「位置関係と表現」「計量」に分割し、その両方の実装も完了したため、第1学年の主要領域として残る「D データの活用」を追加する。

現行の中学校学習指導要領（平成29年告示）解説 数学編の第1学年「D データの活用」では、データの分布について、ヒストグラムや相対度数などを用いて整理し傾向を読み取ること、範囲や累積度数を扱うこと、必要に応じて代表値や累積相対度数を用いること、階級幅などによって分布の見え方が変わることを踏まえて批判的に考察することが求められる。

また、不確定な事象について、多数回の観察や試行から得られる相対度数が一定の値の近くで安定する場合があることを基に、起こりやすさを確率として捉え、過去の多数の観察結果を将来の傾向の予測に活用することが求められる。

既存の中学数学教材では、小教材ごとに説明・例題・練習・3問の確認演習を持ち、単元末では8問を生成して理解度を診断する。データ領域でもこの操作体系を維持しつつ、表やグラフの読み取りを文章だけに依存しない構成が必要である。

## Decision

### 1. `data` 領域を2単元に分ける

中学1年数学に `data` 領域「データの活用」を追加し、次の2単元を配置する。

- `data-distribution`: データの分布
- `experimental-probability`: 多数回の試行と確率

学習指導要領の「D データの活用」に対応しつつ、分布の整理・考察と、不確定な事象の起こりやすさを別の学習単位として扱う。

### 2. 「データの分布」は6技能に分ける

次の順序で学習する。

1. 範囲・階級・度数を整理する
2. ヒストグラムを作り、分布を読む
3. 代表値を分布と結び付ける
4. 相対度数で割合を比べる
5. 累積度数・累積相対度数を読む
6. 分布を批判的に考察する

代表値は単独の計算技能として終わらせず、分布の形や極端な値と合わせて使う。批判的考察では、階級幅、代表値、データの集め方や出典によって結論の妥当性が変わり得ることを扱う。

### 3. 「多数回の試行と確率」は2技能に分ける

次の2技能を扱う。

1. 多数回の試行から確率を捉える
2. 観察結果から起こりやすさを予測する

第1学年では、場合の数による理論確率を先取りせず、多数回の試行・観察で得た相対度数を基に起こりやすさを捉える。確率による予測は見積もりであり、一回ごとの結果や将来の回数を確定するものではないことを明示する。

### 4. 既存のDiagram基盤でデータ表現を図示する

`data-use-diagrams.ts` を追加し、次の関係を模式図で表す。

- 度数分布とヒストグラム
- 平均値・中央値・極端な値の位置関係
- 度数と相対度数の違い
- 累積度数の増加
- 階級幅によるヒストグラムの見え方の違い
- 多数回の試行で相対度数が安定していく様子
- 過去の相対度数から将来の回数を見積もる流れ

新しいグラフ描画ライブラリは追加せず、既存の共有Diagram基盤を使用する。

### 5. データ領域専用の演習レジストリを追加する

`data-exercise-registry.ts` を追加し、既存の数と式・関数用レジストリおよび図形用レジストリから分離する。

各小教材は3問、各単元末は8問を生成する。「データの分布」は6技能のため単元末8問では先頭から一部技能を再出題し、「多数回の試行と確率」は2技能を繰り返して8問を構成する。単元末診断では各問題を対応教材へ戻せる状態を維持する。

### 6. 教材データは固定またはその場で生成した架空データだけを使う

公開リポジトリであることを前提に、実在する学習者の成績、アンケート、行動履歴などの個人データを教材へ埋め込まない。教材内の人数、待ち時間、試行結果などは、説明用に作成した架空データまたはブラウザ内で生成する数値だけを用いる。

外部分析サービス、外部API、認証情報は追加しない。

### 7. 外部依存関係は追加しない

Astro、TypeScript、ブラウザ標準API、既存の共有Diagram基盤で実装する。今回の教材追加のための依存パッケージ更新は不要とし、既存依存関係の最新状況は実装時に確認する。

## Consequences

中学1年数学の「A 数と式」「B 図形」「C 関数」「D データの活用」を一つのコースカタログで学習できるようになる。

データの整理から批判的考察、多数回の試行による確率までを分けることで、計算だけでなく、表現を読み、根拠を確かめ、結論の妥当性を考える流れを教材として示せる。

一方、「データの分布」は6技能、「多数回の試行と確率」は2技能であるため、8問固定の単元末演習では技能ごとの出題数が均等にならない。今後、診断結果の粒度をさらに上げる場合は、単元ごとに問題数を可変にするか、技能ごとの最低出題数を定義する別ADRを検討する。
