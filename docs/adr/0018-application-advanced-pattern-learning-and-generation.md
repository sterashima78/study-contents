# ADR 0018: 応用・発展教材を解法パターン単位で構成し安全に問題生成する

- Status: Accepted
- Date: 2026-08-29

## Context

ADR 0001 では基礎教材を「1ページ1技能」とし、考え方、例題、直後の練習を短い単位で学ぶ構成を定めた。ADR 0017 では大学入試を見据えた教材を完全独自作成し、権利状態を管理する方針を定めた。

最初の試行では数学I「二次関数」に複数の独立問題を並べたが、問題だけを追加すると、学習者は「何を見抜けばその解法を選べるか」を体系的に学びにくい。また「入試標準」というラベルは、教材内の基礎・応用・発展という難易度の流れと別軸になり、他単元へ横展開すると分類が分かりにくくなる。

一方、応用・発展問題には、係数や長さなどのパラメータを変えても同じ解法構造を保てるパターンがある。この種の問題は、条件を壊さない生成規則を先に定義すれば、完全独自問題を繰り返し練習する用途に利用できる。

図形、グラフ、データの読み取りが本質になる問題では、文章だけで説明するより図を同時に提示した方が理解しやすい。公開教材の権利管理を単純にするため、図は原則として教材データからSVG等でプログラム生成し、外部画像の転載に依存しない。

## Decision

### 1. 「入試標準」を教材の難易度ラベルとして使用しない

大学入試を見据えた内容であっても、教材上の難易度は次の語で統一する。

- 応用: 既習技能を2つ以上組み合わせる、または解法選択が必要な問題
- 発展: 場合分け、複数条件の同時処理、複数単元の融合など、より多段階の判断が必要な問題

「大学入試」は教材の目的や対象を説明する文脈では使用してよいが、問題難易度の名称にはしない。

### 2. 応用・発展教材は「解法パターン」を学習単位とする

1つの応用・発展教材は、問題を羅列するのではなく、解法を選ぶための着眼点ごとにパターン化する。

各パターンは原則として次の順序にする。

1. 考え方・着眼点
2. 例題
3. ステップバイステップの練習問題
4. 実践問題
5. 必要に応じて別問題の生成

考え方では、公式だけでなく「問題文のどの条件を見て、その解法を選ぶか」を説明する。

例題では、最終結果だけでなく判断の理由を含む途中過程を段階的に示す。

ステップ練習では、学習者に途中式や条件整理を順番に入力させ、例題の思考過程を再現させる。

実践問題では誘導を減らし、学習者自身が解法を選ぶ。

### 3. 問題生成はパターンごとに明示的に許可する

全問題をランダム生成しない。生成可能なパターンだけに `generatorKey` を持たせる。

生成器は、問題文と正答を別々に作らず、同一の生成パラメータから次を同時に作る。

- 問題文
- 条件
- 解答
- 解答過程
- 必要なら図に渡す値

生成パラメータは、解が存在すること、難易度が極端に変化しないこと、学習対象の解法パターンが維持されることを保証できる有限集合または明示的な制約から選ぶ。

生成規則の正しさを単純に保証できないパターンには生成器を付けない。

### 4. 生成問題もADR 0017の独自作成方針に従う

生成器は、外部問題の文章や数値を保存して組み替える方式では作らない。

完全独自に設計した問題テンプレートと数学的制約から生成する。したがって、生成器のテンプレート、解法、図も公開前に権利レビューの対象とする。

パターン定義にはADR 0017と同じ権利メタデータを持たせる。

### 5. 図が理解に必要なパターンには教材データから図を生成する

次のような問題では図を積極的に提示する。

- 図形の長さ・面積を関数化する問題
- 放物線と直線の位置関係を扱う問題
- 軌跡・領域・ベクトルなど位置関係が本質の問題
- 表やグラフの読み取りが必要な問題

初期実装ではSVGを使用し、次を満たす。

- 外部画像をコピーしない
- `aria-label` または説明文を持たせる
- 図だけに依存せず、問題文にも必要条件を書く
- 縮尺が厳密でない場合は概念図であることを明示する
- 数値を図に表示する場合は教材データと整合させる

### 6. 応用・発展教材データをCIで検証する

`src/content/entrance/` 以下の応用・発展教材は、権利メタデータに加えて次を検査する。

- 難易度が `application` または `advanced` である
- 各パターンに考え方、例題、ステップ練習、実践が存在する
- ステップ練習に1段階以上の入力項目がある
- `generatorKey` がある場合は許可済み生成器のキーである
- `entrance-standard` を難易度値として使用していない

### 7. 最初の実装対象

数学I「二次関数」の5テーマを次のパターンとして再構成する。

- 発展: 定義域と軸の位置による場合分け
- 応用: 放物線と直線が接する条件
- 発展: 2つの実数解がともに正となる条件
- 応用: 図形を二次関数にして最大化する
- 応用: 条件から二次関数を決定する

このうち、数学的制約を単純に保証できるパターンから問題生成を導入する。

## Consequences

問題数を増やす前に、解法選択の理由を学ぶ構造を共通化できる。基礎教材と同じ「説明から練習へ進む」学習体験を維持しながら、より複雑な問題へ段階的に進める。

生成可能なパターンでは、特定の固定問題を暗記するのではなく、同じ着眼点を別の数値や条件で繰り返し練習できる。

一方、生成器には数学的な不変条件の設計とテストが必要になるため、すべての問題を生成対象にはしない。図についても、見栄えより問題条件との整合性とアクセシビリティを優先する。
