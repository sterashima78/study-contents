# ADR 0079: 中学1年「大地の成り立ちと変化」を15技能で実装する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0034, ADR 0039, ADR 0075, ADR 0076, ADR 0077

## Context

中学校学習指導要領（平成29年告示）解説 理科編の第1学年第2分野（2）「大地の成り立ちと変化」は、次の内容を扱う。

- 身近な地形や地層、岩石の観察
- 地層の重なりと過去の様子
- 火山活動と火成岩
- 地震の伝わり方と地球内部の働き
- 自然の恵みと火山災害・地震災害

学習では個別用語の暗記だけでなく、観察記録や資料を分析し、地層の重なり方、マグマの粘性と火山の形、地震波と震源距離、プレートの動きなどの関係性を見いだす必要がある。

また、火山・地震は実際の災害と直結する。学習教材を現実の避難判断に代用させず、実際の災害時には最新の公的情報を優先する境界が必要である。

## Decision

1. `earth` 領域に `earth-formation-change` 単元を追加し、15教材で構成する。
2. 教材順は、観察 → 侵食・運搬・堆積 → 地層形成 → 堆積岩 → 地層の広がり → 化石 → 断層・褶曲 → 火山 → 噴出物 → 火成岩 → 地震波 → 初期微動継続時間 → マグニチュード/震度 → プレート/土地変化 → 恵み/災害とする。
3. 地層では観察事実と考察を明示的に分け、複数地点の柱状図や特徴的な層を比較する考え方を扱う。
4. 火山ではマグマの粘性と火山の形・噴出物を関連付け、火成岩では冷却過程と組織を関連付ける。
5. 地震ではP波・S波、初期微動継続時間と震源距離の定性的関係、マグニチュードと震度、プレートの動き、津波等を扱う。
6. 災害教材では、記録や資料から仕組みを学ぶ。現在の危険度や避難判断を教材だけで行わせず、「実際の災害時は最新の公的情報・避難指示を優先する」と明記する。
7. Diagramは既存の型付き `DiagramScene` APIだけを使用し、新規描画ライブラリや任意SVG/HTMLを導入しない。
8. 演習は各教材3問、単元末8問とし、15技能を再生成時に巡回させる。
9. 教材・演習のデータは静的またはブラウザ内生成のみとし、外部API、位置情報、実在生徒データ、個人情報を利用しない。
10. `package.json`、lockfile、Study AI runtime/model設定は変更しない。既存のAI診断ADRを維持する。

## Consequences

- 中学1年理科の「エネルギー」「粒子」「生命」「地球」の4領域が公開状態になる。
- 地層、火山、地震を独立した暗記事項ではなく、大地の変化として連続的に学べる。
- 災害学習を扱いつつ、教材とリアルタイム防災情報の役割を明確に分離できる。
- 次の中学理科実装対象を第2学年へ移せる。
