# ADR 0100: 概念説明では必要に応じて型付きテーブルを併用する

- Status: Accepted
- Date: 2026-09-04
- Related: ADR 0004, ADR 0005, ADR 0022, ADR 0023, ADR 0046, ADR 0099

## Context

数学教材の概念説明は、文章と式を中心に構成し、必要な箇所では companion diagram を追加している。中学1年「比例を式と表で表す」のように、対応する値を列ごとに比較すること自体が理解の中心になる単元では、文章と式だけでは値の対応関係を追いにくい。

一方、教材本文へ任意HTMLを埋め込めるようにすると、公開リポジトリ内のコンテンツから表示構造やスタイルを自由に変更できる範囲が広がり、アクセシビリティ、レスポンシブ表示、セキュリティの一貫性を保ちにくい。

説明用テーブルは、図と同様に「必要な説明にだけ使える補助表現」とし、コンテンツデータから安全に構造を指定できる共通機能として扱う必要がある。

## Decision

### 1. `MathLesson` の概念説明に任意の型付きテーブルを追加できるようにする

共通の `ConceptTable` を追加し、数学レッスンの概念説明に `table?: ConceptTable` を持たせる。

テーブルは次の構造だけを持つ。

- 任意のキャプション
- 任意の列見出し
- 行見出しを持てる行
- 各行の文字列セル

既存の `Lesson` や `ConceptBlock` 自体は変更せず、共通レンダリングで利用する `MathLesson` 側を拡張する。これにより既存コンテンツとの後方互換性を保つ。

### 2. 表示は `ConceptCard` が所有する

`ConceptCard` が `ConceptTable` をセマンティックな HTML `table`、`caption`、`thead`、`tbody`、`th`、`td` に変換する。

教材コンテンツ側ではHTML断片、CSS、属性文字列を指定できない。表の構造と見た目は共通コンポーネントが管理する。

行見出しは `scope="row"`、列見出しは `scope="col"` を用いる。長い表はカード全体ではなく表コンテナだけを横スクロールさせ、小さい画面で本文のレイアウトを崩さない。

### 3. セルでは既存の数式表示ルールを再利用する

表の見出しとセルは通常の教材文字列として扱い、既存の `toPortableMathText` と `hasFragileMathGlyphs` / `StaticMath` を再利用する。

これにより、単純な `x`、`y`、数値だけでなく、必要な場合は既存の数式表示方針に沿って数式を表内へ置ける。表専用の数式ライブラリやMarkdown/HTMLパーサーは追加しない。

### 4. 最初の適用先を「比例を式と表で表す」とする

中学1年 `proportion-table-expression` の概念説明に、`y = 3x` の対応表を追加する。

表では x、y、y/x を行として並べ、同じ列の y を x で割るとすべて3になることを示す。文章、式 `y = ax`、対応表を同じ概念カードで確認できるようにし、「表から比例定数を読む」という学習目標と表示を一致させる。

### 5. テーブルは必要な説明にだけ追加する

すべての概念説明へ表を付けることはしない。

値の対応、場合分け、比較、規則性など、行・列の対応関係が理解の根拠になる場合に利用する。文章、式、図だけで十分な説明では既存表現を維持する。

### 6. 依存関係は変更しない

既存の Astro コンポーネントと数式表示機能だけで実装する。新しい依存パッケージは追加せず、`package.json` と lockfile は変更しない。

ADR 0005 の依存バージョン方針は継続する。

## Consequences

- 式と表を対応させる単元で、概念説明そのものに対応表を置ける。
- 表を使わない既存教材のデータと表示は変更されない。
- 表のアクセシビリティとレスポンシブ表示を共通コンポーネントで統一できる。
- コンテンツ側に任意HTMLやCSSを許可せずに表現力を増やせる。
- 将来、表のセル結合や複雑な多段見出しが必要になった場合は、用途を確認して型を拡張する必要がある。

## Security and privacy

- 公開リポジトリへ秘密情報、認証情報、個人情報を追加しない。
- テーブルデータは静的な文字列と型付き構造だけを受け付け、任意HTML、任意スクリプト、イベントハンドラーを受け付けない。
- 外部通信、ユーザー入力、ユーザーデータ保存、新しい実行経路を追加しない。
