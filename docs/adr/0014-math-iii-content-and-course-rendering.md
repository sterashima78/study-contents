# ADR 0014: 数学IIIの3領域を科目共通基盤へ追加する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0002, ADR 0003, ADR 0005, ADR 0006, ADR 0007, ADR 0008, ADR 0009, ADR 0010, ADR 0011, ADR 0012, ADR 0013
- Amends: ADR 0007 の科目一覧

## Context

数学I・数学A・数学II・数学B・数学C・化学基礎・物理基礎では、科目一覧から科目・領域・単元・小単元へ進む階層と、例題、直後の練習、小単元確認、単元末演習、公式・定理の根拠を管理する方針を採用している。

数学IIIを追加するにあたり、この学習体験とURL階層を維持しながら、現行の高等学校学習指導要領に対応する教材を追加する。

文部科学省「高等学校学習指導要領（平成30年告示）解説 数学編 理数編」の2026-01-15公開版では、数学IIIの内容を「極限」「微分法」「積分法」の3領域として整理している。微分法の応用として接線、増減、極大・極小、グラフの凹凸、速度・加速度を、積分法の応用として面積、体積、曲線の長さを扱う。

参照: https://www.mext.go.jp/content/20260115-mxt_kyoiku02-100002620_04.pdf

このリポジトリは公開されているため、秘密情報、認証情報、学習履歴の外部送信機構を追加しない。

## Decision

### 1. 数学IIIを3領域・6単元・20小教材で公開する

`src/content/math3/catalog.ts` を入口とし、次の3領域を登録する。

- `limits`: 極限
- `differentiation`: 微分法
- `integration`: 積分法

初期公開範囲は20小教材とする。

- 極限: 6小教材
- 微分法: 7小教材
- 積分法: 7小教材

各小教材は、学習目標、考え方・公式、導出または根拠、途中式付き例題、直後の誘導練習、3問確認、まとめで構成する。

### 2. 数学IIIは既存の科目共通レンダラーを利用する

`MathCourseInfo` に `math3` を追加し、既存の `MathAreaIndex`、`MathUnitIndex`、`MathLesson`、`MathUnitExercise` を利用する。

URLは次とする。

```text
/math3/
/math3/{area}/
/math3/{area}/{unit}/
/math3/{area}/{unit}/{lesson}/
/math3/{area}/{unit}/exercise/
```

表示コンポーネントを科目ごとに複製せず、数学III固有の教材データ、公式根拠、演習レジストリを `src/content/math3/` に分離する。

### 3. 学習指導要領の主要項目を小教材へ対応付ける

極限では、数列の収束・発散、等比数列の極限、無限級数、分数関数・無理関数、合成関数・逆関数、関数の極限と連続性を扱う。

微分法では、積・商、合成関数、三角関数、指数関数・対数関数の導関数と、接線、増減・極値・凹凸、速度・加速度を扱う。

積分法では、不定積分・定積分、置換積分法、部分積分法、いろいろな関数の積分と、面積、回転体の体積、曲線の長さを扱う。

数学Cの「平面上の曲線と複素数平面」に属する内容は数学IIIへ重複配置しない。

### 4. 公式・性質の導出分類を数学IIIへ拡張する

既習事項から短く説明できる公式・性質は `src/content/math3/formula-derivations.ts` に根拠を登録する。

極限記号、合成関数・逆関数、連続性、位置・速度・加速度のように定義を出発点とするものは `scripts/verify-formula-coverage.mjs` で明示的に分類する。分類されていない `formulas` を含む小教材が追加された場合はCIを失敗させる。

### 5. 演習は数学III専用レジストリから共通UIへ供給する

`ExerciseSet` の `courseKey` に `math3` を追加し、`src/content/math3/exercise-registry.ts` から問題を取得する。

小単元では3問、単元末では基礎12問・応用3問・難問1問の全16問を出題する。採点、問題再生成、弱点診断はブラウザ内で完結し、回答や学習状況を外部へ送信しない。

### 6. 科目一覧とCI検証へ数学IIIを追加する

トップページの科目一覧へ数学IIIを追加し、数学I・数学A・数学II・数学B・数学C・化学基礎・物理基礎の既存カードを維持する。

`scripts/verify-build-output.mjs` では数学IIIの科目ホーム、極限、微分法、積分法、単元末演習の代表ページを検証する。数学II専用の生成HTML検証、化学基礎・物理基礎の生成HTML検証、ADR整合性検証など、既存CIは維持する。

### 7. 依存関係は追加しない

2026-08-29時点で利用中のAstro `7.2.9`、MathLive `0.110.0`、Biome `2.5.10`、pnpm `12.0.0` を維持する。数学III追加のための新規ランタイム依存関係は追加しない。

## Consequences

数学IIIが既存科目と同じ情報階層、学習UI、演習体験、公式根拠の管理方針で利用できる。

数学III固有の内容は `src/content/math3/` に閉じるため、既存科目への影響を共有レジストリとトップページの最小限の変更に限定できる。

科目数がさらに増えた場合は、`MathCourseInfo`、演習レジストリ、科目一覧の分岐を完全にデータ駆動化することを再検討する。
