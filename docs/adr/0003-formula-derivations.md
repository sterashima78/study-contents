# ADR 0003: 公式は原則として導出過程を掲載する

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001

## Context

ADR 0001 では、初学者が「なぜ次の式になるのか」を追えるよう、例題の途中式を可能な限り細かく示す方針を採用した。

一方、公式そのものを結果だけ提示すると、例題の途中式が丁寧でも、公式だけは暗記対象として切り離されてしまう。特に乗法公式のように既知の法則から短い式変形で得られるものは、導出を示すことで既習事項とのつながりを明確にできる。

ただし、すべての数式表示が導出対象になるわけではない。定義や、その単元で出発点として採用する基本法則を無理に証明扱いすると、説明が循環したり、学習範囲を不必要に広げたりする。

## Decision

### 1. 導出できる公式は原則として導出過程を掲載する

既習の定義・法則・式変形から導ける公式は、公式だけを提示せず、公式へ至る途中式を掲載する。

基本的な表示順は次とする。

1. 考え方・ルール
2. 公式の導出または性質の根拠
3. 例題
4. 誘導付き練習
5. 確認演習
6. まとめ

例えば和の二乗では、次を省略しない。

1. `(a + b)² = (a + b)(a + b)`
2. `= a² + ab + ab + b²`
3. `= a² + 2ab + b²`

この結果として `(a + b)² = a² + 2ab + b²` が得られることを明示する。

### 2. 導出では通常の操作を優先する

公式専用の覚え方から説明を始めず、その時点までに学習した通常の操作を使う。

例として乗法公式では分配法則による素朴な展開、因数分解では展開した式の係数比較、有理化では分子・分母に同じ数を掛ける操作を使う。

各段階には、何をしたかを短く説明する。

### 3. 定義は導出対象にしない

次のようなものは、原則として「公式の導出」として扱わない。

- 有理数の定義
- 絶対値の定義
- 集合演算の記号の意味
- 必要条件・十分条件の用語の定義

定義については、意味、具体例、使い方を説明する。

### 4. 出発点となる基本法則は根拠と位置付けを説明する

その単元で前提として利用する法則を、同じ法則自身から導出しない。

例えば分配法則を展開公式の導出に利用する場合、分配法則そのものは出発点として扱う。

一方、不等式で負の数を掛けると不等号が反転する性質や、命題と対偶が同値であることのように、学習済みの性質から短く根拠を示せる場合は「性質の根拠」として掲載する。

### 5. 導出が長すぎる場合は学習目標を優先する

導出が現在の学習範囲を大幅に超える場合や、導出そのものが別の学習目標になる場合は、無理に同じページへ収めない。

必要であれば別の小単元へ分離する。省略する場合は、定義なのか、前提として使う性質なのか、後で扱う内容なのかが分かる説明を添える。

## Consequences

公式を既習事項から得られる結果として理解しやすくなり、公式を忘れた場合でも基本操作から再構成する手掛かりを持てる。

教材ページは導出分だけ長くなるため、導出の途中式は公式の理解に必要な段階へ絞る。導出自体が長くなる内容は ADR 0001 の「1ページ1技能」に従って別ページ化を検討する。

今後、新しい教材へ公式・定理・性質を追加する際は、コンテンツレビュー時に「導出対象」「定義」「出発点となる基本法則」のいずれかを判断する。
