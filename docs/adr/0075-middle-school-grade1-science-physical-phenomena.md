# ADR 0075: 中学1年理科「身近な物理現象」を10技能と共通理科基盤で実装する

- Status: Accepted
- Date: 2026-09-01
- Related: ADR 0038, ADR 0071

## Context

中学数学1〜3年の全領域が完成し、次の中学校教科として理科を追加する。現行の中学校学習指導要領（平成29年告示）解説 理科編では、第1分野（1）「身近な物理現象」として、光の反射・屈折、凸レンズの働き、音の性質、力の働きを、観察・実験の結果から規則性や関係性を見いだして表現することが求められている。

既存リポジトリには高校物理・化学・生物と、中学数学で確立したCourseHome / MathLesson / MathUnitExercise / Diagram基盤があるため、理科専用のページフレームを新規に複製する必要はない。一方、中学生向けの確認演習は高校理科の6問セットではなく、各教材3問・単元末8問という中学数学に近い密度が適している。

## Decision

1. コースキー `middle-science1`、ルート `middle-school/science/grade1` を追加する。
2. 中学理科のナビゲーション上の領域は、今後の3学年展開を見据えて「エネルギー」「粒子」「生命」「地球」の概念的なまとまりを使う。学習指導要領上の単元名はunitタイトルとして保持する。
3. 最初のunitとして第1分野（1）「身近な物理現象」を追加し、次の10技能に分ける。
   - 光の反射
   - 光の屈折と全反射
   - 凸レンズの焦点
   - 実像と虚像
   - 音の発生と伝達
   - 振幅・振動数と音の大きさ・高さ
   - 力の働き
   - 力の大きさ・向き・単位
   - ばねの伸びと力の比例関係
   - 2力のつり合い
4. ページ表示は既存のCourseHome / MathLesson / MathUnitExerciseを再利用する。
5. 中1理科専用exercise registryを追加し、各教材3問、単元末8問を生成する。10技能から8問を巡回開始位置を変えて出題し、同じ技能が恒常的に除外されないようにする。
6. 反射、屈折、凸レンズ、音、力、ばね、2力のつり合いを既存の型付きDiagram APIで図解する。外部描画ライブラリは追加しない。
7. 学習指導要領参照は文部科学省「中学校学習指導要領（平成29年告示）解説 理科編」を登録する。

## Safety and privacy

- 強い光源や凸レンズを扱う説明では、光源を直接目で見ないという公式解説の安全上の注意を教材設計の前提とする。
- 今後の物質分野でも、危険な薬品操作を再現可能な手順として詳細化せず、学校での安全管理を前提とした概念理解を中心にする。
- 教材・演習は固定例またはブラウザ内生成値だけを使い、実在する生徒・学校・組織の個人情報を扱わない。
- 秘密情報、認証情報、外部API、分析SDKを追加しない。

## Consequences

- 中学校トップから数学と理科へ進める教科構造ができる。
- 中学理科2・3年も同じコース・ルート・演習・Diagram設計を横展開できる。
- 共通コンポーネントを再利用するため、表示やアクセシビリティの一貫性を保てる。
- 新規依存関係は増えず、Study AIのruntime/model診断条件にも影響しない。
