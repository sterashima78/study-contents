# ADR 0005: 利用ライブラリは確認時点の最新リリースへ固定する

- Status: Accepted
- Date: 2026-08-29
- Updated: 2026-08-29

## Context

このリポジトリでは、利用ライブラリを最新に保つ方針としている。

2026-08-29 時点で npm の公開情報を確認すると、Astro は `7.2.9`、MathLive は `0.110.0`、Biome は `2.5.10` が latest である。

pnpm については12系を使用する方針が別途決まっている。ADR作成時点では12系の最新公開版は `12.0.0-rc.9` だったが、同日の再確認時点で安定版 `12.0.0` が公開済みとなった。

存在しないバージョンや、公開レジストリの現行情報と一致しないバージョンを設定すると、CIやデプロイ時の依存関係インストールが失敗する。

## Decision

### 1. バージョン更新時は公開レジストリの現行情報を確認する

`package.json`、CI、デプロイ設定を更新する前に、npm など公式の公開レジストリで実在する最新版を確認する。

### 2. 依存関係は再現性のため完全なバージョンで固定する

教材サイトは静的サイトであり、ビルド結果の再現性を優先するため、主要な依存関係と開発ツールは完全なバージョンで指定する。

### 3. pnpm は12系の最新公開版を使う

2026-08-29 の再確認時点では安定版 `pnpm@12.0.0` を `packageManager`、CI、デプロイの3か所で一致させる。

今後12系の更新版が公開された場合は、互換性とCIを確認したうえで12系の最新公開版へ更新する。

### 4. バージョンの食い違いを作らない

パッケージマネージャのバージョンはローカル利用を示す `packageManager` と GitHub Actions のセットアップ指定で同一にする。

## Consequences

CIで実在しないツールバージョンを取得しようとする失敗を避けられる。完全固定により更新は自動ではないため、ライブラリ更新時には公開レジストリの最新版確認とCI実行をセットで行う。
