# ADR 0069: 中学3年「標本調査」を8教材で実装し中学数学3学年を完成する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0060, ADR 0062, ADR 0067, ADR 0068

## Context

第3学年D(1)では、標本調査の必要性と意味、無作為抽出、方法や結果の批判的考察、簡単な場合の母集団の傾向の推定・判断が求められる。第1学年のデータ分布、第2学年の箱ひげ図と確率を基礎に、全てのデータを得られない状況での推測へ進む。

## Decision

### 1. 標本調査を8教材に分割する

全数調査との違い、母集団と標本、無作為抽出、割合の推定、個数の推定、標本の偏り、標本による推定値のばらつき、簡単な調査計画を独立技能とする。

### 2. 無作為抽出と批判的考察を中心に置く

数値計算だけでなく「誰が選ばれやすいか」「標本が母集団を代表しているか」「質問方法や無回答に偏りがないか」を考察対象にする。

### 3. 推定値を確定値として扱わない

同じ母集団からの別の無作為標本では結果が変動し得ることを明示する。中学校範囲を超える信頼区間や推測統計の公式には進まない。

### 4. 実在個人・実調査データを使わない

演習・Diagramは架空の学校・製品や生成値だけを使用する。公開リポジトリに個人情報、実在組織の内部データ、認証情報を保存しない。

### 5. D領域追加をもって中学3年4領域を公開済みにする

中学数学入口と中3トップを更新し、中学1〜3年のA〜D領域が公開済みであることを表示する。

### 6. 依存関係とAI境界を維持する

新規依存関係、分析SDK、外部APIは追加しない。`package.json`、`pnpm-lock.yaml`、Study AI runtime/model/診断条件は変更しない。

## Consequences

- 第3学年D領域が学習指導要領に対応して完結する。
- 中学1〜3年の4領域がすべてカタログ上で公開される。
- 標本調査の数値処理と批判的判断を分離して学べる。
