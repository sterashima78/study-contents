# ADR 0054: 中学2年数学を「式の計算と文字式の活用」から開始する

- Status: Accepted
- Date: 2026-08-31

## Context

ADR 0053までに、中学1年数学の「A 数と式」「B 図形」「C 関数」「D データの活用」を1ページ1技能の教材として実装した。

次の学年へ範囲を広げるにあたり、現行の中学校学習指導要領（平成29年告示）数学第2学年「A 数と式」では、文字を用いた式について、簡単な整式の加法・減法、単項式の乗法・除法を扱い、具体的な事象の数量関係を文字式で表したり、式の意味を読み取ったり説明したりすることが求められる。また同じ領域で連立二元一次方程式を扱う。

既存の中学1年教材は、小教材ごとに説明、例題、練習、3問の確認演習を持ち、単元末では8問を生成して理解度を診断する。この操作体系を中学2年でも維持する。

## Decision

### 1. 中学2年数学コースを独立したコースキーで追加する

`middle-math2` を追加し、ルートを `middle-school/math/grade2` とする。

中学1年と学習記録、学習指導要領参照、AI教材コンテキストを混同しないため、`middle-math1` のコースキーを流用しない。

### 2. 最初の単元を「式の計算と文字式の活用」とする

第2学年「A 数と式」を一度に実装せず、まず次の8技能を一単元として追加する。

1. 単項式・多項式と次数を整理する
2. 多項式の同類項をまとめる
3. 多項式を加える
4. 多項式を引く
5. 単項式を掛ける
6. 単項式を割る
7. 単項式の乗除を組み合わせる
8. 文字式を使って数量関係を説明する

連立二元一次方程式は計算技能と利用技能を持つ独立性の高い内容であるため、後続単元として分離する。

### 3. 中学数学の共通表示と演習UIを学年間で共有する

`MathLesson.astro`、`MathUnitExercise.astro`、`MiddleMathExerciseSet.astro` は中学1年専用の条件分岐を、中学数学コース共通の分岐へ拡張する。

問題生成データは学年別ディレクトリに分け、中学2年では `grade2/exercise-registry.ts` を使用する。これにより表示・採点UIは共有しつつ、学年ごとの問題内容を分離する。

### 4. 単元末8問では8技能を1問ずつ扱う

各小教材は3問、単元末は8問とする。今回の単元は8技能で構成するため、単元末では原則として各技能から1問ずつ出題する。

### 5. 新しい外部依存関係を追加しない

既存のAstro、TypeScript、ブラウザ標準APIを使用する。今回の教材追加のために新しい外部ライブラリは導入しない。

公開リポジトリであることを前提とし、教材、演習データ、ADRに秘密情報、個人情報、認証情報を含めない。

## Consequences

中学1年から中学2年へ同じ操作体系で学習を継続できる。中学2年を独立したコースキーにすることで、学習記録や参照情報を学年単位で管理できる。

一方、中学数学共通コンポーネントは複数学年のレジストリを選択する責務を持つ。今後中学3年を追加する際は、条件分岐が増えすぎる場合にレジストリ解決を別モジュールへ切り出すことを検討する。
