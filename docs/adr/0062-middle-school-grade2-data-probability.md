# ADR 0062: 中学2年「データの活用」を分布比較と確率の2単元で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0053, ADR 0054, ADR 0058, ADR 0060

## Context

中学校学習指導要領（平成29年告示）解説 数学編の第2学年「D データの活用」は、D(1)「データの分布」とD(2)「不確定な事象の起こりやすさ」に分かれている。

D(1)では、四分位範囲や箱ひげ図の必要性と意味を理解し、データを整理して箱ひげ図で表すこと、四分位範囲や箱ひげ図を用いて複数のデータの分布の傾向を比較して読み取り、批判的に考察し判断することが求められている。解説では、箱ひげ図は複数の分布を比較しやすい一方、分布の細かな形など失われる情報があるため、必要に応じてヒストグラム等と併用して考察することも示されている。

D(2)では、第1学年で多数回の試行から相対度数を確率として捉えた学習を踏まえ、起こり得る場合が同様に確からしいときに、場合の数を基に確率を求める。起こり得る場合を漏れなく重複なく数え、確率を用いて不確定な事象を考察し表現することが求められる。また、確率1/6を「6回試せば必ず1回起こる」と解釈しないなど、確率を確定した結果と混同しないことが重要である。

第2学年では既に「A 数と式」「B 図形」「C 関数」を実装済みであり、本ADRで「D データの活用」を追加すると第2学年の4領域が揃う。

並行した変更のマージで一時的にADR 0059が重複したが、mainでは座標平面の図示方針をADR 0059、中学2年図形をADR 0060、長い数式の横スクロールをADR 0061として整理済みである。本決定はその連続した採番を引き継ぎADR 0062とする。

## Decision

### 1. `data` 領域を追加し、学習指導要領のD(1)・D(2)に対応する2単元へ分ける

中学2年 `middle-math2` に `data` 領域を追加する。

- `data-distribution-comparison`: データの分布と比較
- `probability-counting`: 場合の数と確率

コース内の領域順は学習指導要領に合わせ、A 数と式、B 図形、C 関数、D データの活用の順に統一する。

### 2. D(1)「データの分布」を4技能で構成する

1. 四分位数を求める
2. 四分位範囲で散らばりを捉える
3. 箱ひげ図を読み、表す
4. 箱ひげ図で分布を比較し批判的に考察する

第1四分位数、中央値、第3四分位数と、四分位範囲 `Q3 − Q1` を段階的に扱う。箱ひげ図では最小値、Q1、中央値、Q3、最大値を対応付け、複数の分布を同一尺度で比較する。

比較では、中央値や四分位範囲だけから分布の細かな形まで断定しない。箱ひげ図では失われる情報があることを明示し、必要に応じてヒストグラムや元データを併用する判断を教材に含める。

### 3. D(2)「不確定な事象の起こりやすさ」を8技能で構成する

1. 多数回の試行と場合の数の確率を結び付ける
2. 同様に確からしい場合を捉える
3. 起こり得る場合を漏れなく数える
4. 場合の数から確率を求める
5. 二段階の試行の確率を求める
6. 確率を比べて公平さを判断する
7. 確率を「必ず」と誤解しない
8. 確率を不確定な事象の説明に活用する

場合の数による確率は、起こり得る各場合が同様に確からしいことを前提とする。樹形図や表の考え方を使って、場合を漏れなく重複なく整理してから確率を求める。

確率計算そのものを目的にせず、結果の起こりやすさ、公平さ、見積もりを説明するところまで扱う。確率から少数回の結果を断定しないことも独立した技能として確認する。

### 4. 箱ひげ図と場合の整理を既存Diagram基盤で可視化する

`src/content/middle-school/math/grade2/data-probability-diagrams.ts` を追加する。

- 四分位数と5数要約を示す箱ひげ図
- 複数の箱ひげ図の比較
- 多数回の相対度数と理論的な確率の関係
- 2枚の硬貨などの樹形図
- 確率の比較による公平さの模式図

ADR 0034以降の型付きDiagram基盤だけを使用し、任意SVG、`innerHTML`、新しい外部描画ライブラリは追加しない。色だけに意味を持たせず、ラベルと`ariaLabel`で意味を補う。

中2の図解は `grade2/lesson-diagrams.ts` で一次関数、図形、データの各companion registryを合成する。

### 5. D領域専用の演習レジストリを追加する

`src/content/middle-school/math/grade2/data-exercise-registry.ts` を追加し、既存の中学数学共通演習UIへ接続する。

- 各小教材: 3問
- 各単元末: 8問
- `data-distribution-comparison` は4技能を繰り返して8問
- `probability-counting` は8技能を1問ずつ

箱ひげ図の批判的考察や確率の解釈では、長い自由記述の完全一致を求めず、「言える／言えない」「同じ／異なる」など評価点を短い回答で確認する。

### 6. 教材データは固定またはブラウザ内生成の架空値に限定する

公開リポジトリであることを前提に、教材・図解・演習で使用するデータは教材用に作成した固定値またはブラウザ内で生成する数値だけとする。実在する生徒、学校、組織のデータや個人情報を収集・埋め込みしない。

外部API、認証情報、秘密情報、分析SDKを追加しない。

### 7. 依存関係とAI診断条件は変更しない

既存DiagramとTypeScriptだけで実装できるため、新しい依存関係は追加しない。`package.json` と `pnpm-lock.yaml` は変更しない。

ADR 0055・0056でAcceptedとなっているAndroid向けWebLLM・モデル診断条件も変更しない。

## Consequences

- 中学2年数学のA〜Dの4領域が揃う。
- 第1学年の多数回の試行による確率から、第2学年の同様に確からしい場合の数による確率へ接続できる。
- 箱ひげ図を単なる作図手順ではなく、複数分布の比較と批判的考察の道具として扱える。
- 確率を計算結果の暗記ではなく、不確定な事象について根拠を持って説明するための値として扱える。
- ADR 0059〜0062を一意に参照できる状態を維持する。
- 次の中学数学の主要追加対象は第3学年となる。

## Validation

CIで次を確認する。

- Biome
- ADRの採番・Status・整合性
- 学習指導要領参照
- formula coverage
- application and advanced content
- Diagramデータ
- component style boundaries
- study AI boundaries
- Astro build
- 生成HTML検証

加えて、次を確認する。

- `middle-math2` がA 数と式、B 図形、C 関数、D データの活用の順に表示されること。
- D(1)の4教材とD(2)の8教材が静的ルートとして生成されること。
- 各教材で3問、各単元で8問の演習が生成されること。
- 箱ひげ図と確率の図解が既存Diagram validatorを通過すること。
- `docs/adr` が0059、0060、0061、0062と一意かつ連続すること。
- `package.json`、`pnpm-lock.yaml`、AI runtime・モデル設定が変更されていないこと。

教材内容は文部科学省「中学校学習指導要領（平成29年告示）解説 数学編」第2学年 D(1)・D(2)を基準に確認する。
