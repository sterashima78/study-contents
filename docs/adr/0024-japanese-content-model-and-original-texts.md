# ADR 0024: 国語教材を専用モデルで構成し独自例文を原則とする

- Status: Accepted
- Date: 2026-08-29
- Related: ADR 0001, ADR 0017, ADR 0023

## Context

このリポジトリへ高校国語の教材を追加する。現行の高等学校学習指導要領では、共通必履修科目として「現代の国語」「言語文化」、選択科目として「論理国語」「文学国語」「国語表現」「古典探究」が置かれている。一方、学習者が受験勉強や分野別復習を行う際には「現代文」「古文」「漢文」という入口も分かりやすい。

既存の数学・理科教材は「領域 → 単元 → 小教材」の階層と「1ページ1技能」を採用しているが、国語では数式の導出よりも、本文中の根拠、語句・文法・句法、人物関係、読みの手順を明示する必要がある。また現代文の既存評論・小説や入試問題を公開サイトへ転載することは権利上の問題を生じ得る。

教材UIについては ADR 0023 により、基本スタイルを `StudyPage.astro` が所有し、各教材表現はAstroコンポーネントがscoped styleを所有する方針が採用されている。

## Decision

### 1. サイト上の国語の入口は「現代文・古文・漢文」とする

URLは次の階層とする。

```text
/japanese/
├─ gendai/
├─ kobun/
└─ kanbun/
```

各分野の下は既存教材と同様に「単元 → 小教材」とし、小教材は原則として1ページ1技能、5〜10分程度で一区切りつく量にする。

「現代文・古文・漢文」はサイト上の学習導線の分類であり、学習指導要領の科目名そのものとして扱わない。教材範囲の検討時には「現代の国語」「言語文化」「論理国語」「文学国語」「古典探究」との対応を確認する。

### 2. 数学用の型へ国語教材を押し込まず、国語専用のコンテンツモデルを持つ

`src/content/japanese/` に `JapaneseArea`、`JapaneseUnit`、`JapaneseLesson` などの型を定義する。

小教材は少なくとも次の情報を持つ。

- 学習目標
- 読み方・ルールの説明
- 判断時に確認するポイント
- 短い例題
- 根拠を順に示す解説
- 直後の確認問題
- まとめ

これにより、数学の式変形用データ構造を国語の文章読解へ流用して型の意味を曖昧にしない。

### 3. 国語固有の表現はAstroコンポーネントとして実装する

次の国語固有表現を `src/components/japanese/` に置く。

- 本文・例文: `ReadingPassage.astro`
- 読み方・文法・句法のポイント: `LanguagePoint.astro`
- 例題と根拠解説: `ReadingExample.astro`
- 確認問題と解説: `PracticeQuestion.astro`

各コンポーネントは自身のscoped styleを所有し、ページ側から内部DOMのクラス構造へ依存したスタイル指定を行わない。ページシェル、パンくず、ヒーロー、見出し、一覧、まとめ、前後ナビゲーションは既存の `src/components/ui/` を再利用する。

### 4. 初期教材の本文・例文・設問・解説は原則として完全独自作成とする

現代文では、既存の評論、小説、新聞記事、市販教材、入試問題の本文を転載・要約・軽微改変して教材本文にしない。必要な読解技能を先に定義し、その技能を確認できる短い文章をこのリポジトリ用に新規作成する。

古文・漢文でも、初期実装では特定の教科書・問題集・過去問の設問や解説を流用せず、文法・句法を確認するための短い例文を新規作成する。

著作権保護期間が満了した古典作品、適切にライセンスされた文章、引用を将来利用する場合は、出典・権利状態・表示方法・レビュー方法を別途ADRで定めてから導入する。権利状態が不明な外部本文をリポジトリへ保存しない。

### 5. 初期実装は基礎となる12小教材とする

最初の検証範囲として各分野4小教材、合計12小教材を公開する。

- 現代文: 接続語、対比、心情の根拠、視点
- 古文: 歴史的仮名遣い、助動詞「む」、省略主語、敬語の方向
- 漢文: 返り点、再読文字、否定、疑問・反語

これは高校国語全範囲の完成を意味しない。構造・表示・教材粒度を検証した後、語彙、文法、句法、和歌、評論、小説、記述などを同じ方針で追加する。

### 6. 新しい実行時依存を追加しない

初期国語教材はAstroの静的生成とHTML標準の `details` / `summary` で構成し、新しいJavaScriptライブラリを追加しない。

確認問題はまず自分で考えた後に答えを開く静的構成とし、自動採点が教材上必要になった時点で既存の演習方式との統合を別途検討する。

### 7. 現行の公式資料を教材範囲の基準にする

教材範囲や読みの観点を検討する際は、文部科学省の現行学習指導要領と国語編解説を一次資料として参照する。

参考:

- 文部科学省「高等学校学習指導要領（平成30年告示）」: https://www.mext.go.jp/content/20220324-mxt_kouhou02-000021499_1.pdf
- 文部科学省「【国語編】高等学校学習指導要領（平成30年告示）解説」: https://www.mext.go.jp/content/20250410-mxt_kyoiku01-100002620_02.pdf

公式資料へのリンクは教材制作の基準を示すためのものであり、本文や設問を複製する許可を意味しない。

## Consequences

現代文・古文・漢文から直感的に教材へ入れる一方、学習指導要領上の科目構成とは区別して管理できる。

国語専用モデルを持つため、数学・理科と無理に同じデータ構造を共有せず、本文根拠や人物関係など国語固有の情報を将来拡張しやすい。

独自例文を原則とすることで公開サイトの権利リスクを抑えられるが、実作品を使った読解教材に比べて文章制作・レビューの負担は増える。外部著作物を使う場合は、権利状態を明示する追加設計が必要になる。

初期12小教材は構造検証用の基礎範囲であり、大学入試までを十分に網羅するには継続的な単元追加と内容レビューが必要である。
