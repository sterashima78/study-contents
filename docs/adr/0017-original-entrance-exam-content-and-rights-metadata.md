# ADR 0017: 大学入試向け教材を独自作成し権利状態を管理する

- Status: Accepted
- Date: 2026-08-29

## Context

ADR 0001 と ADR 0002 では、初学者向けの小単元学習と単元末演習を中心に教材構造を定めた。一方、大学入試では、複数技能から解法を選ぶ問題、複数単元を組み合わせる問題、長い条件を整理する問題、記述式問題など、基礎教材とは異なる演習層が必要になる。

大学入試の過去問は有用な分析資料だが、公開サイトで問題文、図表、データ、解答解説などをそのまま、または軽微に変更して再利用すると、著作権その他の権利処理が必要になる場合がある。大学入試センターも試験問題の一部または全部を利用したインターネット上の問題集作成を二次利用として扱い、事前の利用申請を案内している。

このリポジトリは公開リポジトリかつ公開Webサイトであるため、授業内だけに閉じた利用を前提とした権利制限に依存せず、権利状態を説明できる教材だけを公開する必要がある。

このADRは法的評価の代替ではなく、公開教材を継続的に作るための保守的な内部制作ルールを定める。

## Decision

### 1. 入試演習を基礎教材とは別の学習層として追加する

ADR 0001 の「1ページ1技能」と ADR 0002 の小単元確認・単元末診断は維持する。

大学入試向けには、その上に次の能力を確認する別の演習層を追加する。

- 複数の既習技能から解法を選ぶ
- 条件を整理して数式や図に変換する
- 複数単元を組み合わせる
- 解法の根拠を説明する
- 制限時間を意識して問題を処理する

最初の検証対象は数学I「二次関数」の入試標準問題5問とする。

### 2. 公開する入試問題は原則として完全独自作成とする

入試演習用の問題文、数値、設定、図表、設問、解答、解説は、このリポジトリ用に新規作成する。

次の作り方は禁止する。

- 過去問や市販教材の問題文を転載する
- 数字、固有名詞、単位だけを変更する
- 語順や表現だけを言い換える
- 設問順だけを変更する
- 元問題の図、グラフ、表、データを写す、または実質的に再現する
- 元問題の特徴的な設定や誘導を保ったまま表現だけを変更する
- 解答解説を転載または要約して教材解説として利用する

特定の既存問題を「元問題」として変形する方法ではなく、対象技能と難易度を先に定義し、その仕様から問題を新規設計する。

### 3. 外部問題から抽出してよいのは抽象的な分析情報に限定する

出題傾向を調査する場合は、次のような抽象情報を分析対象とする。

- 対象単元
- 必要な知識・技能
- 必要な思考過程
- 問題形式
- 想定難易度
- 想定時間
- 誤答しやすい観点

調査時に閲覧した問題文や解答解説の全文・大量の抜粋は、ソースコード、教材データ、Issue、Pull Request、ADRなど公開リポジトリ内へ保存しない。

### 4. 入試問題には権利状態メタデータを必須とする

`src/content/entrance/` 以下の問題データには、各問題ごとに次の情報を持たせる。

- `rights.origin`: 問題の由来
- `rights.reviewStatus`: 公開前の権利確認状態
- `rights.reviewedAt`: 確認日

初期実装で公開可能な組み合わせは次だけとする。

- `origin: "original"`
- `reviewStatus: "reviewed"`

`licensed`、`quotation`、`public-domain` など原著作物を利用する状態は、権利確認方法、必要な出典情報、表示方法、期限管理を別途ADRで定義するまで教材データとして受け入れない。

### 5. CIで権利メタデータを検証する

`src/content/entrance/` 以下のJSON教材を検査し、少なくとも次をCIで確認する。

- 問題IDが存在し、ファイル内で重複していない
- `rights.origin` が `original` である
- `rights.reviewStatus` が `reviewed` である
- `rights.reviewedAt` が `YYYY-MM-DD` 形式である
- `original` 問題に外部問題の本文を保持するための `sourceText` などのフィールドがない

機械検査は類似表現そのものを判定するものではない。PRレビューでは次項の人手確認も行う。

### 6. PRで独自性を確認する

入試教材を追加・変更するPRでは、少なくとも次を確認する。

1. 特定の既存問題を書き換えただけではない
2. 問題文・図表・データをコピーしていない
3. 数字や固有名詞だけの変更ではない
4. 特徴的な設定や誘導をそのまま流用していない
5. 解答・解説も独自に作成している
6. 外部著作物の本文や画像をリポジトリへ持ち込んでいない
7. 問題データの権利メタデータが実態と一致している

### 7. 引用は入試問題制作の通常手段にしない

著作権法上の引用に該当し得る場合でも、入試演習問題を作成する目的では原則として外部問題本文を引用しない。

批評・研究など引用の必然性がある別コンテンツを将来追加する場合は、引用部分の明確な区別、必要最小限、主従関係、出所表示などを個別に確認し、入試問題データとは分離する。

### 8. 参照情報は公式資料へのリンクと抽象的な制作メモに限定する

出題方針を確認する際は、大学入試センター、文部科学省、文化庁などの公式資料を優先する。

参考:

- 大学入試センター「このウェブサイトについて」: https://www.dnc.ac.jp/about_site.html
- 文化庁「著作権」: https://www.bunka.go.jp/seisaku/chosakuken/

外部資料へのリンクは参照先を示すためのものであり、その内容をこのリポジトリへ複製する許可を意味しない。

## Consequences

過去問そのものを大量に掲載する方式より制作コストは上がるが、公開教材として権利状態を説明しやすくなる。また、特定年度や特定大学の問題表現に依存せず、必要な技能から演習問題を設計できる。

入試傾向の分析と問題制作を分離するため、「過去問に似せること」ではなく「同程度の思考を独自の設定で要求できること」が教材品質の基準になる。

権利メタデータとCI検証だけでは著作権侵害の有無を自動判定できないため、公開前の人手レビューは引き続き必要である。
