# ADR 0059: 中学2年「図形」を平行線・多角形と合同・証明の2単元で実装する

- Status: Accepted
- Date: 2026-08-31
- Related: ADR 0054, ADR 0057, ADR 0058

## Context

中学校学習指導要領（平成29年告示）解説 数学編の第2学年「B 図形」は、B(1)「基本的な平面図形の性質」とB(2)「図形の合同」に分かれている。

B(1)では、平行線や角の性質、多角形の角についての性質を扱い、観察・操作で見いだした性質を平行線などの根拠に基づいて確かめ説明することが求められる。

B(2)では、合同の意味、三角形の合同条件、証明の必要性・意味・方法を理解し、三角形や平行四辺形の基本的な性質を論理的に確かめること、証明を読んで新しい性質を見いだすこと、具体的な場面で活用することが求められる。また、定義・証明・逆・反例・≡を扱い、正方形・ひし形・長方形を平行四辺形の特別な形として扱う。

## Decision

中学2年の `geometry` 領域を追加し、学習指導要領の区分に合わせて次の2単元に分ける。

### 1. `parallel-lines-polygons`

4技能で構成する。

1. 対頂角・同位角・錯角を捉える
2. 平行線の性質と条件を使う
3. 三角形の内角・外角を説明する
4. 多角形の内角・外角を求める

単に角度を計算するだけでなく、平行線、対頂角、同位角、錯角など、使った根拠を教材本文で明示する。

### 2. `congruence-proofs`

8技能で構成する。

1. 合同の意味と対応を捉える
2. 三角形の合同条件を使う
3. 仮定・結論・根拠で証明を組み立てる
4. 二等辺三角形の性質を証明する
5. 平行四辺形の性質を証明する
6. 平行四辺形になる条件と特別な形を捉える
7. 逆と反例を使う
8. 図形の性質を具体的な場面に活用する

証明は完成した文章の暗記を目的にせず、仮定、結論、根拠、合同条件、対応する辺・角という構造を段階的に扱う。

### Diagram

角の位置関係、三角形の内角の説明、多角形の三角形分割、合同な三角形、二等辺三角形の補助線、平行四辺形の対角線、特別な四角形の関係を既存のDiagram基盤で描画する。

中2一次関数の図解と責務を分けるため、図形用は `grade2/geometry-diagrams.ts` に分離し、`grade2/lesson-diagrams.ts` で一次関数図解と合成する。

### Exercises

図形専用の `geometry-exercise-registry.ts` を追加する。

- 各小教材: 3問
- 各単元末: 8問
- B(1)の4技能は単元末8問の中で繰り返し出題する
- B(2)は8技能を1問ずつ出題する
- 証明教材でも自由記述の長文一致は要求せず、仮定、結論、根拠、合同条件など評価点を短い入力で確認する

### Security and dependencies

公開リポジトリであることを前提に、教材・演習には固定の架空条件またはブラウザ内で生成する数値だけを使用する。秘密情報、個人情報、認証情報、外部APIを追加しない。

新規依存関係は追加しない。`package.json`、`pnpm-lock.yaml`、ローカルAIのruntime・モデル設定は変更せず、mainでAcceptedとなっているAI診断用設定を保持する。

## Consequences

- 学習指導要領B(1)からB(2)への流れを、計算から論理的な説明・証明へ自然につなげられる。
- 図形の性質を視覚的に確認しながら、証明では根拠を言語化する構成になる。
- 中2の公開領域は「A 数と式」「B 図形」「C 関数」まで拡張される。
- 次の独立した追加対象は「D データの活用」の確率・データとなる。
